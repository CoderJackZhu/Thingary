隐私政策

一句话：你的资料留在你自己的设备上，我们拿不到。想在几台设备间用同一份资料，可以自己接一个网盘（可选，默认关闭），内容先加密再上传，我们同样看不到。物谱没有账号、广告和使用统计。

最后更新：2026-10-25。适用于物谱（Thingary）的 Android、iOS、Mac 与 Windows 版。

资料默认只在你的设备上

你记录的物品、账户、盘点、规划条件和照片，都保存在这台设备上物谱自己的存储空间里。物谱没有账号，我们也没有运营任何接收你资料的服务器，所以我们既看不到，也没法帮你恢复。同步默认关闭，只有你自己配置之后才会发生，见下文「可选的同步」。

要说清楚的一点：设备上的资料库和图片本身没有加密，可选的加密保护的是你导出的备份和上传的同步副本。

我们不收集，也不跟踪

  • 不自动向开发者发送个人信息、设备标识、使用记录或崩溃日志。
  • 不含广告，不含第三方统计、分析或跟踪工具；本网站也不使用统计脚本（在线测算页的可选计数功能默认关闭）。
  • 开发者不会将你记录的资料提供给第三方；你主动配置的同步和分享由你选择的服务处理。
  • App 隐私标签与应用内的隐私清单据此声明：不收集数据，不用于跟踪。

默认不联网

手机版未配置同步时不主动访问网络。你点击帮助、官网、GitHub 反馈或自己填写的商品链接时，由系统浏览器打开对应网页，不附带资料库内容。桌面版的「检查更新」只在你开启或点击后访问公开版本列表，不发送资料库内容。可选同步见下文。

「写邮件反馈」会打开一封草稿，附上应用版本、系统版本和屏幕尺寸等运行环境信息，不读取物品、账户或金额。你可以修改草稿，并自行决定是否发送。

可选的同步（默认关闭）

如果你想在几台设备间使用同一份资料，可以在设置里选 WebDAV 同步，把资料放到你自己的网盘（如坚果云、Nextcloud）或自建服务器上。

  • 加密在你的设备上完成。资料先用你设置的同步口令加密，再上传；服务器的运营方和我们都看不到内容。服务器能看到的只有设备名、时间、版本号和文件大小。
  • 什么时候联网。开启后，物谱会在打开、回到前台或进入后台时联系你配置的服务器，看有没有新版本。它不会自己替换你设备上的资料，有新版本或冲突时会提示你自己选。
  • 我们收不到什么。你的服务器地址、账号、密码和同步口令只保存在你的设备上，开发者收不到。
  • 口令要自己记好。忘记同步口令，云端的加密副本就无法恢复；你设备上的资料不受影响。

备份由你自己保管

物谱可以导出完整备份和表格，支持的平台还可导出 PDF 报告。Android 与 iOS 导出后会打开系统分享面板，由你决定保存到哪里、发送给谁或取消。物谱不会自动发送这些导出文件。你可以在「备份安全」中用恢复密钥给备份加密；密钥丢失后无法找回加密备份，请自行妥善保存。备份一旦离开物谱，其保管与隐私由你选择的服务负责。

权限各自的用途

权限用途说明
相机（iOS）为物品、凭证拍照仅在你点「拍摄」时使用；照片保存在本机物品档案。Android 版不申请相机权限。
相册与文件选择选择图片、导入表格或恢复备份只读取你选中的内容。Android 版不申请全盘文件或整个相册的读取权限。
系统身份验证解锁物谱中的本机资料使用面容 ID、触控 ID 或 Android 的生物识别／设备凭据。验证由系统完成，物谱不会读取指纹、面容或设备密码。需要你主动开启。
通知在本机按计划提醒盘点、保修到期、周期付款等全部是本机定时通知，不经过推送服务器；拒绝通知不影响其他功能。
开机完成（Android）手机重启后恢复已设置的提醒只重新安排本机提醒，不上传资料。
网络（Android）连接你配置的 WebDAV 服务器同步默认关闭，开启后只连接你指定的地址。开发者不接收资料或服务器凭据。

通知等可授权权限可在系统「设置」中调整；同步和身份验证可在物谱设置中关闭。Android 版不申请通讯录、短信、定位或电话权限。物谱还提供「屏幕隐私」选项，在切换应用时遮住内容。

如何删除资料

  • 应用内：可删除单条物品、心愿、账户或记录；删除的内容先进入「最近删除」，在「最近删除」中清空后永久清除。
  • 整体删除：在 Android 或 iOS 上卸载物谱，会删除应用内保存的资料（包括应用内保存的自动备份）。桌面版的资料清理见更新与卸载指南。
  • 你导出的文件：已分享到「文件」、云盘或其他位置的备份、表格、PDF 不由物谱管理，请到相应位置自行删除。

物谱的开发者没有你的资料副本，所以不存在向我们申请删除的流程。

儿童

物谱不向任何人收集资料，也不面向儿童设计账户或社交功能。

政策变更

若以后功能变化涉及资料处理，会先更新本页并在版本说明中告知。本页历史可在源码仓库查看。

联系方式

请在 GitHub Issues 提问或反馈。请不要在公开 Issue 中贴出真实的账户、金额、照片或备份文件。安全问题请按安全政策私下报告。

Privacy Policy (English)

Thingary has no account, advertising or usage analytics. This policy covers Android, iOS, Mac and Windows. Your items, accounts, snapshots, plans and photos are stored on your device by default. The developer operates no server that receives your library. Optional sync, off by default, uploads an encrypted snapshot to a WebDAV server you configure yourself. The library and photos on the device itself are not encrypted; optional encryption protects exported backups and sync copies. Last updated: 2026-10-25.

  • No network by default. The mobile app makes no network requests unless you configure sync or open an external link. Help, GitHub feedback, website and product links open in the system browser without library contents. Desktop update checks run only when requested or enabled and do not send library contents.
  • Feedback email. Writing feedback opens a draft with the app version, system version, screen dimensions and other runtime details, without reading your items, accounts or balances. You can edit it and decide whether to send it.
  • Optional sync (off by default). Your library is encrypted on the device with a passphrase you choose before it is uploaded to your own WebDAV server (for example Jianguoyun or Nextcloud). The server operator, and we, cannot read it, but the server can see device names, timestamps, version numbers and file sizes. Thingary contacts that server when you open the app or bring it to the foreground or background, to check for a newer version; it never replaces your local data on its own. The developer receives no address, account, password or passphrase. A forgotten passphrase cannot be recovered.
  • Backups are yours. Backup and spreadsheet exports, and PDF reports on supported platforms, are shared through the system share sheet on Android and iOS. You choose the destination or cancel; exports are not sent automatically. Optional recovery-key encryption is available; a lost key cannot be recovered. The local database and photos are not encrypted; optional encryption protects backup and sync copies.
  • Permissions. Camera access applies to iOS only. Image and file selection reads only what you choose. System authentication uses Face ID, Touch ID or Android biometrics/device credentials; biometric data and device passwords never reach Thingary. Notifications are local reminders, without a push server. Android boot-completion access restores your scheduled reminders after a restart; network access connects to your configured WebDAV server. Android requests no camera, contacts, SMS, location, phone or broad storage permission.
  • Deleting data. Delete records in the app (they go to Recently Deleted first; empty it to remove permanently). On Android and iOS, uninstalling the app removes its internal data and backups. Desktop cleanup is described in the update and uninstall guide. Files you exported elsewhere must be deleted there.
  • Contact. GitHub Issues. Please do not post real financial data or backups publicly.
