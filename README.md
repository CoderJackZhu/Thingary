# 物志 · Possio

一个面向 macOS 的 Local-first 实物资产管理应用，记录重要物品从心愿、购买、使用、维护到退役或售出的完整生命周期。

**定位：高完成度的 Mac 桌面体验 + 个人持物档案 + 成本分析 + 本地数据。** 不做金融投资、日常记账或依赖服务器的家庭库存系统。

当前已完成首批工程实验，处于 CP0 检查点；已有最小验证 App，完整业务功能尚未实现。中文名「物志」、英文名「Possio」为工作名，发布前再核查名称可用性。

## 本机验证工程

- 安装锁定依赖：`npm ci`。
- 开发窗口：`npm run tauri -- dev`。
- 前端类型检查与构建：`npm run build`。
- 格式与 Rust 检查：`npm run check`。
- 数据与故障实验：`npm test`（使用独立临时目录；会终止自己创建的测试子进程）。
- 本机 App 打包：`npm run tauri -- build --bundles app`。

App 产物位于 `src-tauri/target/release/bundle/macos/Possio Verification.app`。不含远程更新、后台代理或正式资产库；本轮没有推送发布。只在当前 Apple Silicon Mac 验证，旧系统及 Intel 尚未实测。

验证 App 使用当前用户临时目录下的 `possio-verification-v1`；系统可清理该目录，请勿录入真实资料。界面仅能保存/补录内置虚构物品。图片、备份及恢复目前由自动实验验证，正式用户操作界面随对应 T 任务实现。
