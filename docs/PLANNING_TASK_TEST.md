# 规划任务测试

这是一组给真实使用者的任务，不是操作教程。目的是观察能否独立完成、理解结果及识别未确定的条件。不要先读代码或预期答案；卡住也属于有效反馈。

使用开发文档的虚构浏览器预览，在下面地址的本机端口启动开发服务器。每个任务用自己的链接进入，刷新会重置该任务。只使用虚构数据，不填写个人资料。浏览器测试不能证明原生保存与重启。

每题约3分钟。完成后记录：你的结论、哪里找到依据、最困惑的一句话、是否需要提示。超过3分钟可以停止，记录停在哪里；不必猜测软件想要什么答案。

## 反馈格式

每题填写：

- 完成／卡住，用时约：
- 我得出的结论：
- 我从哪里找到依据：
- 最困惑的按钮、词句或一步：
- 有没有靠猜测或别人提示：

若中途由他人提示操作，保留提示内容并标记“提示后完成”。不把提示后完成记为独立成功。参与者反馈到达前，只能标记“待测”，不能由代理操作结果代填。

维护者汇总时区分操作障碍、误解、计算错误与范围缺口。先解决影响结论的误解和计算错误，再决定是否调整文案或导航；单次测试不能证明所有用户都能理解。
