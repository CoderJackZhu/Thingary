# 物志 Possio：UI 方向与交互原型

日期：2026-09-24 · 状态：两套候选，待用户比较；未冻结视觉规范，未开始应用实现。

## 1. 这一步要决定什么

用户已明确：第一次打开时，应像精致的 Mac 工具，安静、清楚、操作顺手。由此建议以 **A「静序」为主方向**，B「物笺」用于比较个人档案应有多少温度。两套共用信息架构、业务口径与样例，不因风格变化增减功能。

本轮用户确认的是方向偏好及进入 UI 阶段，不等于已批准某套页面、所有字号或最终技术栈。产品业务仍以 [产品设计](PRODUCT_DESIGN.md) 为准；本文件只维护视觉提案、原型范围和 UI 验证记录。

打开 [交互原型](ui/prototype.html)，在顶部切换 A/B、快速新增、完整详情和深浅色。文件自包含，可直接用浏览器打开，不需要安装依赖、联网或启动服务。

## 2. 两套候选

| 维度 | A · 静序（推荐） | B · 物笺 |
|---|---|---|
| 体验重点 | 查看、比较、补录、修改 | 在相同操作结构中增加档案感 |
| 视觉性格 | 克制、精确、轻量 | 温暖、安静、略有书卷感 |
| 基础色 | 冷白与淡灰 | 纸白与浅石色 |
| 强调色 | 蓝色，只用于选中、焦点和主要动作 | 苔绿，保持低饱和度 |
| 字体 | 苹方为中文主体，Avenir Next 用于数字与少量英文 | 苹方为操作文字，宋体用于物品标题，数字仍用 Avenir Next |
| 密度与结构 | 紧凑侧栏、表格、右侧摘要；细分隔线 | 同一骨架；标题更舒展，分区留白更多，摘要图片略大 |
| 边角 | 6–9 px 组件圆角 | 5–6 px，更像平整的纸面 |
| 主要取舍 | 比较效率高；个人收藏气息较弱 | 更适合回顾；标题和图片占用更多空间 |

首选“相同数据、相同页面、相同视图”比较，不用一套表格、一套大图掩盖实际差异。两套都能切换网格。若喜欢 A 的工作区与 B 的温度，可在 A 上减冷、保留图片与备注留白；不要将两套字体和色彩全部拼在一起。

### 颜色与排版提案

| 用途 | A 浅色 | B 浅色 | 深色共同要求 |
|---|---|---|---|
| 主表面 | `#FFFFFF` | `#FCFBF7` | 深色独立配色，不以简单反相处理 |
| 侧栏 | `#F4F5F7` | `#F1EFE7` | 与主区有轻微层次差 |
| 主文字 | `#252A32` | `#30372D` | 清楚但不使用刺眼的纯白 |
| 次级文字 | `#6C7480` | `#777B6E` | 待最终字号下逐项复核对比度 |
| 强调色 | `#365FC5` | `#53664B` | 提亮强调色，搭配深色按钮文字 |
| 图片背景 | `#EEF1F4` | `#EEECE3` | 不改变物品插图本身的含义 |

字体来自本机，原型无远程字体请求。正式版先确保中文和数字可读性，再确定精确字体回退策略。原型采用较紧凑的桌面密度；正式规范建议正文与表格主信息 12–13 px，辅助信息不以过小字号作为空间不足的补救。10 px 微文案和窄窗口表现需在用户实际显示器上评估，不能直接视为最终字号标准。

间距按 4/8 px 节奏：组件内 8–12 px，表单与分组 16–24 px，页面边距 24–32 px。图标统一细线，状态同时有文字，不只依靠颜色。只用短暂的选中、悬停和反馈过渡；尊重减少动态效果设置。首版不需要装饰性长动画。

## 3. 三个核心界面

### 资产浏览与右侧摘要

左侧导航、主列表、右侧摘要构成主要工作区。单击查看摘要，双击或“打开完整档案”进入详情。切换风格不重置搜索、选中项或列表/网格选择。

列表优先回答：什么物品、购入金额、状态。摘要补充图片、日均持有成本、日期和持有天数。顶部金额明确写为“当前持有物购入金额”，并显示未计入的未知金额数量，避免被误读为市场估值。

当前样例选择相机，成本包括一次清洁费用。摘要可关闭；再次选择物品重新打开。搜索和状态筛选可操作，无结果时提供清除条件入口。返回列表保留查询、筛选与选中物品；滚动恢复仍需后续 Spec 明确并验证。

### 快速新增

名字是唯一必填项。金额、日期、分类直接可见，品牌、型号和备注逐步展开。未知金额和日期保持空值，零金额说明为确实免费；不自动代入今天。封面位置保留，图片选择不在本轮交互范围。

新增和编辑使用同一表单语言，取消有未保存输入时明确提示。错误放在表单内，保留输入并可重试。演示成功后回到可查看的新物品，提示它仅在原型中临时保留。

正式版仍需补齐：渠道、序列号、保障入口、图片选择与失败、保存中状态、关闭应用时的未保存处理。这些是已有产品范围，不由本轮简化原型裁剪。

### 完整物品档案

顶部为物品身份与生命周期；主体分为成本、购买资料、备注、时间轴、保障、维护与附件。维护同时出现在时间轴和费用摘要，但成本只计算一次。

“编辑资料”可演示；维护、生命周期等尚未展开的动作禁用，避免把无效果按钮误认为已经实现。完整流程在后续 Spec 和专题原型中继续细化。

## 5. 原型边界与后续验证

原型使用自包含 HTML/CSS/少量交互脚本，只为比较 UI 和走查操作。没有 Tauri、数据库、文件附件、真实保存、备份、系统快捷键注册、原生菜单或持久化能力。它不构成可用 App，不是最终前端源码或技术栈承诺。

本轮实现：A/B 与深浅色切换、列表/网格、搜索、状态筛选、购入金额排序、选择与摘要、完整详情、临时新增和编辑、空值与金额校验、取消保护、模拟失败后重试。快捷键在页面获得焦点且浏览器不拦截时演示 ⌘F/⌘N/⌘E，不能据此证明原生 Mac 快捷键正常。

两套插图均为项目内原创 SVG 示意，无外部图片或字体依赖。未将真实个人资产、发票、序列号或用户档案写入样例。首页祝语与英文装饰文字也是提案：如果实际使用显得占空间，优先缩短标题区域；首版中文可去掉英文眉题。

待验证：VoiceOver 完整流程、键盘列表方向键、焦点返回、原生窗体与菜单、系统深浅色跟随、各显示器缩放和辅助字号、完整 P0 异常状态。当前深浅色按钮只模拟手动切换，不能视为已经接入 macOS 外观设置。

## 6. 本轮检查记录

已在 Ego Lite 中用实际页面操作检查（2026-09-24）：

- 名称必填会阻止保存；仅填写名称可新增，金额和日期保持未知，汇总未计入数量同步增加。
- 搜索依次选中退役、售出、赠品、未知金额和未知日期样例，界面显示与第 4 节基准一致。
- 模拟失败时弹窗保持打开、名字保持不变；取消失败模拟后重试可加入列表。
- 有输入时取消会提示放弃；选择保留后弹窗与输入仍在，确认放弃后关闭。
- B 方向完整详情能打开；深色切换改变对应配色；网格显示八条样例；首次使用展示新增入口。
- 1440 × 1000 目标尺寸下，B 完整详情的文档宽度未超出视口。这只是页面几何检查，不替代视觉审查。
- 原型脚本语法检查通过；未运行或声称通过应用构建、持久化或原生 Mac 测试。

**视觉检查限制**：Ego Lite 截图连续超时；内置浏览器不允许直接访问本地文件；进一步底层截图尝试被自动审批拒绝，理由为可能绕过浏览器限制，已停止。未取得截图，不能声明已经完成像素级审查、可读性验收或小窗口视觉验收。请打开原型检查实际观感，后续在正常可用的截图路径上补验。Ego Lite 提示有更新，本轮没有升级。

本轮只检查上述具体交互。排序、完整编辑更正、键盘快捷键、所有窗口断点和 VoiceOver 尚未全面验收。持物 iThings、有数等真实 App 的直接交互对比仍是竞品文档中的待实测工作；本轮不以公开介绍替代实测，也未宣称桌面体验差异已获验证。

## 7. 确认后的下一步

先选定 A、B 或以 A 为主的有限调整，再将这份文档收敛为一个视觉基线。随后进入可执行 Spec，将产品设计第 16 节的流程映射到页面、输入、结果、失败状态和验收例；继续使用现有技能与项目文档，不另建重复的 Spec 体系。
