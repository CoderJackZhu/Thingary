## 5. 验证边界

- 原生首条记录走查账户路径，实物首次记录另有自动测试；心愿、支出与周期记录的首次使用识别共用业务表检测，未逐一重复所有表单的首次启动路径。
- 重置故障和丢失回执由自动测试覆盖，未在原生 GUI 内注入磁盘故障。真实系统通知投递未重做；本轮检查的是样例隔离和真实 Store 来源。
- 重置保留旧样例目录用于故障保留，连续重置会增加少量本地占用；本轮不自动清理旧样例。
- 浏览器预览为内存模型，刷新重置；`?demo=1&section=settings` 可检查样例界面，切库与重置明确要求使用隔离原生版验收。
- 当前只验证本机 macOS/Apple Silicon，不宣称覆盖 Intel、最低 macOS 版本或 VoiceOver 完整走查。
