# T15 总览与分类分布实现与验证

日期：2026-09-26。起点 `main` = `b57f06a7f3aeaa4341594f175c4fa3a549c92455`（含 T14），分支 `codex/t15-overview`，Claude 串行实现与验收；无 schema 变更、无远程。

## 口径与实现

- `src-tauri/src/insights.rs` 每次读取时从有效记录重算，不存汇总；前端只显示后端结果。
- **当前持有** = 未删除的 Active + Retired，并分列使用中／已退役；已售出只作说明。**当前持有物购入金额**只合计已知实付价，另列未知数量；同卡说明**历史购入金额**（含已售出、不含已删除）。
- **平均持有时间**：当前持有且购入日期已知的物品，按「max(1, 今天 − 购入日 + 1)」自然日取平均后四舍五入；日期未知的件数单列，不参与。没有可计算物品时显示「—」。
- **进行中心愿**：Ongoing 数量，并说明预计金额不计入资产。
- **分类分布**：范围可切换「当前持有」「历史全部」，口径可切换「按数量」「按购入金额」；数量占比与金额占比分开，金额占比只用已知金额并提示未知件数；未分类单列。圆环配完整表格（分类、数量、金额与未知件数、占比），表格同时是无障碍与低对比色的文字替代。
- **颜色**：采用 dataviz 参考调色板的 7 个分类色，用其 `validate_palette.js` 分别对本应用浅色卡片 `#ffffff` 与深色卡片 `#252931` 校验，全部检查通过（对比度 WARN 由常显表格标签化解）。颜色槽位由后端按分类顺序、只在「有任一未删除物品」的分类中分配，因此切换持有／历史不会给同一分类换色；第 8 个起及未分类用中性灰，由表格名称区分。
- **最近事件**：取 T14 时间轴投影中最新 8 条有效事件，点击进入物品，或按心愿当前状态打开相应筛选。「在资产列表中核对」回到全部资产。
- 侧栏「总览」开放；沿用 `asset-overview` 指标卡、`detail-section`、分段按钮与 tokens。

「持有毛日均与售出净日均分开展示」属于 T17 的成本排行；总览不提供把各物品日均简单平均的组合指标（产品设计第 9 节）。累计购入趋势归 T16。
