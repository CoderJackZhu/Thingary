# U07 拖动、弹窗与资产编辑排版（2026-09-27）

拖动预览原先被移到页面最外层，因而丢失分类列表的行布局，显得比原行大。现在预览保留在所属列表中，继承同一行样式，并固定为原行的宽高；同时减轻拖动时的倾斜与阴影。共用的购买渠道、状态等排序手柄也采用相同处理。

退役与售出弹窗原有“取消”按钮和右上角关闭按钮执行相同动作，现移除重复的“取消”。关闭仍清除未提交的输入；结果待核对时仍要求先核对，避免关闭未确定的保存请求。相关错误文案改为“关闭后重新读取”。

已有资产的编辑页把备注和图片扩展为左侧两列，置顶与统计开关纵向排在右侧；展开“更多资料”后，品牌、型号和序列号横跨整行。两种主题的默认窗口截图见[深色](u07-native/asset-editor-dark.png)与[浅色](u07-native/asset-editor-light.png)。窄窗口回到两列或一列，不强制使用三列布局。

验证：`npm run build` 和 `git diff --check` 通过。隔离原生身份 `local.possio.u07.drag` 在设置页把“电脑”拖到“手机”之后，界面提示已保存，列表顺序相应改变。最终隔离身份 `local.possio.u07.layout` 中，退役与售出弹窗均只显示关闭与保存；输入虚构备注或价格后点叉，再打开时输入为空，详情仍显示“使用中”。编辑页在默认 1360 × 900 窗口显示完整，无右下大块空白。正式身份 `local.possio.main` 的资料库未用于测试。
