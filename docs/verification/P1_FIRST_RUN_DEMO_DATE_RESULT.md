# P1：首次样例体验与日期输入

日期：2026-09-27。工作分支：`codex/first-run-demo`。此记录对应待安装构建，不代表 `/Applications/物志.app` 已替换。

## 变更

- 首件真实资产前，普通 App 打开独立的八件虚构样例库。样例可在列表、详情、总览、时间轴和统计中查看，也可编辑；分类、图片、心愿等操作写入样例库自己的 SQLite。界面标记样例身份，允许查看空的“我的资料”。点击“新增资产”转到正式资料库；取消首件录入返回样例，保存后自动退出。正式库中只要曾有资产（包括移入最近删除的资产），样例就不再显示。
- 样例库不参与正式库汇总、备份或 CSV；样例模式的备份、恢复和导出按钮禁用，后端也拒绝这些命令。最近删除仍可在样例内体验。
- 新增资产及心愿转资产的购入日期预填本地今天；编辑已有资产保留原值。资产、售出、状态、维护、保障和心愿的日期字段提供同一个鼠标日历，同时保留键盘输入。可空字段可在日历中清空；原有日期校验仍在保存时执行。
