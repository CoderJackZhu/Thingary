## 走查中发现并修复的问题

| 问题 | 修复 |
|---|---|
| 财富页 `usePageBar` 位于盘点提前 return 之后，打开盘点时 hooks 数量变化导致整树崩溃 | hooks 移到 return 之前（`src/WealthPage.tsx`） |
| 菜单焦点未进入列表项时（或快速按键），方向键与 Esc 落在触发按钮上无效 | 打开时同步聚焦第一项；触发按钮自身处理 Esc/ArrowDown/Tab |
| 表单关闭后焦点偶尔停在 BODY：React commit 先清空 ref 再跑 cleanup，`dialog.current?.close()` 是空操作，节点被直接移除 | 关闭流程先对活的 dialog 调 `close()`（原生把焦点还给触发者），再卸载；`refocusHeading` 仅在焦点已丢失（菜单跨页场景）时兜底回页面标题 |
| 搜索折叠断点定为 780px，而 800×600 是产品最小窗口，最小尺寸下反而看不到折叠 | 折叠断点提到 900px（1080 默认高窗与 800 最小窗之间）；与 CSS 断点一致 |
