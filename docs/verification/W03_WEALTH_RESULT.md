# W03 财富盘点：删除恢复、备份与原生验收

日期：2026-09-28 · 分支 `feature/wealth-a` · 设计见 [ADR-001 第 17 节](../decisions/001-local-desktop.md#17-a--财富盘点技术设计2026-09-28w01-已实现)

## 1. 本轮实现

- `wealth_trash`：盘点、账户的软删除与恢复，回执复用 `feature_requests`，重复请求为空操作。账户仅在从未出现于任何盘点（含已删除盘点）时可删除，否则返回 `ACCOUNT_HAS_HISTORY` 提示改为停用。恢复盘点时重新检查同日是否已有有效盘点（`SNAPSHOT_DATE_TAKEN`）及账户启用/停用期间是否仍包含该日（`SNAPSHOT_ACCOUNT`）。
- 最近删除新增“财富”筛选；盘点、账户行直接“恢复盘点/恢复账户”，走财富页同一回执协议。盘点更正页与误建账户的编辑框提供两步“移入最近删除”。
- 备份恢复确认增加“账户 N 个 · 盘点 N 次”。
- 修复：从已保存的盘点切换日期时，旧金额会被带到新日期（未经确认即成为新观测，违反 17.4 第 2 条）；现在只有新盘点中手工输入的值随日期切换保留。

## 4. 未覆盖与已知行为

- 已安装的 1.1.6 正式版本身未运行；以同一 schema 14 代码线的隔离构建代替。
