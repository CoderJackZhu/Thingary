## 数据语义与保护

- 标签改名保持 ID；删除更新偏好里的标签引用。售出渠道以名称存储，改名/删除同步更正当前有效售出记录，覆盖最近删除内的物品，撤销售出的历史快照不改。
- 售出更正追加审计与请求记录，不篡改既有审计；更新物品修订号，拒绝旧表单覆盖。
- 删除核对关联数量、选项修订号、资料库 generation；替换目标必须同类型、启用且不是自身。
- 更新、引用改写和回执同事务提交；前端在发送前持久化请求标识，结果未知时阻止再次修改并提供「重新读取并核对」。未提交的编辑输入不持久化为草稿。
- schema 保持 20，无迁移。正式身份 `local.possio.main` 未启动、正式库未读取或写入。
