# T16 购买趋势实现与验证

日期：2026-09-26。起点 `main` = `a51a747ea12f633f29ed70d6e5a1316f34f8cd8e`（含 T15），分支 `codex/t16-trends`，Claude 串行实现与验收；无 schema 变更、无远程。

## 口径与实现

- `Store::purchase_trend(granularity, today)`（`src-tauri/src/insights.rs`）每次读取重算。范围固定为**历史全部**：未删除资产，含已退役与已售出；售出从不回减。粒度按月／按季／按年，范围为「全部」：从最早有日期的购入所在期间连续到当前期间，空期间保留为 0，不跳过。
- **期间边界**：按购入日期所在自然月／季／年归入，期间首尾两天都包含；闰日 2024-02-29 归 2 月，9-30 归 Q3、10-01 归 Q4，12-31 与次年 1-1 分属两年。起止日期由日历计算，不用 30 天近似。
- **未知值**：有日期但金额未知的购入计入件数、不计金额，并在期间和总计中列出未知件数；购入日期未知的物品不归入任何期间，单独报告件数及其中已知金额，不伪造归属。
- **累计**：逐期累加已知购入金额，单调不减。
- **界面**：侧栏「统计」开放。购买趋势卡片说明范围与边界，切换按月／按季／按年；上方为各期间购入金额柱状图，下方为累计购入金额折线图——两张单轴图，不用双纵轴；另有「查看表格」给出每期起止、件数、金额（含未知件数）与累计。颜色使用 T15 已校验的分类色第 1 槽；每期整列可悬停并用原生提示显示精确数值。持有周期与日均成本排行留给 T17，同页追加。
