# U04 心愿完成、时间轴与记录表单修正

日期：2026-09-27。基于 U03 的用户反馈；仅用 `local.possio.u02.acceptance` 虚构资料验收，未打开正式资料库。

## 已落实

- 攒钱达到目标时，最后一笔只计入目标剩余金额，进度显示 100%，自动实现并关闭详情；已实现心愿留在清单。清单设「全部／进行中／已实现」，默认全部；已实现详情不再显示继续攒钱入口。自动实现的心愿在编辑累计金额或目标后不足 100% 时回到进行中。
- 时间轴左侧以一条容器级虚线贯穿月份和事件，节点仍为外圈与中心点。
- 维护和保障表单把说明／备注与添加图片放在同一块，顶部保留关闭和保存，去掉清空和取消。
- 保障、资产和心愿的提醒开关立即更新表单，不再等系统许可返回才可继续输入。请求许可时提示可继续填写；失败时给出打开 macOS 通知设置的入口。后台排程在许可请求未结束时跳过该次同步，许可通过后重新同步。
