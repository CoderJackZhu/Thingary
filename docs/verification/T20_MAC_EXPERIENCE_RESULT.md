# T20 Mac 操作体验实现与验证

日期：2026-09-26。起点 `main` = `dd49c8a`（含 T19），分支 `codex/t20-mac-experience`，Claude 串行实现与验收；无 schema 变更、无远程。范围：AC06/39/40 的键盘、焦点、窗口与外观部分，R07，及 T18 记录留给本阶段的 T12–T17 800×600 与浅色对照。

## 改动

- **⌘, 设置**：原生菜单「物志」新增「设置…」（⌘,），与 ⌘N／⌘F／⌘E 走同一 `asset-action` 事件；前端沿用侧栏「设置」的限制（有草稿／待核对删除恢复时不切换）。
- **800×600 版式缺陷**（原生走查发现，仅改 `src/style.css`）：
  - 心愿清单整页没有左右内边距，卡片与搜索框贴住侧栏（修复前 1080 宽）；改为与总览／时间轴／统计相同的 `0 22px`。
  - 总览四项指标在 ≤900px 变 2×2 时行间无间距、第三格多出竖线；补行距并去掉该竖线。
  - 时间轴类型按钮的内边距被通用 `.segmented button{padding:5px}` 覆盖，「退役 / 售出」与「心愿」挤在一起；提高选择器优先级。
- `tests/mac-shortcuts.test.mjs`：四个快捷键均为原生菜单项、带对应加速键并被页面处理（撤销前端处理时失败）。

## 隔离原生验收

隔离包 `local.possio.t06b.preview`，虚构资料。辅助功能 API 读取菜单、焦点与控件；每次按键前确认 App 在前台且窗口在辅助功能树中可达（期间一次检测到 Claude 在前台，该次按键自动放弃）。窗口尺寸经辅助功能设置为 800×600，截图为窗口 ID 截图。

|---|---|
| 菜单 | 物志：关于、设置… ⌘,、隐藏、退出 ⌘Q；文件：新增物品 ⌘N、关闭窗口 ⌘W；编辑：撤销至全选、搜索物品 ⌘F、编辑资料 ⌘E；窗口：最小化、缩放。 |
| ⌘, | 从总览按下进入设置页。 |
| ⌘F | 从设置页回到全部资产，焦点在「搜索物品」。 |
| ⌘E | 列表选中 iPad Air 4 后打开编辑资料，焦点在名称；Esc 关闭后焦点回到该物品。详情页 ⌘E 同样打开，Esc 后回到按键前的「新增维护」。 |
| ⌘N | 打开新增表单，焦点在名称；空表单 Esc 关闭，焦点回到触发处。 |
| 弹窗期间 | 新增表单打开时按 ⌘, 不切换页面；连续 Tab 35 次焦点始终在表单控件内（到末尾时停在网页区域后循环），不会落到背后列表。 |

| 可访问名称 | 总览、全部资产、心愿、时间轴、统计、素材库、最近删除、设置、详情页：无名称的按钮／复选框／弹出菜单／输入框为 0。 |

## 未验证与边界

- **需要用户操作**：系统外观在运行中实时切换（修改系统设置不由代理执行）、VoiceOver 实际朗读流程、显示器缩放与辅助字号。代码上「跟随系统」由 `prefers-color-scheme` 与窗口主题 `None` 实现，本轮只验证了重启后与当前系统一致。
- 不提供网页缩放（⌘+／⌘-）；「缩放」指窗口最大化与 800×600 最小窗口。
- Dock 图标点击以再次打开 App 触发同一 Reopen 事件替代，未物理点击 Dock。
- 正式签名构建、离线与打包重启归 T21。不宣布 CP3、CP4 或 P0 通过。
