## 未验与观察

- **断网**：未关闭本机网络（属于系统设置，不代为修改）。改为核对 App 进程运行时没有任何网络套接字（`lsof -i` 为 0），并在重开后核对数据；资料全在本地。
- **VoiceOver 与减少动态效果**：未开启系统 VoiceOver，也未改系统“减少动态效果”设置。可访问名称以 AX 树为证据（按钮、标题、年份选择器均有名称）；Q02/Q03 新增样式没有 transition/animation，既有动效在 `prefers-reduced-motion` 下关闭。
- **模块读取失败**：原生构建不含故障注入，局部错误与重试的证据仍来自 Q02 Rust 测试和浏览器样例。
- **800×600 侧栏横向滚动条**：浅深色都出现侧栏底部横向滚动条。Q02/Q03 未改侧栏样式，属既有问题；侧栏为已确认布局，未自行修改，待用户决定。
- **物品详情焦点**：键盘打开物品来源后焦点停在网页区域，没有移到物品标题。属既有物品详情行为，未修改。
- 重开 App 默认进入个人库（退出前在样例中），属既有行为，与本阶段无关。
