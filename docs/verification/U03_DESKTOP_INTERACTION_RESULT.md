# U03 桌面交互与信息密度修正

日期：2026-09-27。用户本轮授权直接修复，并明确中途不再询问常规取舍。

## 本轮规则与实现

- 新增、编辑资产／心愿及维护、保障、退役、售出表单：普通输入仅在当前页面保留；点关闭、取消或退出直接离开，不弹保存草稿或放弃修改确认。保存与关闭放在顶部。
- 仅已提交但结果未知的请求保留原请求回执，供核对是否成功，避免重复金额或重复写入。它不再称为普通草稿。启动时清理旧版未提交草稿，保留未决回执。
- 默认窗口 1360×900；资产表单三栏、心愿表单双栏；紧凑资产详情及摘要。默认表单主要项目同屏展示；小窗口或展开较多可选资料时正文可滚动，顶部操作一直可达。无限增长的历史、附件与长备注不承诺全部无滚动。
- 心愿列表缩为与资产接近的行高，整行及图标点击均进入详情，取消独立预览和查看详情按钮。详情左侧集中进度、快捷金额和攒一笔，右侧资料。
- 心愿不再提供优先级、放弃入口，日常状态只有未实现／已实现。旧历史数据不删除，旧放弃请求仍可核对。
- 选择项使用圆形选中态；分类、渠道等用拖动手柄排序，键盘方向键仍可操作。设置中新建名称与按钮相邻，编辑／移除收进更多菜单，图标与文字居中对齐，不显示已删除引用数。
- 设置移除外观重复入口，宽屏用分类与资料管理双栏。分类未提交输入在离开页面后丢弃。
- 箱子默认图标重新绘制；手机、电脑、平板等排在前面，咖啡机靠后；图标点击立即选用。上传图片按钮和统计排除复选框加大、重新绘制。
- 成本模式改为直接分段切换；时间轴用连续可见虚线连接外圈与实心点，采用桌面同侧对齐，便于扫读。
