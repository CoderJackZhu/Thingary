# R03 周期费用：删除恢复、时间轴与原生验收

日期：2026-09-28 · 分支 `feature/recurring-c1` · 设计见 [ADR-001 第 19 节](../decisions/001-local-desktop.md#19-c1--周期费用技术设计2026-09-28r01-已实现)

## 1. 本轮实现

- `wealth_trash` 增加 `plan` 与 `payment`。删除计划只标记计划本身，其付款随父对象隐藏；恢复付款时若所属计划仍被删除返回 `PARENT_DELETED`，若该期已有新记录返回 `PAYMENT_EXISTS`。
- 最近删除“财富”筛选显示计划行与独立删除的付款行（付款行注明所属计划是否也被删除）；计划与付款编辑框提供两步删除。
- 时间轴“支出”筛选增加已付的周期付款；恢复确认显示周期计划与周期付款数量。
