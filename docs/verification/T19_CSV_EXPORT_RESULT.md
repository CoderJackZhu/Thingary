## 已实现

- `src-tauri/src/csv_export.rs`：手写 RFC 4180 输出，不新增依赖。UTF-8 带 BOM、CRLF 行尾；字段含逗号、引号、换行或首尾空格时加引号并把引号加倍。以 `= + - @`、制表符或回车开头的文本前加 `'`，防止电子表格当作公式；金额与日期列不加前缀。
- 列：档案编号、名称、分类、品牌、型号、购入价（元）、币种（CNY）、购入日期、渠道、状态（使用中／已退役／已售出）、售出日期、售价（元）、备注。范围为全部未删除资产（含已售出），按建档时间与 ID 稳定排序；未知价格／日期／分类／渠道留空，¥0 写 `0.00`；已撤销的售出不导出。
- 原生保存面板泛化为 `possio_pick_save(标题, 按钮, 建议名, 扩展名)`，备份与 CSV 共用；由面板追加扩展名。面板里确认替换后原子写入。命令 `export_csv` 返回文件名、所在文件夹与行数；取消面板不写文件。
- 设置 › 资料管理的 CSV 入口启用，说明范围、编码、未知与零、公式防护，以及不含图片／维护／保障／心愿、不能用于恢复。
