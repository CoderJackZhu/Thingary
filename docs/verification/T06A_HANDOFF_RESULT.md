## 接入契约

- 公共组件与类型名称保持 T06a 契约。父层负责唯一 snapshot、实际校验、写入与回执。
- `onReload` 仅成功读回数据才 resolve；失败必须 reject。重载期间保留旧 snapshot，避免卸载行组件导致草稿丢失。组件显示 loadError 并禁止写入，不把旧数据当最新。
- `onCommand` 的 success 只能在父层设置新 snapshot 后返回；已知失败返回 retry，未知结果返回 reload 或 reject，不能吞掉读取失败然后报成功。
- 名称与图标是独立操作；界面明确提示图标即时保存，名称单独保存。
- `PreviewCatalog`、`applyPreviewCommand`、`previewSnapshot`、`validatePreviewName` 仅为内存验收辅助，不代替 Rust/SQLite 事务、正式约束或真实资产持久化。
