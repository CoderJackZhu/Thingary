## 3. 窄窗口列表跟进

第一次原生截图（`native250/1-assets-800.png`）显示：面板让出宽度后，列表只有名称与金额两列，右侧约四成空白。随后加了 CSS：≤980px 且无选中物品时恢复购入日期、金额与状态列（选中物品后仍回到名称加金额）。浏览器预览核对通过；最终构建的原生核对见第 4 节。

## 4. 最终构建的窄窗口原生核对

最终 2.5.0 构建（含该 CSS）在原生 800×600 下：无选中物品时列表占满主区，显示名称、购入日期、购入金额、状态四列，名称完整（超长名称才省略），没有空面板（`docs/ui/u21/native-assets-800-final.png`）。**通过**。截图均为应用窗口（`screencapture -l`）。
