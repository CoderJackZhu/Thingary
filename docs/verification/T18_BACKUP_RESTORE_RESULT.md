## 实现

存储层（完整一致性快照、清单与散列、写后解包复验、校验失败拒绝、恢复前保护副本、日志化指针切换、数据集代号作废旧请求、旧版本迁移）在 V04/V05 以来已具备；本阶段补齐产品集成：

- **原生面板**：`native/images.m` 新增 `NSSavePanel`（建议名「物志备份-日期时间」，由面板追加 `.possio`）与限定 `.possio` 的 `NSOpenPanel`，与现有选图器相同的主线程桥接。取消面板即返回空，不启动任务（AC34）。
- **命令**：`create_backup`（选择位置 → 串行存储 worker 中生成并复验，编辑请求排队等待快照完成）；`inspect_backup`（把所选文件冻结复制后完整解包校验，返回散列、时间、格式版本及物品／最近删除／心愿／维护／保障／原图数量，当前库不变）；`restore_backup`（只接受检查时的散列与当前代号，走既有保护副本与日志化切换）。`Store::inspect_backup` 按版本读取计数，兼容 schema 1–12。
- **设置 › 资料管理**：四个入口并列说明用途——完整备份、从备份恢复、导出资产表（CSV，入口占位至 T19，明示不能用于恢复）、最近删除。任务状态分为进行中／完成（显示文件名与所在文件夹）／失败（说明当前资料未改变）。恢复为「选择 → 检查摘要 → 确认替换当前资料」两步，并提示保护副本；有编辑中表单或待核对操作时禁止备份与恢复。
- **切换后作废旧工作**：恢复成功后清除本机所有 `possio.*` 草稿与待核对请求（保留外观设置）并重新加载；旧窗口请求已因数据集代号变化被存储层拒绝。提示只统计真正的草稿与待核对键，不把测试构建残留的 `possio.qa.*` 标记计入。

## 剩余边界

- 磁盘不足、拒绝访问与进程中断（AC33）由存储层故障注入测试覆盖，本轮未在原生环境制造磁盘满；损坏档的提示文案为通用「备份无法读取或写入」，可再细化。
- 备份上限沿用验证期的 100 MiB／1023 个文件；超过时明确拒绝，尚未支持大库分卷。
- 恢复前未保存的草稿会作废（提示中写明），不做跨数据集迁移。
- CSV 导出属于 T19；不宣布 CP4 或 P0 通过。
