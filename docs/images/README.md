## 复现入口

在独立开发树运行 `npm run dev -- --port 1439`，打开：

```text
http://127.0.0.1:1439/visual-preview.html?plan-basic=saved&capabilities=real&theme=light
```

夹具使用虚构物品、账户与历史记录；规划另以 10 万元模拟起点、60 岁退休、每月完整预算 4,000 元、预计储蓄 5,000 元展示需求与预测。总览金融净资产与规划模拟起点不是同一金额，不能相加。日期随预览运行日变化；重新拍摄时保持同组图日期一致。

## 更新检查

1. 先核对版本、实际功能与文案，再拍摄；不得打开正式资料库 `local.thingary.main`。
2. 保持同组视口、主题、数据和日期。等待页面切换与主题动画结束，检查截图不是过渡帧；不要拼改截图中的功能、金额或状态。
3. 逐张核对导航、表单、缺项与结果；长页面可滚动展示所需区域，不能裁掉影响理解的假设。
4. 同步 README、使用指南、业务规则、架构和活跃设计的已实现／未实现状态；检查相对链接与图片可读。
5. 运行 `node scripts/offline-guide.mjs <临时输出目录>`，检查离线图片及目录跳转。已经发布的标签与安装包不重写，后续文档随下一版打包。
