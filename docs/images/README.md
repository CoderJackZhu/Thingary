## 更新检查

1. 先核对实际包、源码与引用，不把旧发布包推定为当前工作树；只用隔离身份及虚构资料。
2. 保持同组主题、内容尺寸与资料，等待主题过渡、读取及布局稳定；逐张观察真实截图。
3. 长页面滚动到所需区域，保留影响理解的假设和缺项；截图状态与正文例子必须一致。
4. 更新本清单中的日期、包来源、尺寸及逐图状态；新增图与现有文件名同步到引用文档。
5. 执行 `node scripts/offline-guide.mjs <临时输出目录>`，核对图片及来源清单哈希。已发布标签和安装包不重写，截图随后续版本打包。
