# 收入复盘、历史基准、金额打码与决策报告设计

状态：**范围已批准，待实施、待验收。** 基线：`7eaff7c612e51875cdc9f299ecef2951abfd8f87`。入口见 [整体设计](PLANNING_LIFECYCLE_DESIGN.md)，持久化与统一计算见 [资金与方案](PLANNING_DATA_SCENARIOS_DESIGN.md)，迁入见 [CSV 设计](FINANCIAL_HISTORY_IMPORT_DESIGN.md)。

当前源码已接入第一阶段轻量复盘：盘点后入口、派生清单、最多三条事实观察与现有发生核对。收入覆盖声明、归因、冻结基准及正式报告仍为下文目标规格，未由本阶段交付。

## 1. 收入与复盘的默认顺序

1. 最近完整盘点：日期、金融净资产、与前次的变化。
2. 区间收入：已记录到账、公积金已知缴存及完整程度。
3. 期间的重要发生：已购入/取消/延期安排，以及现有物品和费用来源。
4. 原预测与实际：同一资金范围的可比差额和无法比较的原因。
5. 从现在重算：当前方案的缺口、待确认假设、下一步调整入口。

默认围绕最近相邻完整盘点 `(B0, B1]`；用户可选择其他完整端点。盘点自身仍要求所有应盘点账户填写，规划中的未知不恢复盘点“未变/未知”按钮。

没有方案时前两步独立可用，提供建立计划入口；没有收入时已知资产变化照常显示。缺少原因记录只使原因区降级，不清空资产事实。

## 2. 历史指标的成立条件

### 2.1 默认指标

金融净资产变化 `ΔNW = NW(B1) − NW(B0)`，只说明余额/负债净变化，包含估值、利息、收入、消费和外部资金变化。不能直接命名真实储蓄、投资收益或支出。

如显示规划资金范围的余额变化，明确标出资金范围与两端规则是否一致，不能与金融净资产混为一项。公积金变化独立显示，不通过减缴存把投资增长变成现金储蓄。

区间到账收入显示“已记录收入”。只有用户确认覆盖区间完整，才能称“该区间确认收入”；公积金未知独立标不完整。条数不证明月份完整，奖金不替代另一个月的工资记录。

默认不显示反推消费或储蓄率。旧推导保留兼容读取和必要历史对照，不能继续在新页面作为真实指标或自动作为未来投入。

### 2.2 收入完整性

覆盖声明保存起止日、complete/partial/unknown、确认时间与修订；使用 `(from, to]` 与盘点一致。完整零收入可以通过覆盖声明明确表达，不强制制造零收入行。

收入新增/编辑/删除发生在已确认覆盖内时，声明转为“记录已变化，待复核”；覆盖原声明保留历史，不悄悄继续显示完整。覆盖声明冲突或重叠需合并/分段；删除记录不能改变其他区间的完整性。

未来收入不可当历史事实输入；未来净投入仍在方案内独立确认。

### 2.3 可选归因与未归因变化

区间可补汇总项：投资估值变化、明确外部资金变动、资金范围内外的转移。正负号定义为增加/减少该范围，每项带期间、来源/依据、known/estimated/unknown。

内部转账对全金融净资产为0，但对选定可用资金范围可能有影响。公积金解锁/提取在总资产内部转移，不能同时当外部收入。借款增加现金且增加债务，也不能当工资或净财富收益。

对应同一资金范围可展示：`未归因变化 = 余额变化 − 已核对估值变化 − 已核对外部变动 − 已核对范围转移`。仍叫未归因变化，不自动把残差当消费或工资储蓄；已知但不完整的归因显示缺项。

物品购入、实际付款、首付记录在原因区提供依据，不再扣余额变化，也不加回净投入；归因引用同一来源去重。用户选择不计入历史典型区间只改变统计集合，不改变事实。

### 2.4 历史典型值

默认趋势展示真实日期下的净资产变化；月均变化按区间天数标准化，标“含估值变化”。汇总优先按区间天数加权，展示样本区间数、覆盖天数、范围与缺项，不假定短区间等于整月。

原中位数可在展开的历史参考保留，清楚列每区间一票及样本少状态，不称准确常态投入。历史参考不会自动更新方案假设，未来净投入设置始终要用户确认。

通用基础优先、未来投入选填及职业扩展后置的方向已确认；目标先看需求的规则见[总设计 §4.4](PLANNING_LIFECYCLE_DESIGN.md#44-积累能力资金承受能力与首次引导)与[数据规格 §4.4](PLANNING_DATA_SCENARIOS_DESIGN.md#44-积累条件压力条件与时间线适配)，**第一批通用基础已集成，完整报告入口仍待后续交付**。未来投入旁可并列历史参考：已记录收入标覆盖情况，净资产变化标含估值变化；没有完整支出覆盖不能生成「实际结余」。若以后有已核验净收支来源，可带来源并列展示，仍不自动填入或采用。复盘不因新收入、新盘点或职业标签改写未来假设。

## 3. 计划发生核对

完整盘点保存后提供非强制“复核计划”入口；待核对包括预计日已过、已有发生来源未关联、付款未确认被起点吸收、贷款/费用来源已变化。

每项只有明确动作：确认实际发生、关联已有事实、延期、取消、暂不处理。暂不处理保留缺项，不能默认确认。实际发生状态与付款分项沿 [数据规格](PLANNING_DATA_SCENARIOS_DESIGN.md#6-计划发生与盘点接续) 保存，不另建复盘金额账。

复盘更正不回写真实余额、不自动创建物品、不自动结束订阅。已发生事件只去掉被新盘点反映的历史付款，剩余贷款与持续费用继续预测。

## 4. 冻结历史基准

### 4.1 生成时机

采用方案时自动建立一次基准；用户也可“保留当前预测”。普通编辑保存创建方案修订但不每次生成基准。采用的写入与基准同一事务，重复请求返回原对象。

未知关键输入可保存不完整基准，只冻结当时可计算的指标及缺项。不能用0补齐预测曲线；报告明确不完整。

### 4.2 必须冻结什么

| 内容 | 保存要求 |
|---|---|
| 身份 | baseline_id、scenario_id/修订、名称、生成日期、generation |
| 事实起点 | snapshot ID/修订/日期、纳入账户身份/金额/方向、已确认发生与债务起点、资金规则 |
| 假设 | 已启用的净投入或完整阶段、目标、预算、费用包含、退休收入、受限缴存/解锁、预测时段、金额基准；选填值未知仍保留状态 |
| 条件种类 | 按实际启用能力记录原规划/月投入/当前收支；后续比较再纳入偏低/偏高/压力、原输入单位和分配规则；适用范围、衔接及未覆盖项不能遗漏 |
| 参数 | 采用参数的值/出处/日期/修订、模型版本、计算精度；高级模拟记录种子/样本数 |
| 输出 | 主结论、目标结果、月度可用/受限资金及剩余债务、缺口节点、关键未覆盖项 |

保存必要字段而不复制整份资料库、图片或原始导入文件。冻结输出可长期只读查看，不依赖未来安装包仍包含旧计算引擎；算法更新不能用新版重算替换旧结果。

可比差额需要的原始值保留精度，显示舍入单独处理。高级大样本不存每条随机路径，保存结果摘要、版本与种子；不能宣称旧引擎不可得时可以精确重现全部路径。

### 4.3 更正、删除与版本

源盘点更正不改变原基准，显示“来源后来更正”，实际曲线使用更正后事实并说明。用户可从更正后建立新基准。修订事实不擦掉当时的判断背景。

软删除源保留基准及来源失效说明；永久删除依 [数据规格](PLANNING_DATA_SCENARIOS_DESIGN.md#9-读取写入恢复与删除) 解除依赖与删除相关原始快照。基准属于本地用户资料，随完整备份恢复，不上传服务。

算法变化时实际对照仍使用旧冻结预测；最新未来显示新版本及关键口径变化，不以新旧数值差直接归因用户行为。

## 5. 实际对照与最新重算

### 5.1 两个明确视角

“当时的预测”：起点与假设固定，未来预测不移动。

“从现在起”：使用最新完整盘点与当前方案、重新确认的发生状态和来源，重算未来。

同屏可切换，标签与日期始终显示；禁止只有一条随余额更新却叫原计划的曲线。

### 5.2 可比性

真实点仅来自完整盘点；不插值造实际数据。比较基准所纳入的资金范围，采用冻结的账户身份与比例；缺账户/类型变化/资金解锁状态未确认时标不可完全比较，不从当前总净资产减基准现金结果。

债务、受限资金和可用资金分列必要差额。旧总额参考可叠加为参考线但不参与账户范围的现金对照。展示不同金额基准时先转换到同一基准并注明通胀假设；名义与购买力不能直接相减。

盘点在月中，月份级预测可取所在月末或相应部分期模型点，必须标“与该期预计对照”，不伪装为精确当天预测。精确到日的实际事实仍保留原日期。

### 5.3 偏差解释

显示“实际比该期预计高/低 X”，以及可确认的变化：新增计划、投入假设改变、已记录外部变动、已知估值归因、实际发生日期/金额差异。其余称未解释偏差。

多个原因之间不自动分配贡献率；物品成本不等于偏差金额；仅资产低于曲线不能判定储蓄执行失败。可展示重新采用同一条件后的计算差，但应标“情景变化影响”，不当作事实因果。

当前方案修改后显示距最近基准改变哪些条件，用户可采用/保留新预测，旧基准继续可查。一次月度复盘不要求重填全部假设。

## 6. 集中的依据核对

在结果详情提供一个“计算依据”面板，不新增主导航。按影响程度排序：资金起点与日期、可用性、未来净投入、实际发生待核对、费用包含、退休收入与缴费、收益/通胀/预测时段、未建模项。

预算依据保留既有必需/灵活标记，结果注明完整预算或仅必需开销的检查范围；只覆盖最低保障不能称原目标全部达成。普通金额目标才可按确定目标金额显示 25/50/75/100% 里程碑；动态退休所需资金、安全底线和期间现金压力不强行统一为这个百分比，也不新增一组主页面图表。

每项显示已确认/估算/未知/本次排除、来源与确认日，提供拥有方入口。关键未知影响主结论时出现在结果旁；不相关的养老金资料不能阻塞普通目标。

条件范围不是概率区间。反求报告说明只调整哪个积累变量、哪些日期/预算保持固定；未来投入未知时保存需求结果及未知状态，不把需求当能力。当前低收入恢复未知时，长期条件试算与当前承受能力分开展示，不把两条独立轨迹拼成完整退休路径。职业参考仅在明确采用后记录来源/模板版本及用户覆盖值；打开模块不修改计划或基准。旧基准保留其原模型结果，不因采用新输入模型重算覆盖。现有报告展示组件 v1 先用结构化 assumptions/missing 表达这些依据；字段不足则由独立集成任务版本化扩展，不在本次设计工作修改既有契约或接入导出入口。

不把所有缺资料变成红色错误。读取失败、缺事实、用户明确排除、假设范围不同是不同状态。

需求说明分别列所设收益与两段收益各降低 2 个百分点的条件、各自所需月投入及适用期间；不用「中位路径」或「五成把握」解释确定性反求。高级模拟比例须紧邻完整预算/必需预算范围、预测终点和余额判据，不能独立大字显示为个人真实成功率。终点恰好为零且满足有限期预算时标无余量；判据与缺口定义以[数据规格 §4.4](PLANNING_DATA_SCENARIOS_DESIGN.md#44-积累条件压力条件与时间线适配)为准。旧报告和冻结基准保留其原模型版本及解释，不被新规则重写。

## 7. 金额打码

总览提供统一“隐藏金额”，快捷入口复用当前控件；偏好本机保存并跨相关页面生效，库切换保持隐私偏好但不带资料。无需密码，不宣称应用锁或加密。

覆盖金融余额/负债/收入、物品价格成本、费用、目标金额、报告预览、图表轴/提示、表格、小计及辅助说明。由金额推导的进度比例也隐藏；时间和一般状态可保留。隐藏曲线及带金额的辅助展示，不能只模糊大数字。

使用替代文本，不只 CSS 模糊；DOM 文本/可访问名称/提示/title/复制内容不包含被隐藏金额。计算内存仍有原始资料，打码不抵抗本机文件读取。

编辑金额时采用明确的临时显示：用户打开输入表单或点“显示此字段”后可编辑，关闭回到全局打码；不因打开详情自动解除全局状态。键盘与读屏能知道金额已隐藏。

CSV/完整备份本质携带真实资料，不自动产生无法恢复的打码文件。打码开启时导出动作清楚标“导出真实资料”；用户明确选择该动作即授权本次导出，不另套多轮确认。报告则支持独立隐私版本。

## 8. 可读决策报告

### 8.1 来源与入口

当前方案更多菜单、基准详情、两方案比较提供“生成报告”。先选择当前结果/某份基准/两份比较，再预览、打印或保存 PDF。报告使用一个固定读取/冻结上下文，不拼不同批次。

当前报告生成时形成独立只读报告快照（可只在导出过程内存持有）；后续修改不能导致正文和图表不一致。基准报告始终使用冻结输出，报告日期与基准日期分开。

### 8.2 固定内容

1. 标题、方案/基准名称、起点日、生成日、金额基准和模型版本。
2. 一句话结论、主要目标结果、缺口/底线节点。
3. 起点资金范围、受限资金与债务；真实值和假设标签。
4. 已纳入安排、阶段、净投入、预算、退休收入、收益/通胀。
5. 一张必要资金趋势及简洁目标/方案差异表。
6. 计算依据、关键未知和未覆盖项。
7. 基准实际对照（有可比实际记录时），区分旧预测与最新未来。

先给简洁摘要，再按内容扩展，不为固定页数填图。不附原始图片、序列号、账号凭据、完整收入明细或完整账户流水。报告不是可恢复备份。

### 8.3 隐私与文件

默认隐藏具体账户名称和敏感来源名称，用账户1/2等稳定局部别名；是否显示金额继承当前打码状态，预览可明确选择完整/隐私报告。隐私报告隐藏金额及可反推出金额的比例、轴/提示，保留一般结论、日期和缺项。

导出仅传递所选报告的已脱敏载荷给打印/PDF路径，不把真实金额藏在不可见 HTML、图层、附件或 PDF 元数据。文件名不含余额、账号或敏感方案名；用户选择本地保存位置，不自动上传或写云盘。

首版采用同一可打印排版生成 PDF；不要求用户安装开发依赖或注册账号。A4/常见纸张、长表分页、中文字体、表头重复和页码可读，图表不裁切。取消导出不改变方案/基准。保存失败可重试同一快照，不能报告成功。
