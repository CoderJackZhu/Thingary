## 第二轮：Open Design 生成（2026-10-01）

用 Open Design 的 `brandkit` 与 `creative-director` 技能重新发散：16 个概念、淘汰 8 个，精修 8 个。文件在 `od-round1/`：`board.html` 是它生成的概念板（含评分、品牌色提案、推荐排序，浏览器直接打开），`icons/` 是 8 个单独的 SVG（纯路径，无 `<text>`，不需要转曲）。

| 稿 | 概念 | 我的看法（看过渲染图后） |
|---|---|---|
| 01 物谱线 | 五线谱，五个大小不一的点是不同年份的物品 | 故事最好，但视觉像「滑块／设置」或横线纸，16 px 糊成一片 |
| 02 牛角托物 | 「物」本义是牛，一对牛角托着一件小物 | **形最有力、最耐缩、最独特**；橙红方块像鼻环，且「牛」容易联想到牛市／Bull 类品牌，需要重画托物的位置 |
| 03 开格 | 九宫格里一格打开，镂出罐子 | 通用，像 bento／启动台 |
| 04 物的家谱 | 竖向时间线加分叉节点 | 与 Git 分支图标几乎一样，淘汰 |
| 05 牛＋包 | 「牛」＋「勹」抱着一点，抽象出「物」的骨架 | 最中文、有趣，但看起来像一个具体的汉字（接近「钊」），读起来怪 |
| 06 T 架 | 架子搭成 T，上面放几件几何物品 | 干净但像积木玩具，只服务英文名 |
| 07 刻度吊牌 | 打孔价签，边缘刻度是持有天数 | 好看、有物品感；16 px 只剩一块斜牌，略「购物」 |
| 08 角谱 | 五线弯成牛角 | 复杂，像磁铁或 Wi-Fi，不适合当图标 |

品牌色提案（靛墨 `#2c2a7a`、朱砂 `#c8472b` 点缀、宣纸 `#f4ecdc`）合理：墨与朱砂对应「谱」的两件工具，比现在偏艳的靛紫渐变更稳。

**结论：** 没有一版明显达到「就是它」。方向上最值得继续的是 02（牛角托物）；它之后的迭代应解决「鼻环」和「牛市」联想。

## 第三轮前的第二轮：围绕 1、2、3 再迭代（2026-10-01）

在第一轮选出的三个方向上各出 3 个变体，文件在 `od-round2/`（`board.html` 概念板、`icons/` 里 9 个 SVG，纯路径无字体）。Open Design 在写到「总排序」那一段时遇到会话额度上限，概念板里这一段只有「TBD」，下面的评价是我看过渲染图后写的。

| 稿 | 概念 | 我的看法 |
|---|---|---|
| 1A 粗谱线＋双小节线 | 4 条粗线加小节线，点落在线上 | 仍像「滑块／设置」面板，淘汰 |
| 1B 带符干音符点 | 谱表上的音符 | 一眼是谱，但就是音乐 App 的图标，撞车，淘汰 |
| 1C 谱表即搁板 | 立柱＋搁板，板上放几件物品 | 清楚读成「放东西的架子」，靛墨＋朱砂很稳；但「谱」的联想没了 |
| 2A 牛角摇篮 | 圆润的牛角弧捧着朱砂圆球 | 像一张笑脸＋红鼻子，牛的出处要解释，淘汰 |
| 2B 新月负形 | 方块里镂出新月，悬一个点 | 像人形或月相 App，淘汰 |
| 2C 留白线描 U | 宣纸底上一道墨弧加一个朱砂点 | 像磁铁或括号脸，淘汰 |
| **3A 田字格·茶杯** | 练字的田字格，格中放一只茶杯，杯上一点朱砂 | **最好**：「格物」落在中文用户熟悉的田字格上，故事具体、辨识度高、32 px 仍清楚。隐患：茶杯会让人猜是茶或咖啡 App |
| 3B 档案抽屉·相机 | 大小不一的格子，一格拉开露出相机 | 复杂，小尺寸成一堆灰块，淘汰 |
| **3C 朱砂印格·收音机** | 宣纸上歪着盖一方朱砂田字格，格中是收音机 | **最有手感**；隐患：收音机会让人猜是电台 App，且朱砂用得多 |

**结论：** 三个方向里只有「格」（田字格）站得住；「牛角」两轮都没救回来，「谱」要么撞音乐 App、要么退化成搁板。

**建议的下一轮（只做田字格）：**
1. 格中放「中性」的物，而不是具体的某种物品：一个圆角方块或一个抽象的器物轮廓，避免被猜成茶、电台等某类 App。
2. 田字格里直接写一个「物」字：练字的田字格加上这个字，最贴「物谱」。需要用开源字体（如思源黑体，SIL OFL）取字形轮廓，不能用系统字体。
3. 沿用靛墨底、宣纸、朱砂的配色，朱砂只留格线或一个点。

## 选定方向：Open Design 第一轮 01「物谱线」（五线谱，2026-10-01）

用户选定第一轮的第 01 个（靛紫渐变五线谱），并要求检查是否过于拥挤。文件在 `chosen/`，`chosen/compare.html` 把原版与改版并排放在一起，含 128／64／32／16 px 与像素放大。

**拥挤的来源（1024 画布单位量得）：**

| | 谱线行距／线宽 | 线间空隙 | 大点的镂空环咬进相邻谱线 | 点与点镂空环的最小间隔 | 16 px 时的线缝 |
|---|---|---|---|---|---|
| 原版 | 86 ／ 30 | 56 | **5**（毛边） | 36 | 0.88 px |
| `staff-relaxed-5.svg` | 104 ／ 32 | 72 | 0 | 45 | 1.12 px |
| `staff-small-3.svg` | 120 ／ 40（3 线） | 80 | 0 | 78 | 1.25 px |

- `staff-relaxed-5.svg`：放松的五线主图。行距 86→104，最大点半径 60→54，镂空环 16→14，横向收进 2 px，大点不再咬线，点与点间距更匀。
- `staff-small-3.svg`：小尺寸专用的三线版（≤64 px 用）。16 px 下五条线无论如何都会糊，所以小尺寸应该换成更粗更稀的三线版。macOS 的 `.icns` 允许每个尺寸放不同的图，主图 128 px 以上用五线版，16／32／64 px 用三线版。
- `staff-spaces.svg`：点落在谱线之间的空档里。读得更像乐谱，但点小、大小对比弱，更像「横线纸上的点」，辨识度和个性比点在线上差。

**仍存在的问题（已向用户说明）：** 点落在线上的版本无论怎么放松，整体仍像「滑块／均衡器」（线是轨道，点是旋钮）；放松只解决了拥挤，没有解决这一点。

**尚未做：** 把选定版接入应用（生成带分尺寸图稿的 `icon.icns`、更新 `tauri.conf.json` 的图标配置、重新构建安装）；侧栏小标志的单色版。

**已接入应用（2.3.5）：** 用户选定第 1 条路（放松五线做主图，小尺寸用三线版，接受它像滑块这一点）。`icon.icns` 由 `chosen/` 里的两个 SVG 经 Chrome 无头渲染成 1024 px 透明 PNG，再用 `sips` 缩到各尺寸、`iconutil` 打包；`tauri.conf.json` 的 `bundle.icon` 改为 `icons/icon.icns` 加 `icons/icon.png`。隔离原生包核对：「关于物谱」面板显示新图标，侧栏品牌小标志为新图形。
