# 名称与应用图标

中文名为「物谱」，英文名为 Thingary。应用图标采用谱线与记录点的组合；大尺寸使用五线版，小尺寸和侧栏使用三线方形版。

## 正式资源

| 资源 | 用途 |
|---|---|
| [staff-relaxed-5.svg](chosen/staff-relaxed-5.svg) | 大尺寸五线图稿 |
| [staff-small-3sq.svg](chosen/staff-small-3sq.svg) | 小尺寸与侧栏的三线方形图稿 |
| `src-tauri/icons/icon.png`、`icon.icns` | 随 macOS 应用提供的打包图标 |
| `src/LogoMark.tsx` | 界面内的单色标志 |
