# 品牌与图标

## 现状

应用图标目前仍是占位图（`src-tauri/icons/icon.png`，三条蓝色横线）。正式 logo 尚未选定。

## Logo 草稿（2026-10-01，待选）

`drafts/` 里是 6 个概念稿，均为 1024×1024 的 macOS 圆角方块图标 SVG；`drafts/sheet.html` 把它们并排放在一起，含 128／64／32／16 px 缩小测试与深色底、名称组合效果，用浏览器直接打开。

| 稿 | 想法 | 备注 |
|---|---|---|
| 1 物字印 | 深墨底白色「物」，右上一个时间点 | 中文优先；候选名都以「物」开头，改名不用重做 |
| 2 年轮方块 | 立方体是一件物品，外圈断开的年轮是持有的时间 | 小尺寸下年轮变淡 |
| 3 箱钟 | 牛皮纸箱，顶面是钟面 | 呼应应用里默认的封箱纸箱图标 |
| 4 红印 | 朱红底、白色印框与「物」 | 取「志／谱」的典籍印章意象 |
| 5 叠卡 | 三张档案卡叠起，最前一张是一件物品的记录 | 偏通用，小尺寸辨识度一般 |
| 6 递减曲线 | 日均成本随持有时间下降，终点是那件物品 | 偏数据，辨识度高，物品感弱 |

含「物」字的稿（1、4）用的是 `<text>` 和系统字体，**正式使用前必须用开源字体（如思源黑体，SIL OFL）转成轮廓**，不能嵌入 PingFang 的字形。选定后再生成 1024 px 的 `icon.png` 与 `.icns` 并替换占位图。

## 第二轮：Open Design 生成（2026-10-01）

用 Open Design 的 `brandkit` 与 `creative-director` 技能重新发散：16 个概念、淘汰 8 个，精修 8 个。文件在 `od-round1/`：`board.html` 是它生成的概念板（含评分、品牌色提案、推荐排序，浏览器直接打开），`icons/` 是 8 个单独的 SVG（纯路径，无 `<text>`，不需要转曲）。

| 稿 | 概念 | 我的看法（看过渲染图后） |
|---|---|---|
| 01 物谱线 | 五线谱，五个大小不一的点是不同年份的物品 | 故事最好，但视觉像「滑块／设置」或横线纸，16 px 糊成一片 |
| 02 牛角托物 | 「物」本义是牛，一对牛角托着一件小物 | **形最有力、最耐缩、最独特**；橙红方块像鼻环，且「牛」容易联想到牛市／Bull 类品牌，需要重画托物的位置 |
| 03 开格 | 九宫格里一格打开，镂出罐子 | 通用，像 bento／启动台 |
| 04 物的家谱 | 竖向时间线加分叉节点 | 与 Git 分支图标几乎一样，淘汰 |
| 05 牛＋包 | 「牛」＋「勹」抱着一点，抽象出「物」的骨架 | 最中文、有趣，但看起来像一个具体的汉字（接近「钊」），读起来怪 |
| 06 T 架 | 架子搭成 T，上面放几件几何物品 | 干净但像积木玩具，只服务英文名 |
| 07 刻度吊牌 | 打孔价签，边缘刻度是持有天数 | 好看、有物品感；16 px 只剩一块斜牌，略「购物」 |
| 08 角谱 | 五线弯成牛角 | 复杂，像磁铁或 Wi-Fi，不适合当图标 |

品牌色提案（靛墨 `#2c2a7a`、朱砂 `#c8472b` 点缀、宣纸 `#f4ecdc`）合理：墨与朱砂对应「谱」的两件工具，比现在偏艳的靛紫渐变更稳。

**结论：** 没有一版明显达到「就是它」。方向上最值得继续的是 02（牛角托物）；它之后的迭代应解决「鼻环」和「牛市」联想。
