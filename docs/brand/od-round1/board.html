物谱 · Thingary
图标概念探索

16 个概念发散(SCAMPER / 二元联想 / 同构类比),自评淘汰,精修 8 个。每个图标均为 1024 viewBox 纯矢量(path / rect / circle / polygon),无 <text>、无字体;单独的 SVG 在 icons/。下方「名称组合」里的文字是网页字体,仅作排版示意。

被淘汰的 8 个方法理由
环与点轨道种子 8与「年轮」同构、也像日食/活动环,已被否掉的方向再包装。
t+h 连字Thingary 字母字母图标是最通用的做法,且丢掉了中文。

留下的 8 个见下;评分(10 分制)是我的主观判断:独特 = 不像其他 App;小尺寸 = 16/32 px 可辨;故事 = 与「物的志/谱」绑定的深度。

01物谱线

同构类比(谱=乐谱) · 主题:靛紫渐变

五条谱线是「谱」,五个大小不一的点是不同年份落在线上的物品;左侧小节线说明这是一份「读得下去」的记录。点有一个暖色——「现在还在用的那件」。

不足 16 px 时五线会糊成灰带,靠点的大小才能认出;细线只能做得很粗,显得不够「乐谱」。

02牛角托物

词源 + SCAMPER·Substitute · 主题:靛墨 + 朱砂(提案)

「物」本义是牛:一对粗壮的牛角,下方托着一件小物(方块)。只有两个形,16 px 依然清楚,是最稳的侧栏小标志。

不足 橙红方块在牛头下像「鼻环」,有人会读成牛头像而非「物」;汉字典故需要一句话解释。

品牌色提案

靛墨 #2c2a7a
主色。白字对比约 12:1,16 px 下底板足够沉,不糊。
朱砂 #c8472b
只当点缀:每个图标至多一个暖点。
宣纸 #f4ecdc
浅色底板与文稿类界面。

理由:墨与朱砂正是「谱」的两件工具(落墨、钤印),一冷一暖,语义和「安静、可信、长期」吻合;靛墨是现有默认靛紫的收敛版,不用重新教育用户,也避开 #bf5af2 那一端偏艳、像别家的紫。紫渐变保留为主题之一即可。

推荐排序

01#1 五线谱唯一把「谱」与「物」同时讲清、且没有任何一个已有 App 用过的故事。风险只在小尺寸——所以粗线、少点、去装饰。

02#2 牛角托物最稳最耐缩,词源有底蕴;缺点是图形自己不讲故事。

03#6 T 架几何干净、16 px 可辨,但只服务英文名。

04#5 牛 + 包最「中文」,但离被否的第④版最近,需要先验证用户是否接受。

05#8 角谱想法最密,适合做大尺寸品牌插画,不适合直接当图标。

06#7 刻度吊牌叙事贴切(持有天数),小尺寸弱。

07#4 物的家谱像 git 图,联想偏开发者。

08#3 开格最安全也最普通。

App 图标 + 侧栏小标志,二选一的话:首选 #1 五线谱,侧栏用去掉底板的单色版(上方「名称组合」右侧 20 px 即是)。若你实测 20 px 线条仍发虚,就把侧栏版减为 3 线 + 3 点;图标本体不变。#2 牛角是备选,它在侧栏表现最好,代价是故事弱一档。

注:macOS 圆角方块为 824×824 近似 squircle(n=5),四周留 100;阴影为 SVG 滤镜,导出 .icns 时可去掉。
