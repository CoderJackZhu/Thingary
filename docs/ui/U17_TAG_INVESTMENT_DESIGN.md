# U17 · 标签投入分析界面设计

日期：2026-09-30。状态：设计细化，未实现、未做视觉或原生验收。本文件只维护布局、交互、状态和对照要求；业务与验收唯一依据为[产品设计 D23](../PRODUCT_DESIGN.md#u17-product)，进度唯一见[实施计划 U17](../IMPLEMENTATION_PLAN.md#u17)。

## 1. 入口与页面结构

沿用 [U16 界面规范](U16_DESIGN_SPEC.md)的 tokens、格式、表格、指标行、按钮与主题形态。复用物品区域的子视图，不新增侧栏项或替换统计页。选中具体标签后，在物品列表筛选区显示「查看投入分析」，不依赖搜索结果数量或选中数量；空标签也可进入。已有停用标签在筛选器保留并注明状态，无标签/全部标签无此入口。

文字线框（布局契约，不作为已验证视觉稿）：

```text
物品 › 标签投入 › 摄影                       搜索标签内物品
摄影  4 件                    [历史全部 | 当前持有]  ⓘ
[累计投入 ¥36,000] [售出回收 ¥5,000] [净投入 ¥31,000]
购入 ¥35,000 · 维护 ¥1,000          使用中 2 · 退役 1 · 已售出 1
物品投入明细                         占标签范围内全部投入
物品 / 状态       购入       维护      累计投入       占比
镜头             15,000         0        15,000       41.7% ━━━
机身             12,000     1,000        13,000       36.1% ━━
旧机身            5,000         0         5,000       13.9% ━
配件              3,000         0         3,000        8.3% ━
```

- 指标行三格；购入/维护及生命周期数量作为紧凑明细行，不再加大卡片。未知提示位于指标与列表之间，说明购入未知件数、维护未知条数和排除件数；不能只藏在 ⓘ。缺失时标题使用产品规则的“已知”前缀。
- 不加饼图或大趋势图。占比列用数字加小横条；标签内全组不完整或分母零时不画条，显示规则对应说明。长名称截断但完整名称可通过可访问文本和悬停查看。
- 排行固定为产品规则的投入降序；首版不提供多个排序或分类钻取，点击物品打开原档案。表格中名称是可聚焦入口，点击不产生业务写入。
- 分页或分段渲染须显示“已显示 n / 共 N 件”；读取完整集合后再做渲染分段，不能将当前片段当作全量汇总。首段 100 件，每次“加载更多”再显示 100 件；先搜索全部数据再分段，规则见 ADR-001 第 25.5 节。

## 2. 搜索、导航与快捷键

- 从列表保存来源上下文（侧栏状态、查询、排序、分页、滚动、焦点），进入分析仅携带标签 ID。源列表其他筛选不继承到分析；分析范围每次从列表新进入默认历史全部。
- 顶栏只注册“搜索标签内物品”，⌘F 聚焦本页搜索；匹配名称、品牌、型号、分类、备注和序列号，沿用既有物品匹配习惯。筛选条保持可见。无新增主操作，⌘N 在本页不动作，原生菜单状态同步；⌘A 在搜索输入里仅选文字，不触发来源列表批量选择。
- 面包屑“物品”返回来源列表并恢复上下文；“标签投入”在物品详情返回当前分析。普通页面 Esc 按既有导航层级：先关闭弹出菜单/模态，再从详情回分析、从分析回来源列表。详情编辑沿用原规则，不增加退出确认或草稿。
- 从分析打开档案后，详情原有编辑、维护、售出等功能继续使用既有入口；返回后重查数据。改标签/删除导致物品不再属于集合时移出该行并提示，焦点回到明细标题；仍在集合时恢复到原入口。不得为打开详情修改标签或清除搜索。
- 切库、恢复、重置使旧上下文失效：退出分析回物品列表，清空标签范围和本页搜索；晚到的响应与错误均忽略。重新启动不自动回到分析、不持久化分析条件。

## 3. 状态与适配

| 状态 | 页面处理 |
|---|---|
| 加载中或换标签/范围 | 占位与读取提示，不把旧范围金额配上新标题，不显示零 |
| 无物品 | “这个标签下还没有物品”；返回物品列表，不新增独立录入流程 |
| 当前持有为空 | “这个标签下没有当前持有的物品”；可切历史全部 |
| 全部排除 | “N 件物品均设置了不计入统计”；显示排除件数与返回列表入口 |
| 金额缺失 | 已知指标、待补录原因、禁用比例；点物品回档案补录 |
| 全部明确零投入 | 显示 ¥0，说明无正金额投入，比例为 — |
| 搜索无结果 | 保留汇总，仅列表显示无匹配结果及“清除搜索” |
| 失败/溢出 | 原因及重试，不展示部分成功的汇总；保留标签与范围 |
| 标签或物品失效 | 显式提示与返回，不跳同名记录 |

常规对照建议 1280×800；窄窗使用 800×600。窄窗指标可换行，明细改紧凑行或折行，仍显示累计投入、占比、状态和未知提示，购入/维护可归入行内次级信息；不能出现整页横向溢出或把未知提示裁掉。三主题及浅/深沿用现行色彩与形态，不引入新 SVG 图标或图表依赖。

## 4. 设计与实现出口

U17a 出同尺寸虚构数据视觉稿，与现行 U16 物品页面框架并排确认一致性；U17c 实现后再以同样数据、窗口和主题逐项对照，文字线框不代替截图证据。B/C/D × 浅/深均覆盖正常状态与窄窗；空、缺失、搜索无结果、失败至少覆盖默认主题浅/深，其他主题抽查状态对比度。键盘检查覆盖 Tab、Enter、⌘F、⌘N、⌘A、Esc、详情返回焦点与模态守卫；隔离原生验收必须实际执行，浏览器只能证明渲染和模拟交互。

所有证据在实施后归入 `docs/verification/U17_TAG_INVESTMENT_RESULT.md`（尚未创建）；按 U17-AC 编号记录实测结果、截图、未测项及残余限制，不提前填写通过。

## 5. zcode 交互实现检查表

| 动作 | 保留/重置行为 | 焦点与展示 |
|---|---|---|
| 从列表进入 | 保存完整来源；历史全部、空分析搜索、首段 100 | 焦点到分析标题；读屏可知标签名 |
| 搜索 | 汇总/分母不变；重置首段与明细滚动 | 焦点留输入；“找到 N 件”与页头纳入数区分 |
| 切历史/当前 | 保留分析搜索；重置首段与明细滚动；请求换票据 | 焦点留范围按钮；新范围加载时不摆旧数 |
| 打开物品 | 保存分析范围/搜索/显示条数/滚动和物品 ID；原列表上下文不覆盖 | 详情标题接焦点，使用原档案布局 |
| 从详情返回 | 重查已提交事实；恢复分析条件和显示条数，已移出物品不强塞回来 | 原物品入口仍存在则恢复，否则焦点到明细标题 |
| 从分析返回列表 | 原来源状态/查询/排序/分页/滚动不变，数据按最新事实刷新 | 恢复“查看投入分析”按钮；标签已失效时退到列表标题 |
| 点击其他侧栏页 | 正常导航退出当前链，不强迫留在分析 | 卸载本页动作；再次从列表进入按首次进入处理 |
| 切库/恢复/重置 | 清空两层返回上下文、分析搜索与分段 | 回到新库物品列表，旧名字/金额/错误不闪回 |

详情面包屑可采用「物品 › 摄影投入 › 物品名」：第一层回来源列表，中间层回分析，当前层不点击；具体文字在视觉稿统一，但必须能到达两级来源。窄窗即使面包屑按 U16 隐藏，也要提供带可访问名称的返回按钮：详情回分析、分析回列表；不依赖用户知道 Esc，不给普通表单增加退出确认。

不完整状态按原因显式展示，不只改颜色。只有“已知”前缀不足以表达存在多少缺失，必须有数量说明。全组缺失导致比例隐藏时，不出现空的灰色 100% 条。明细无匹配、空标签、全排除、加载失败按第 3 节区分；底部“已显示 n / 共 N”中的 N 为搜索匹配数，指标行及占比分母仍为全部纳入集合。

U17a 视觉稿和 U17c 实现截图均放在 `docs/ui/tag-investment/`，以 `index.html` 索引主题、模式、窗口尺寸、场景、基准版本、设计/实现文件及差异说明。文件名可采用 `design-b-light-normal-1280x800.png` / `actual-b-light-normal-1280x800.png`，其余组合一致。目录在实际生成证据时创建，不提前放空占位图片。
