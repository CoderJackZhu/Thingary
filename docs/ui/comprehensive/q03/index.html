  • 虚拟资产事件 → 打开对应档案编辑框（example-notes.cn）；关联计划的虚拟事件金额为空，费用只经付款。

  • 返回恢复：时间轴筛选（领域）与滚动位置在来源往返后恢复；键盘 Tab/Enter 可打开来源。
