## 4. 原生验收：阻塞与剩余清单

### 4.1 阻塞

本会话进程的 `AXIsProcessTrusted()` 与屏幕录制预检均为 `false`：无法读取窗口、驱动控件或截取窗口画面；`System Events` 调用会超时。按 [T20](verification/T20_MAC_EXPERIENCE_RESULT.md) 的约定，代理不修改系统设置，也不绕过授权。**要继续原生验收，需要你在系统设置中给运行 Claude Code 的宿主程序重新授予「辅助功能」和「屏幕录制」**（2026-09-26 的授权对当前会话不再生效），并在验收期间不要使用键盘鼠标。

### 4.4 需要其他机器

macOS 14 与 Intel Mac 没有实测，当前只在 Apple Silicon、macOS 27 上验证。对外发布时应写明「仅在 Apple Silicon 验证」，不承诺其他环境。

### 4.5 不建议再投入

故障注入类（读取失败、回执丢失）已由 Rust 测试覆盖；旧 schema 备份恢复由迁移测试覆盖；GB 级大资料库的备份耗时属于压力测试，D20 已写明上限，发布不依赖它。
