# 业务规则与计算口径

本文维护当前有效的业务约束，供使用者理解数字、贡献者判断改动。操作步骤见[使用指南](USER_GUIDE.md)，实现与数据一致性见[架构说明](ARCHITECTURE.md)。

心愿决策与盘点表达、全局搜索与整理增强已有源码实现；源码已有收入／盘点变化分析、通用退休／FIRE、可选未来养老金收入、心愿及房车大额计划、贷款和持有成本，下文维护当前口径。

命名方案与冻结基准、历史总额参考、收入覆盖声明及完整决策报告尚未实施；实施时同步本文，未写入本文的行为不能视为已提供。

## 产品范围

个人物品档案与金融净资产盘点并重，关注低频记录、长期回顾。重要支出、周期费用与虚拟资产是可开关的辅助模块；关闭模块不删除资料。当前不做日常流水、账号／云同步、AI、行情与交易、按量或按使用时长的成本模式，不做常驻后台联网或自动下载安装；版本发现仅限下述已获选择授权的检查。

**主要使用者与取舍**：主要使用者是钱分散在多个平台、愿意每月或每季盘一次家底、关心“还要上几年班”的城市上班族，通常已经或曾经维护一张资产表格。门面是账户盘点加三个问题：每月要存多少、什么时候能不靠工资、歇一阵能撑多久。物品档案、周期费用与虚拟资产是可选辅助，不删除也不再作为并列起点；市场路径、敏感性矩阵等高级分析折叠，不占首屏。2026-10-17 起解除功能与界面冻结，按维护者自用需要补充盘点与核算能力（参考同类资产 App）；仍不做日常流水、账号与云同步、行情联网、交易与 AI。未完整验证的项目作为已知限制列于用户指南；跨设备同步、手机端、家庭视角等不在当前范围。取舍依据本节与功能进入标准；收敛优先折叠和默认关闭，再评估删除，且不能隐藏需处理状态或改变老用户有效偏好（见[贡献指南](../CONTRIBUTING.md)）。

**网络**：资料使用完全离线。联网只有两种情形，均只读取 Gitee 与 GitHub 的公开发布列表（版本号、发布时间和发布说明），不发送资料、设备或使用信息，但与普通网站访问一样带有常规网络信息与应用版本 User-Agent，不承诺匿名网络访问。

- **手动检查**：「设置 › 关于与帮助 › 检查更新」按钮，点击时查询一次。
- **启动时检查（可选）**：默认不开启；在设置里打开或接受一次性邀请后才生效。开启后每次启动应用最多安排一轮查询、距上次尝试（无论成败）至少 24 小时，只在界面空闲且解锁时进行，失败静默不打扰，不下载、不安装、不改设置。关闭开关后不再发起自动查询，已保存的发现和已读状态保留。授权与发现缓存保存在本机偏好文件，不进资料库与备份；偏好文件损坏时按未授权处理，不自动联网，可在设置里显式重设。

两处来源都连不上时手动检查报错并保留重试，自动检查静默；只有一处连得上时用它的结果并注明另一处未能连接，取两处中最高的版本。一个来源落后的较低版本不会抹掉另一处已确认的更高发现；缓存中的候选超过 7 天未再确认时不再亮未读提示，只显示上次发现日期。下载页由本应用校验过的版本号和固定来源地址拼出；结果只显示，不在应用内下载或安装。

**当前源码的范围收缩**：以可持续维护和复盘的资料为重点，官方复杂测算只留链接。养老金／医保政策计算、地区参数和停续缴安排已退出，旧出生年月、基数等政策输入不兼容。养老金保留为可选未来收入，物品、账户、盘点等客观事实及个人养老金／公积金账户保全，市场模拟与深入分析保留。实际收入分类与投资区间资金流动核对也已接入；计算损益金额，不提供证券账本或收益率。验收范围见[开发说明](DEVELOPMENT.md#收入分类与投资区间接入验证)，源码完成不代表已经发布。

财富记录保存结果未知时保留原请求。任意页面（包括重启后的总览及模块关闭时）提供只读核对入口；金融导入进入数据管理核对专用回执。核对失败不解锁写入，不换请求重提；仍在编辑时先关闭表单或使用原页面核对。分页只控制呈现，不改变完整期间合计、排序或来源。

自己的资料尚未保存第一条记录时，总览显示起步选择：盘点账户为主按钮，整理物品为次要按钮，两者可独立使用。整理物品切到物品总览并打开新增表单；盘点账户切到综合总览并进入账户页。默认勾选隐藏周期费用与虚拟资产，只有用户点击起步按钮且可靠读取到当前模块偏好时才写入这两个开关，其余模块及独立收入／资金流动开关原样保留；不修改模块默认值或旧偏好继承。写入失败展示错误并保留卡片，主操作仍可继续。跳过只按资料库 generation 保存本机关闭状态，不改模块设置；本机存储不可用时本次会话内仍隐藏卡片，下次启动可能再次出现。起步选择显示期间不再显示总览旧的空白起步卡片。样例库或已开始的资料库不显示卡片。

无账户时，“账户与盘点”优先提供已有资产表格导入，其次手动添加第一个账户。金融导入仍由设置的数据管理托管，沿用现有表格格式、回执与恢复语义。

新建账户明确保存成功且父页刷新到同一资料库代际后，页面原位显示轻量成功行「已添加『账户名』」，提供「继续添加账户」（打开空白表单，不复制名称或余额）与「去填写余额」（进入今天的完整盘点；当天已有记录时按更正处理）。该行只保存在本次页面会话，离开页面或切换资料库即清除；创建失败、结果未知、父页刷新失败或编辑／删除路径都不显示，也不因此重复提交创建请求。

总览待关注的完整性提示只检查已启用的财富、周期费用与虚拟资产来源；关闭模块而未读取不表示读取失败，已启用来源失败时仍提示可能不完整并提供重试。

## 关于与帮助

设置末尾的「关于与帮助」直接显示名称、实际应用版本、开发与维护者、检查更新、「启动时检查更新」开关及结果，并汇总指南、反馈与源码入口；没有单独的关于弹窗或第二层关于按钮。维护者名字链接到 GitHub 主页；底部的 Star 提示打开项目页，由用户自行操作，不自动点赞。版本与检查更新按钮同行；开关与说明紧随其后，显示上次成功检查（或上次未成功尝试）的时间。打开本页不联网，查询只由按钮或已开启的启动检查发起。

发现适合当前设备且高于当前版本的新版本时：侧栏「设置」入口出现小圆点（可访问名称含「有新版本」，颜色不是唯一信号），本页显示版本卡（版本、发布日期、当前版本、下载、忽略此版本、发布说明与来源）。只有版本卡在页面前台实际可见时才记为已读并清除圆点；仅挂载、折叠或被锁屏遮挡不算。忽略只针对该版本，不关闭自动检查，仍可手动下载；更高的新版本会再次提示。升级到不低于候选的版本后清除可更新状态，不弹完成提示。偏好文件损坏时显示读取失败与「保持手动并修复设置」「开启自动检查并修复设置」两个显式选择，先保留损坏原件再重写；遇到更新格式的偏好只保留文件并提示使用较新应用，不提供覆盖修复。这两种情况下仍可手动检查，不把读取或保存失败伪装成功。隐私、反馈须知及许可信息默认折叠。隐私说明、AGPL 全文和第三方依赖许可清单可离线查看。外部网站只在用户点击后由系统浏览器打开，使用固定公开地址，不附带资料或设备信息；应用本身不因此发起网络请求。失败时显示可复制的地址。

原生关于与帮助菜单进入「关于与帮助」页面，检查更新菜单额外定位并聚焦版本行，本身不触发联网；查询只由检查按钮或已开启的启动检查发起。锁定或编辑期间菜单按原有保护丢弃或阻止，不排队。备份入口定位到数据管理，不自动启动备份或恢复。这些入口不绕过编辑、待核对请求和资料操作的导航保护，也不改变资料语义或主侧栏结构。

**首次邀请**：本机尚未做出选择（未开启也未关闭）且自己的资料已有至少一条记录时，应用在无编辑、无保存核对、未锁定的普通页面询问一次「自动发现新版本？」；样例库、无记录资料不询问，也不与盘点提醒邀请同页叠加（盘点提醒优先，更新邀请顺延到之后合适的页面访问）。开启需持久保存成功；保持手动或关闭卡片都记录为已关闭，不再主动询问，可随时在设置重新打开。偏好无法保存时如实提示并保留邀请，不伪造已开启；邀请不预先联网。

检查更新按当前应用的系统与架构选择有兼容安装附件的最高版本，不以仓库的最高标签直接判断过期。Mac 优先通用 DMG，其次匹配 Apple Silicon／Intel；Windows 只匹配当前应用架构的 NSIS／MSI。新版本主按钮直接在浏览器下载匹配文件，其他下载来源与发布页默认折叠；不在应用内下载、运行安装或替换应用。只有版本说明、没有兼容附件的来源不提供下载按钮；更高版本缺少兼容包时明确说明当前设备暂不可用，不要求下载其他平台。只有一处可达时仍披露另一处未能查询，不能保证结果是最新。

## 隐私与资料安全

「设置 › 屏幕隐私」提供默认关闭的「窗口不在前台时遮住内容」与「打开物谱时需要验证身份」。遮挡在失焦或隐藏时用不透明内容覆盖整个应用，回到前台立即移除，保留表单输入和进行中的保存。身份验证仅 macOS 支持系统登录密码／Touch ID，启用前须验证通过；系统能力不可用时不能开启。Windows 暂不支持身份验证，仍可使用遮挡。

开启身份验证后，前端启动先显示锁定页，验证成功前不挂载主应用、不发送读取资料命令；取消或失败停在锁定页并允许重试。可选闲置后重新验证：从不（默认）、5 分钟、15 分钟、1 小时；键盘、鼠标和滚动刷新计时，超时且离开窗口再回来才重新锁定。编辑、保存或待核对请求未处理完时延后锁定，处理完再锁。重新锁定保留已挂载页面；锁定期间原生菜单事件丢弃，解锁后不补执行。

偏好仅保存在本机，不写资料库。这只是防止旁人看到屏幕，不会加密资料库文件。可另行创建加密备份；本机资料库文件仍未加密。原生存储工作线程仍沿用既有启动初始化，锁屏不构成文件访问控制。

## 产品承诺与功能进入标准

物谱帮助用户低频维护物品、资产负债与生活计划，并在下次盘点时复核变化。价值来自资料持续积累、复用与核对，不以独立计算器的数量衡量完整度；使用频率低不等于没有价值，判断标准是下次回来能否接续。官方已有复杂测算的事项只提供外部链接，不内嵌公式、不维护地区参数；链接不代表物谱验证了结果。一次性试算须复用已维护资料、回答具体资金问题，不成为独立的专业政策工具。

新增或继续扩展的能力应同时满足：

1. 用户知道如何取得和更新主要输入，不需要研究政策公式或填写大量专业参数。
2. 输入能随盘点、实际到账、支出发生或计划调整继续维护，结果服务于明确的下一步决定。
3. 计算关系可以解释；未知与假设可见，不叠加难以核实的假设制造精确结论。
4. 与已有档案、账户、时间线或计划复用同一事实，不另建重复资料体系。
5. 外部权威工具已承担的复杂核算只链接；仅在整体资金规划确有需要时接收用户明确录入的结果。

不能满足时优先删除入口、收缩职责或改用链接。放入“高级设置”、添加免责声明或把默认参数改成用户自填，都不能代替范围收缩。

Windows 窗口 ×／Alt+F4 遇到正在编辑的普通表单或前台任务时，提示先完成或取消操作并保留当前输入；显式关闭表单仍丢弃未保存输入，不保存草稿。仅存在持久化的未知结果回执不阻止退出，重启后核对原请求。 Windows 正常退出前另行确认当前提醒排期，最多等待约 5 秒；失败或超时保留窗口，用户可以返回应用或明确选择仍然退出。提醒检查不改变记录保存结果，结果未知的提交仍按原回执核对。

## 金额、日期与未知值

- 金额以人民币整数分计算；外币账户按盘点时手填的汇率折算成人民币保存，同时保留原币金额和汇率；不联网取汇率，不按新汇率重算历史。使用整数运算，折算四舍五入，恰为半分时远离零；不能用浮点数累计金额。
- 未知金额／日期保留为空。零金额是明确事实，例如赠品或没有欠款；未知不能填成零，汇总须表达不完整及未计入数量。
- 日期使用本地自然日和 `YYYY-MM-DD`。新增物品购入日期默认留空，表示未知；心愿转购入默认今天，仍可改或清空；购入与生命周期事实不使用未来日期，未来计划放在心愿中。
- 同名物品可以存在，保持各自稳定 ID；名称不能代替对象身份。

## 物品与生命周期

名称是物品的最小必填资料。价格、日期、分类和封面可缺失。存放位置复用备注；标签可选且每件物品最多一个，不新增专用位置字段。使用中与退役都属于仍持有；售出后不再属于当前持有。保障是否有效与物品状态分别判断，不用“保障中”覆盖生命周期。

不用、送人或丢失记录为退役；卖出记录为售出；录错、重复或退货记录使用删除。售出需要实际售价和日期，售价允许为零，未知购入价不阻止售出。维护费用、保障和生命周期日期须与已知持有区间一致；未知日期不伪装为有效保障。新建物品时开启保障，默认从购买日期起一个自然年，购买日期未知时从今天起，结束日期可修改；闰年 2 月 29 日顺延到次年 2 月 28 日。新建表单更改购买日期时，默认保障日期随之更新，手动修改的结束日期保留；此默认值不改写已有保障。

维护类型包含“配件”：Mac mini 底座、灯光透镜等依附主物品的配套花费按维护费用计入总投入、日均成本与重要支出。已单独作为物品记录购入价的配件不重复记维护费；需独立管理或可在多件物品间共用时，可单独建档。

心愿清单是大额购买的考虑清单与决策记录。新心愿默认“考虑中”，名称为唯一必填；预计价格、考虑理由（复用备注，界面标签为“想买的理由与顾虑”）、链接与计划日期均可空；新心愿表单不提供分类、渠道与置顶，添加日期自动记录且不可改，旧记录已有的分类、渠道、置顶值仍可见、可改可清除。购买必须明确确认：“已买到，记录购入”以实际输入创建物品（预计价格仅作参考，不当作实付金额），或显式关联一件已有物品；一次确认只建立一个稳定关联，重复请求与结果未知的回执只对应同一件物品。“不再考虑”保留档案与图片，可“重新考虑”回到考虑中并更正决定备注；已购入不通过改备注撤销，误记购入须到关联物品核对。心愿可在“更多资料”中选择一件在册未删除物品作为“考虑替换的物品”：此关系与购入关联是两条独立关系，设置或清除不修改该物品的任何资料；新物品购入不自动退役、出售或删除旧物品，不推断二手价值，也不从预计价格中扣减。原物品退役或售出不自动取消这条关系；物品进入最近删除时显示“原物品在最近删除”并提供恢复入口；永久删除后有效关系清除，仅保留该物品的名称作为失效关系的展示历史，可在编辑心愿中明确清除，不按同名重新绑定；仅编辑其他资料时保留失效名称。原物品已在最近删除时，保留原关系不阻止编辑心愿，新选目标仍须未删除。计划日期到达不改变状态；提醒为当日 9:00 单次通知，考虑中以外状态与删除、关闭模块时撤销，重新考虑不自动恢复。删除心愿不删除已购入或旧自动生成的物品。

旧攒钱兼容：`decision_state` 为唯一权威状态（考虑中／已购入／不再考虑／历史待核实），旧 `status` 只是兼容投影。攒钱写入已停用，旧 `saved_cents`、模式与来源保留为只读历史；攒钱自动实现与来源不足的旧已实现记录迁移为“历史待核实”，原自动生成物品转为只读的历史生成关系（不删除、不重复生成、不回退用户编辑）。手动／转换实现但缺少关联物品的合法旧记录同样转为历史待核实，保留旧实现日期并提供显式补录入口。核实表单加载原物品现值后才开放输入；未改字段不写回，修改以加载时的物品修订校验，冲突不得覆盖后来更正。历史待核实经三种核实处理：确实已购入（明确复用原物品，可补录实际价格／日期，原物品在最近删除时先恢复）、尚未购入继续考虑（清空有效购入关系，保留历史关系）、不再考虑。升级不自动清理旧版生成的物品，旧请求回执只核对不补执行。

## 成本与售出保值率

| 指标 | 口径 |
|---|---|
| 当前持有数量 | 未删除的使用中与退役物品 |
| 当前持有物购入金额 | 当前持有物已知的实付购入价合计，不是二手估值 |
| 历史购入金额 | 所有未删除物品的已知购入价，包括售出与退役 |
| 期间购入金额 | 按已知购入日期归入期间；日期未知不归入某个月 |
| 总投入 | 购入价＋维护费用（含升级、配件） |
| 净生命周期成本 | 总投入－售出回收金额 |
| 日均持有成本 | 总投入÷持有天数 |
| 首页物品日均成本 | 当前持有物品的已知日均成本逐件合计，不含金融账户与周期费用 |
| 售出后净日均成本 | 净生命周期成本÷截至售出日的持有天数 |
| 按次成本 | 按已记录的使用次数计算；缺少有效次数不计算 |
| 售出保值率 | 售出价÷购入价；不含维护费，购入价未知或为零不计算 |

持有天数＝`max(1, 截止日与购入日期的自然日差＋1)`；截止日为售出日或今天。购入当天算一天，售出后天数固定；退役仍持有，因此持有成本继续摊薄。购入日期未知不展示天数或日均成本，成本资料不完整须明确提示。

首页日均合计只取未删除的使用中与已退役物品。每件复用现行日均成本（四舍五入到整数分）后相加，维护费计入；售出后不再参与当前合计。遵守“不计入日均成本”，总金额／统计页的排除选项独立，不连带排除日均；按次计费另列未参与件数。缺少价格、日期或有未知维护费的物品不当作零；显示已计入、资料不全、按次与排除数量。有物品但没有任何可计算日均时显示未知；空资料库显示零。存在未知项且已有可计算值时明确显示“仅已知部分”。此指标是历史成本摊算，不代表每天实际支出，也不是总购入金额除以平均持有时长。

例如购入 ¥16,999、维护 ¥300、售出 ¥5,000、持有 1,000 天：总投入 ¥17,299，净成本 ¥12,299，毛日均 ¥17.30，净日均 ¥12.30。售价超过总投入时净成本可以为负，不截断成零。

售出统计区分每件同权的平均保值率与按金额加权的总回收率。已删除、不计入统计、购入价未知或为零的物品不参与保值率计算，并说明未参与原因。累计购入曲线出售后不回减；它不表示当前财富。

## 账户、盘点与金融净资产

账户新增房产、个人养老金、保险现金价值、黄金与贵金属类型。房产只记录估值，固定不计入金融净资产；不将其与物品价值合成总资产。保险填写现金价值而非保额或累计保费，默认不计入，可明确开启；个人养老金与贵金属默认计入，不能据此推定随时可取。默认值仅用于新建或未手动选择的类型切换，不改历史盘点口径。房贷仍作为独立负债按其计入状态处理，不自动抵扣房产。应收款记录借给别人、尚未收回的钱，默认计入；车辆记录当前估值，默认不计入金融净资产，可明确开启，不像房产那样强制排除。两者在规划资金用途中默认建议为受限，需用户确认后才作为可用资金。

只记录账户名称、类型、方向、日期和余额，不需要卡号或登录凭据。负债填正的欠款金额，计算净资产时扣除；可将贷款等账户排除于净资产。账户有盘点历史时按停用规则处理，不删除历史事实。

账户清单默认使用中，页内账户范围可切换已停用／全部；默认分组不让两种状态交叉，状态可排序。显示筛选不影响盘点、汇总和历史事实。变化页只默认收起两端已知零且无变化的停用账户，余额、未知、变化或计入范围变化仍保留；比较指标与合计不随显示筛选改算。

金融净资产＝计入账户的资产余额－负债欠款。物品购入金额不加入金融净资产；已经反映在账户余额里的购买，不再次扣减。

完整盘点一次记录一个日期，同一天再次盘点更正原记录。盘点主入口统一叫「盘点全部账户」，账户行保留「快速更新」；更正当天记录时界面明确说明是更正。对照各平台逐行填写本次金额，所有应盘点账户都填齐才可保存；零余额明确填 0，差额由系统计算。未填齐时提供「定位下一处未填」：按共享汇率 → 各账户金额／份额／单价的表格顺序聚焦下一处空缺或非法输入，末尾回到首处，填齐后不再出现也不抢焦点；输入法组合期间的回车保持原始行为，正常回车只移到下一可编辑金额字段，最后一处不直接提交。盘点记录页说明：完整表示应盘账户都有金额；快速更新可能沿用旧值，不代表全部重新核对。每行只读显示该账户在盘点日之前最近一次的金额与日期作为参考，没有更早记录时显示“无”，不预填、不代替本次输入。没有“未变”“未知”按钮、状态选择或批量确认，不按前值自动填入。停用账户通过账户资料中的停用日期处理，不用空金额代替停用。更正加载原记录金额；直接改金额即保存新数值。盘点备注随同一次保存请求提交，最多 10000 字，可空；只更正备注时保留已填写的原条目金额、分类与计入范围，旧“未变”行沿用已记录金额，不从更早盘点重推导。旧版不完整盘点继续可查看，进入更正后需补齐缺失金额再保存，缺失不转换为零。切换日期加载所选日期自己的备注，未保存的备注修改切换前需确认丢弃，取消保留日期、金额与备注。

**快速更新**：账户列表、概览账户清单和已有账户编辑页提供修改余额、增减金额与转账，提交的是新余额。修改余额可从未知开始；增减与转账必须基于所选日期的已知金额，并检查保存时金额未变。当天已有盘点时使用当天原记录（未知不回退更早金额），只更正目标账户，其余金额、分类、计入设置与备注原样保留；没有当天盘点时，其他应盘账户沿用更早已知金额，没有金额的保留未知。日期不早于最近一次未删除盘点且不晚于今天，并须在账户有效期内；没有合法日期的账户保留历史更正入口，不提供快速更新；快速更新备注最多 500 字，按账户名追加到当天备注，历史更正仍进入盘点记录操作。保存首次完整盘点后的提醒询问也适用于快速更新；转账只改余额，不创建收支或资金流动明细。完整盘点的逐行填写规定不变。

转账界面只提供金额已知、计入范围相同的资产转资产或资产转负债（还款）；不提供负债转出。转出余额与剩余欠款不能为负。计入范围优先采用当天已有盘点保存的设置，其次为当前账户设置；保存时在同一事务重新核对，不同范围拒绝写入；两个账户的金额变化相互抵消，金融净资产的这部分变化为零，其他账户在新盘点中的范围变化仍按既有规则提示。不同计入范围请分别修改余额；快速更新不自动创建收支或资金流动记录。

含沿用金额的盘点标记为「快速更新」，没有未知账户时仍是完整盘点，进入曲线与比较。总览及账户概览同时注明含沿用金额，并非全部当日核对。只读详情分开显示本次填写、沿用和未知；无法可靠核实历史来源日期时只写「沿用」，不猜测日期。账户金额旁的更新时间取最近一次明确填写金额的日期，沿用不刷新；超过 90 天弱提示，不自动改金额。保存结果未知仍保留原请求并核对，金额已变化时刷新参考值并保留输入，用户核对后才能再次保存。

旧版不完整盘点不画入完整净资产趋势、不冒充完整比较；概览采用最近一次完整盘点并提示较新旧记录是否缺失。综合总览在净资产金额旁固定显示“截至 YYYY-MM-DD 完整盘点 · 距今 N 天”；期间控件旁常显“所选期间用于重要支出与近期记录；持有物品与固定负担为当前资料，净资产取最近完整盘点”。

综合总览的眼睛按钮记住金融金额显隐偏好；隐藏净资产、变化、资产负债、规划摘要、资产结构与近期盘点金额，金额替代为固定星号。头图保留线形，提示、播报和较期初金额／比例均用 `******` 替代。该偏好只管理总览显示，不修改数据、其他页面或导出。横轴刻度按实际显示间距选取，省略文字不删除数据点。

总览头图保持单条金融净资产面积图，无纵轴；账户概览的「净资产变化」默认只显示金融净资产，可通过图例开启金融资产与负债的同轴对比，负债以正数表示，并提示「净资产 = 资产 − 负债」；负净资产时包含零轴。只连接完整盘点，不完整盘点保留虚线竖标，未知不画零。历史趋势采用与规划轨迹协调的渐变面积、细网格、底部轻图例和行式浮层；样式仅作用于历史趋势，规划／目标图表保持原样。金融净资产图只给净资产线铺面积，资产与负债只画线；流动资金与投资图的面积为各系列的独立余额，不堆叠；未知断点不补面积。账户图例可切换，至少保留一条线；浮层只展示已开启的系列，分类余额图不显示净资产变化。范围、自定义起止日期及各图图例仅在当前会话、当前资料库中记忆。范围为近 30 天（今天向前 30 个自然日至今天，双端包含，共 31 天）、近 6 个月、近 1 年、今年以来、全部和自定义；默认全部。范围内完整盘点至少两次才可使用；自定义双端包含，开始不晚于结束、结束不晚于今天，输入无效或完整盘点不足两次时提示并保留上一次合法曲线。

范围旁「较期初」取所选范围内第一次与最后一次完整盘点的净资产差；期初非正时不显示比例。期初之后到期末（含）有任一盘点标明计入范围变化，显示「账户计入范围有变化，不直接比较」且不给数字；期初自身的变化标记指向范围外，不用于阻断。范围裁剪不改变最近完整盘点的大数字和结构汇总。

账户概览按需展开「流动资金与投资」，与净资产图及其表格共用所选范围。流动资金是计入的 cash；投资是计入的 investment、mixed、fund、bond、precious_metal，不含公积金、个人养老金、保险和房产等。两项按盘点记录时的类型与计入设置汇总，盘点不完整时均未知；完整且没有该类账户时为零。投资余额与现金估算所用 `market_change_cents` 均包含贵金属；独立投资区间核对仍保持既有账户范围，不自动纳入贵金属。变化包含存取与估值，不等于收益。

账户分组仅是当前查看归属，不改变账户类型、是否计入、盘点历史、净资产或规划。可创建、改名、拖动或键盘排序；分组名称去首尾空白后为 1–40 字，不能重复。删除组会在同一事务把所有关联账户（含已停用和最近删除）设为未分组并增加账户修订，不删除账户。

账户页按组小计采用最近一次盘点的历史方向、计入与金额；未知或该次未涵盖的账户只提示未知／仅已知部分，不用跨日期的最近已知金额补齐。资产结构按组采用与按类型相同的最近完整盘点事实，当前分组只决定归属；搜索和账户范围筛选不改变结构与比例分母。未分组排在最后，空组保留，计入资产总额为零时不显示比例。查看方式仅在当前资料库的本次会话中记忆。

金融账户模板可选「分组」列，按名称复用；新名称在预览中列为「将新建的分组」，只有整批确认后同事务创建。预览后分组或账户变化需重新预览；旧模板仍可使用，空分组表示未分组。CSV 和 Excel 导出分组名称，分组也随完整备份恢复。

盘点记录表显示备注摘要，点击日期或摘要按稳定 snapshot ID 打开只读盘点详情（含日期、完整性、记录时账户金额与状态、全文备注与“更正这次盘点”入口）；时间轴与来源跳转同样进入只读详情，原记录已删除时提示而不是打开同日替代记录。两次盘点比较在各端点分别展示日期和各自备注。财富 CSV 在行末增加“盘点备注”列，同一盘点的每个账户行输出相同备注；金额列、行粒度与排序不变。

两次盘点比较要求起点早于终点。负债的欠款增加对净资产是负影响；区间新增账户起点按零处理。账户是否计入、金额完整性等条件无法对齐时，显示原因和已知部分，不能声称合计已对账。比较基准日期必须明确展示；变化额为明确的零时显示「持平」，区别于未知（—）和没有上期数据。净资产变化包含存取、消费与估值变化，不等于投资收益。

综合首页规划摘要与目标页共享 `buildRetireCalc`、`goalHeadline`、`coverageNow` 和月账本。默认复盘展示金融净资产变化（含估值）、已记录到账收入与公积金；没有收入仍保留可比资产事实。收入条数不证明覆盖完整。历史月均变化按区间天数加权，中位数每区间一票；复盘另列估计存下、推算花销和投资账户变化（规则见下文），不称为真实储蓄或储蓄率，也不自动作为未来投入。预计月净投入未确认时保留未知，仍可在其他条件齐全时反求需求；旧阶段原值和 ID 仅用于历史载荷与回执，不重新启用旧界面。

规划以最近完整盘点的收盘日 B 为起点，金额基准 T 单独保存且首次确认后固定。可用、受限、排除规则按稳定账户 ID 与参与比例明确确认；猜测规则只用于缺项展示，不给完整可行结论。债务本金单列，不先扣可用现金；已发生贷款按截至 B 的本金与剩余月数接续。资金规则、付款范围或余债未核对时阻止完整结论。首月净投入与普通预算按 B 后剩余天数折算；计划一次性付款、月供和持有费先检查已有资金，后续月末净投入不能消除月初不足。

“现在可用的钱”不限于现金：确认可变现且愿意用于本计划的基金、证券等投资，按盘点价值及参与比例纳入可用池。新增现金和投资账户的表单建议为可动用，需确认后保存；已保存的受限／排除选择不自动更改，公积金与其他资产仍建议受限。用途未确认继续阻断资金结论，收益稳定与否不代替可动用确认。目标页列明现金及投资计入金额和未作可用资金的账户；大额计划与核算注意事项留在“目标”，心愿影响、职业变化和资金续航位于“试算”。

通用净投入对费用的包含关系按积累／退休作用域、费用来源 ID 和参考额保存。先加回已含参考额，再扣实际月供／持有费；月供结束只停还款，维护费继续。未发生计划的费用只能额外计入，不能凭空加回参考额。个人养老金与公积金保留真实账户和盘点事实，不由政策公式生成余额、未来缴存或税费。已有受限余额通过独立资金规则维护；一般资金释放只按用户明确安排转入一次，金额未知保持未知，不从历史收入反推未来缴存。

预计月已过的纳入计划显示“日期已过，请确认是否发生”，不移到当月。实际发生核对保存实际日期、一次性付款分项及账户、全部付款是否已核对、吸收盘点 ID／修订，以及余债截至日／剩余期。已发生事实不随方案开关撤销；B 前且明确属于同范围盘点的已吸收付款不重扣，B 后付款只扣一次，未知／部分付款保留缺项。可关联既有物品、重要支出或已购入愿望的稳定 ID，核对日期和金额，不新建物品或复制支出。付款关联按事实稳定 ID 去重：物品购入、关联到该物品的已购愿望与已关联支出属于同一事实，不得在发生核对中重复计入。独立购入／独立支出即使日期和金额相同也不合并。旧库及备份保留原始资料；读取时若存在重复关联，返回待核对缺项并阻断完整结论，修正关联后方可继续。 来源更正使读取状态带 `reference_issues` 并阻止完整结论；被引用来源的删除／永久清除需先解除规划关联。保存、请求回执、冲突、重启与备份沿用个人资料事务。当前规划只读报告已接入保存条件的适配；完整收入覆盖声明、冻结基准与完整报告属于后续目标规格；月度收入历史导入纳入 0.0.3 Beta。

两块摘要使用同一次只读事务中的最近完整盘点、收入、个人资料与复盘统计，不把不同批次组合成当前结论。读取错误单独提示，历史资产统计可独立显示。规划关闭或只看物品时不读规划来源；财富关闭而规划开启不读取隐藏财富；明确保存模拟起点可计算独立需求，实盘依赖则提示缺项。宽窗两块并排，窄窗上下排列。

**盘点提醒**：「账户与盘点 › 盘点记录」页底部可选开启（默认关闭），间隔为每 1、2 或 3 个月。提醒由最近一次**完整**盘点的日期加间隔推算，在当天上午 9 点发系统通知，若届时还没有新的完整盘点，一周后再提醒一次；不完整盘点不重新计时，保存新的完整盘点后旧提醒自动取消，从未完整盘点过则不提醒。月末日期按日历月顺延到月底。这个资料库的**第一次**完整盘点保存后，若提醒关闭且这台电脑还没问过，会在保存提示下方询问一次是否开启（不预选间隔，用户点选才请求通知权限；样例库预置多次完整盘点，不出现该询问）；选「先不用」也算问过，此后不再主动问，盘点记录页底部的设置入口始终可用。账户与盘点关闭时提醒暂停、设置保留；提醒偏好与「已问过」标记都只保存在本机，不进入资料库、备份或 Excel，样例模式不安排提醒。提醒日期已过时不补发，也不改变任何金额、状态或规划结论；设置保存不代表系统通知已获准。

**目标进度记录**：每次完整盘点后，第一次打开目标页时记下当时的目标结论（可用资金、需要每月存、当时填写的每月能存、当时结论及是否仍有待核对项），每个盘点修订只记第一次，之后修改目标条件不会改写已记的历史；目标页在至少有两次记录后显示「盘点以来的变化」。只在资金起点来自完整盘点时记录，手填模拟起点、未算出的结果不记；未知保持未知，不补零，不为升级前的盘点补记。盘点被更正后旧点隐藏，由下一次打开按新修订重新记录；盘点删除时隐藏、永久清除时一并删除。记录不是资产事实、不改任何余额，不进入 Excel，随完整备份保留；写入是尽力而为，失败不影响目标页。

## 通用规划基础的当前 core 边界

当前源码使用通用月份与现金流模型，旧养老金／医保政策测算、地区参数、缴费基数和停续缴安排已退出。第一批接入不改变物品、账户、盘点、实际收入与缴存、已发生付款、余债及其稳定引用。个人养老金与公积金仍是金融账户类型，实际余额是资产事实。

所有规划分区共用一个 Profile/revision/core。schema36 在事务内一次转换旧规划：保全可独立解释的通用预算、日期、事件及发生事实，移除政策输入；年龄依赖的时间等待重新确认，不用旧生日暗中换算。迁移失败整体回滚。旧备份恢复使用同一转换，原备份字节不变；新版本资料不可交给旧版本直接打开。历史请求回执保留，只核对旧请求 ID，不重放旧政策载荷。

资金来自完整盘点或明确的手填模拟，两者不相加。已含费用先扣已确认参考额再加实际来源，额外费用只算一次；取消事件的费用不计入。负债本金不先扣可用现金，按确认的未来还款计入。金额基准与盘点日独立；普通首期流按剩余天数折算，期初付款先于月底投入，不能用月底收入掩盖月初缺口。

## 财富记录、财务复盘与目标

财富下保留账户与盘点、收支记录、财务复盘、周期费用和虚拟资产；规划保留目标单入口，页内分“目标／测算详情／试算”三标签。收支记录按收入／重要支出／资金流动分栏，共用全部、年、月或自选自然日期期间，不合成一份流水总额。财务复盘分为本期复盘、盘点比较与区间回顾；本期取相邻完整盘点，任意两端比较与单账户历史另行保留。目标条件修改后重算；新盘点不重写旧核对，历史实际到账不自动成为未来投入。默认阅读以事实及明确核对的投资损益为主，旧估计仅作折叠历史参考。

实际收入由独立 `incomes` 控制；资金流动由 `movements && wealth` 控制，不依赖 `planning`。关闭目标不关闭财务事实，关闭来源不查询或泄漏其金额，也不删除资料；完整导出与备份仍保全全部事实。可信旧偏好的一次继承、损坏设置的修复见[架构说明](ARCHITECTURE.md#module-preferences)。收入历史及所有批量导入／导出统一在设置的数据管理；日常记收入仍留在收支记录。

规划模块可关闭，关闭不删除资料。导航保留目标单入口，页内分“目标／测算详情／试算”三标签；没有独立政策测算页面。目标首屏提供“每月要存多少／什么时候能不靠工资／歇一阵能撑多久”三个入口，复用已有反求、预测和独立续航，不新增计算；前两问未设目标时先设置目标，第三问直接定位试算中的资金续航。目标保留已保存条件与结论，测算详情展示轨迹、逐年快照、退休收入与预算、风险分析；试算展示心愿影响、职业变化与独立资金续航。尚未设置目标时禁用测算详情，试算仍可使用独立资金续航，其他依赖目标的内容保留缺项提示。视图仅保存在会话内，重新进入、切库、恢复或关闭规划后回到目标；待确认回执、编辑、设置和报告打开时沿用页面切换的阻断规则。首次设置先选择财务自由或按计划退休，五步依次填写目标与规划终点、月生活预算、可用资金、未来收入、可跳过的每月净投入；最后通过 setup 一次事务保存。允许未知，关闭不保存普通草稿；失败保留输入，提交结果未知冻结写入并核对原请求。

时间直接保存 YYYY-MM；目标表单以新填写的出生年月、退休年龄和规划终点年龄为主，自动换算月份。出生年月存为通用参考月及零个月参考年龄，不新增政策生日字段，不复用已删除生日。新确认或更正参考只更新年龄显示，保留已保存的目标月份；明确改年龄时才改对应月份。原有非零年龄参考继续可用，不能倒推出出生年月当作本人事实。所有分析以月份为轴，无年龄参考时显示日期而不猜年龄。未来收入选择分为未确认、明确不计、手动；每项包含名称、月金额、开始月、可选结束月与金额／增长口径，养老金只是其中一种角色。开始及结束月均计入。缺金额或开始月的条目保留并提示未计入，未知不当零。金额可以是开始时名义值或指定月份购买力，可选择固定名义或恒定购买力。保存原始金额 A 及其基准月 S，不因打开页面或更改通胀改写；计划基准月 T、开始月 L、年通胀 i，月份差按整月计。开始月名义到账 `N = A × (1+i)^((L−S)/12)`；账本月 M 的基准购买力在固定名义模式为 `N / (1+i)^((M−T)/12)`，保持购买力模式恒为 `A / (1+i)^((S−T)/12)`。不得先改写为实际金额再折算一次；缺通胀且确需折算时该项不可计算，其他事实照常显示。收入从开始月月末首次进入账本，结束月为最后一次到账，未填结束月持续到规划终点；开始月早于资金起点时只向后续算，不补发历史收入。官方链接仅提供外部查询，软件不判断领取资格或自动获取待遇。

暂时取不出的钱（公积金、个人养老金等）保留在账户与盘点中；规划可另设明确月份的预计可用净额，一账户不能重复释放。该计划不写实际到账、不估税、不生成未来缴存；超过现有参与余额必须显式标为估计，金额或来源不明时提示未计入。

目标首页集中展示并允许逐项修改主要条件。下一步优先真实缺项或影响结果的核对事项；假设已核对且无其他待办时隐藏建议卡片，不用数值是否不同于默认值判断完成。应急金月数用于既有参考，不从退休测算可用资金另行扣除。当前报告先展示受控结论和结构化关键结果，再展示主要条件与详细依据；有影响结论的事项时，在结论旁显示事项数并指向下方清单，隐私版本该提示只显示数量；默认隐私，未知、未达成、无余量与展示范围有限分别说明。

预计每月投入可以为正、零或负；未知时仍可反求固定目标所需金额，但不输出预测达成日期。候选不保存，不以历史净资产变化替代未来投入。结果列明预算、来源和假设，缺漏注明影响；有限终点恰好为零表示无余量，不能外推终点以后。

- **月度收入**：记录到账日期、必填税后到账与可选公积金缴存（整数分，日期不晚于今天）；缴存留空 = 未知，填 0 = 明确没有；同一天可有多行，备注最多 500 字。编辑使用修订号，删除进入最近删除并可恢复，永久删除后无法恢复。公积金提取是账户间转移，不需要记录。新增只预填最新一条的已知缴存，最新未知则留空，不回溯更早记录。收入支持专用 Excel 工作表导入，可与账户／完整盘点同批原子提交；同日同额的不同外部键不自动合并。
- **区间**：只取相邻两次完整盘点，复用盘点比较的可比判定，不假设每月盘点。不完整盘点不能结束区间；范围变化时保留缺项。没有收入记录仍显示可比净资产变化，已记录收入按起点之后、终点当天及以前归入区间，记录数不证明覆盖完整。
- **口径**：估计存下采用 `monthly_cash_saving_cents`，只看现金、存款和负债的变化，不含公积金和投资类账户（含黄金与贵金属）；推算花销采用 `monthly_cash_spend_cents`，由已记录税后收入、公积金缴存和账户变化推算。已计入公积金账户时，区间花销 = 税后收入 + 缴存 − 金融净资产变化 + 投资账户变化；未计入公积金账户时不加缴存。投资账户变化采用 `market_change_cents`，单列并标「含转入和涨跌」，绝不与估计存下相加。统一说明：「估计存下只看现金、存款和负债：转进投资账户的钱会让它偏低、花销偏高；收入没记全会让花销偏低。」这些是估计，不代表真实消费或收入记录完整；不展示储蓄率，不自动作为未来投入。
- **历史资产参考**：取终点晚于最新完整盘点往前12个月的可比区间，排除一次性变动；月均净资产变化按天数加权，中位数每区间一票，均标含估值变化。没有收入不剔除资产事实。另列「每月估计存下（中位数）」「每月推算花销（中位数）」；前者取有收入的有效区间，后者只取自身有效样本，各自少于3个显示「区间太少，暂不给出」。第二问、存钱辅助和详情不展示历史估计，也不提供采用入口；历史估计主要保留在财务复盘的折叠历史参考中，不自动生成预测。唯一例外是目标首页「每月能存的钱」一行下方的差距提醒：已填写每月能存的钱，且历史参考有至少 3 个可比区间的「每月估计存下（中位数）」时，若与所填金额相差至少 ¥1,000 且至少为较大者的 25%，显示一句只读提醒（含区间数、统计起点、估计值取整、所填金额和「只看现金、存款和负债，是估计」的口径），并提供「去财务复盘查看依据」与「先不提醒」。提醒不写入任何数字、不提供采用入口，不进入报告、测算详情或试算；「先不提醒」只在本机按资料库和最新盘点日期记忆，下一次完整盘点后可再次出现；任一前提未知时不显示。未来预算与投入由用户明确填写；到账减开销辅助仅采用本次手填的两个数，投资转账不算生活开销。一次性标记只影响历史参考，不改盘点事实；永久删除盘点时一并清除。
- **复盘**：现状保留净资产变化（含估值变化）、已记录到账收入和公积金，新增估计存下、推算花销、投资账户变化的区间合计及「约每月 X」。范围变化或这一期没有收入记录时三项都显示「暂时算不出」并说明原因；缴存未知使花销金额为空时，只让推算花销显示「暂时算不出：有缴存金额未知」；无投资类账户时显示「没有投资账户」。缴存有未知行仍展示已知小计和未知条数，全未知不补零。变化保留本期金融净资产变化及一次性标记；原因显示备注和来源记录，只解释、不调整资产数字、不声称收入记录完整。原因金额未知不补零；观察合计扣除退款与售出回收，排除未知金额并列明条数。 推算花销为负（结余超过已记录收入）时不显示金额，改为「暂时算不出：存下的比记录的收入还多，收入可能没记全」；中位数为负时同样处理。
- **盘点后的轻量复盘**：完整盘点保存后提供可关闭的入口，进入财务复盘中该盘点对应区间；无可用相邻完整区间时保留起步说明与盘点比较。关闭目标不改变财务复盘入口。本期事实与待核对清单由当前资料分别派生，不持久化完成状态；资产变化、已记录税后收入与付款固定展示，缺项不挤占事实。账户范围变化时不展示可比较的资产增减；收入未记录与明确零、付款无记录与未读到区分。核对操作就近提供，不重复生成下一步入口；发生确认与撤回在目标侧维护，财务复盘不嵌入目标写入表单。无保存计划时不提供发生核对。记录仅提供线索，不做差额归因或反推消费。发生核对沿用已有保存与回执，不回写余额、不复制物品或支出；关闭核对不保存草稿。读取失败仅降级对应来源，不把未知当零。纳入 0.0.3 Beta，发布状态以实际发行记录为准。

本期复盘的净资产变化、已记录收入、重要支出和投资损益分别表达，不能构成必然对账等式；重要支出不是全部生活开销，收入减重要支出不称真实结余。退款、净支出和售出回收分别展示；已确认实付才计支出，来源事实按稳定 ID 去重。期间不含起始盘点日、包含结束盘点日，跳往明细沿用同一期间；金额未知、日期待补、来源关闭和读取失败分别表达，不补零。

财务摘要来自同一 `finance_sources` 读取快照中的期间、能力和事实，失败仅影响对应分区。投资损益继续使用盘点差额与确认转入／转出；手填与明细模式互斥。关闭资金流动时不自动切换为手填：手填模式只读已存核对事实并保留可用计算，明细模式明确不可用，不通过旧入口读取隐藏流动。已提交但结果未知时只核对原 request，不产生新写入请求。来源返回只用于打开具体记录或从复盘下钻到明细，仅保留一层上下文，最近跳转覆盖更早返回位置；从总览的模块链接、起步选择或侧栏进入顶层页面不显示返回链接。切库、恢复或能力变化使失效上下文清除。

## 存钱目标

账户与盘点的概览可维护名称、目标金额、可选日期、备注与关联账户；总览仅提供只读摘要。金额用整数分，目标金额须大于零，至少关联一个资产账户；房产和负债不能新增为来源。公积金、个人养老金与保险现金价值等需提示可用性限制，不据类型推定提款时间。目标不预留资金、不改变退休规划可用资金；同一账户可以关联多个目标，进度独立展示且不得相加。账户同时用于目标和退休规划时提示重叠，未读取到规划时明确无法判断。

当前进度来自同一次最近完整盘点，展示实际日期；不能从不同日期拼接余额。关联账户缺金额、已删除、已停用或已变为房产时，列出已知部分与缺项，不给完整百分比、缺口或每月需存。较新的不完整盘点只提示，不覆盖完整基准。已达金额随余额变化，不保存永久达成状态。每月需存仅在日期有效、未来且剩余整月数大于零时显示：以基准盘点日计算，不含基准月、包含目标月，缺口按整数分向上分摊；同月改为显示缺口，今天与逾期分别说明。

历史趋势按当前目标金额和当前关联账户回看，不代表过去设置；不回看创建日之前的盘点。删除进入最近删除，恢复保留关联；仍被目标引用的账户不得永久清除，须先解除关联或永久清除目标。保存结果未知只保存请求编号等回执元数据，读取原请求核对，不持久化目标表单或重放写入。完整备份保全目标与关联，表格导出仅作分析，不提供目标回导。

## 区间回顾

财务复盘的区间回顾只读汇总金融净资产端点与记录间变化、完整／不完整盘点次数、已记录收入、重要支出、当前存钱目标与已有规划结论。期间改用首页总览的期间选择：近 30 天、近 6 个月、近 1 年、今年以来、全部和自定义，默认「近 1 年」；自然年不再作为并列选项，而是自定义面板里的按年份快捷选择（把起止日期填成该年 1 月 1 日至年末，今年到当天，之后仍可修改）。近 30 天为今天向前 30 个自然日至今天，两端包含，共 31 天；近 6 个月、近 1 年为向前 6、12 个日历月的同日到今天，闰日截到有效月底；今年以来为 1 月 1 日至今天；全部不限定起点（读取时用契约允许的最早自然日，界面与复制只写「全部期间（截至今天）」），终点为今天；自定义双端包含，结束不晚于今天，未填齐或顺序无效时保留上一有效范围并提示。期间只保存在会话内，重启或重新进入恢复默认近 1 年，不改变已保存资料或本机金额隐藏偏好。各分区独立表达未记录、来源关闭与读取失败，不以一项缺失抹掉其他事实，也不把收入减重要支出称为真实结余。

净资产终点取窗口内最近一次完整盘点；起点取窗口开始日当天或之前最近一次完整盘点，缺失时取窗口内第一次。标题写实际起止日期，窗口前起点可能使实际跨度超过所选窗口。窗口内无完整盘点时说明没有完整盘点；只有一个有效端点时只列该端点的日期与金额，不显示变化额。实际跨度按完整日历月计算：预设窗口标为对应名称（如「近 1 年变化」「今年以来变化」「全部期间变化」），自定义窗口不足 11 个月标为「自本区间首次盘点以来 N 个月变化」，达到 11 个月标为「区间变化」。两个端点可比较且期间无范围变化才显示变化金额；期间曾改变范围、缺项或比较来源失败时保留原有阻断与原因，未知不补零。页面不再默认展开大幅净资产曲线，只保留起止日期、金额与变化额，并提供「查看这段走势」入口跳转到账户与盘点概览；该入口带上同一期间选择（会话内记忆），曲线仍按账户概览自己的取数规则绘制。总览曲线、本期复盘及盘点比较的取数与口径不变。

收入与重要支出按窗口日期筛选，两端包含。记录数量不证明覆盖完整，日期未知不归入窗口，退款与售出回收仍单列。存钱目标显示最近完整盘点的当前进度并标明依据日期，与所选窗口无关，不回溯重算历史进度，不预留或扣减资金。规划结论按关联盘点日期取窗口内有效、完整且修订匹配的已记录点，不按实际记录日期筛选、不受普通列表最近 24 条上限影响，并披露后来记录、条件变化及盘点更正后的失效。

页面金额遵循本机隐藏偏好；复制摘要标题为「区间记录摘要（隐私版／含金额版）· 起止日期」，独立默认不含金额、比例、目标和账户真名、备注或可反推资金的退休月份。明确选择含金额后仍使用局部别名，不带名称或自由文本。复制与读取不保存报告、不记录新的规划结论、不改变资料；本项不新增资料结构、迁移或备份格式。

## 退休与 FIRE 估算

保留同一月账本上的需求反求、资金轨迹、覆盖情况、逐年快照、Coast／Lean／FI／Fat 条件比较、通用压力测试、固定种子市场模拟、敏感性矩阵及收益顺序检查。条件比较不修改保存的计划，模拟路径占比不是现实概率或承诺。FIRE 搜索到用户指定终点，传统模式检查指定目标月份；图表和快照使用明确日历月份。

当前报告从同一组已保存来源生成只读快照，未来投入未知仍可展示需求，但不生成假零预测。默认隐私隐藏金额及自由文本，完整版账户仍使用稳定局部别名；复制与显示使用同一视图。存在影响计算的未计入或待核对条件时，不能把已纳入部分称作完整覆盖。普通来源更正不改已打开快照，切库、恢复或关闭规划丢弃快照；关闭不保存报告。当前报告不提供逐月趋势、逐项购买结果、冻结基准、方案比较或打印／PDF，这些未覆盖内容明确说明。

大额计划与心愿仍只改变预测，不扣真实余额。已发生首付按明确吸收关系避免重复扣除，剩余贷款按余期接续，持有成本独立；已发生事实不能通过纳入开关或删除设想撤销。未来设想可更改月份、金额、换车周期及截止月份。职业变化与资金续航仍是可选临时工具；职业入口由用户打开，应用默认沿用原计划未来收入与已确认的资金释放，可显式改为本次排除，现金费用由用户确认，不调用社保政策引擎，不保存职业路线。

大额计划在“目标”常驻展开；心愿对目标的影响位于“试算”，只比较影响、不计入目标，决定后可按现有方式加入大额计划。完整未来设想计入后直接重算，不以实际付款、余债核对为前置条件；未知费用包含关系继续按额外费用暂算并提示，核对选填。旧终点未确认时可明确选择「按规划终点计算」，只将该计划的 until_month 设为 null 并清除 time_unconfirmed，不改金额、计入状态或实际发生记录。日期已过或已发生资料不完整仍按现有覆盖规则处理，不能凭开关伪造付款事实。心愿仍独立比较购买影响，不自动并入目标基础结论。

投资复盘独立组件用于校验两端范围与外部转入／转出，损益金额为期末减期初减转入加转出；它不是收益率。当前源码已接入收入分类、区间持久化、导出备份与主页面入口；验收边界见开发说明，不代表已发布。可选逐笔资金流动与规划假设核对的领域保存、UI 接入及隔离核心原生闭环已完成；新规则见本文下节，损益核心公式不变。

新计划按服务覆盖期限制固定期限：提前付款不生成期限外一期，最后一期可截断至结束日。付款日与服务期分别按原始月日锚点顺延，月底取当月最后一天，不逐月漂移。

订阅的单期服务默认一个自然月，下个周期开始前一天为本期最后服务日；这不是整项订阅的终止日期。未指定结束日的订阅在总览与侧栏不反复提示每期付款待确认，仍可在周期费用页主动记录实际付款。其他周期费用保留付款提示；订阅是否有限期均保持周期待办静默；未指定有效期的旧独立订阅显示持续使用，但其价格仍保持单次投入，不推断成月费。

历史订阅须明确服务结束日期，过去的下一付款日不推断为终止日；已结束不计入使用中，也不安排结束后的续费。已结束订阅不进入主页「待关注」，包含旧独立订阅和关联周期计划的订阅；档案、估算和付款事实保留，即将到期且尚未结束的权益仍正常提示，其他类型权益的到期提示保持原义。虚拟列表的累计费用显式标为估算，已记录支出只汇总单次投入与已确认付款；未补记显示为未记录付款。

累计估算按服务开始至今或已指定的结束日（取较早者）、按整期与价格记录计算；初次录入前的历史使用当前价格估算，保存后的调价从更正日起分段。期限预计包含完整期的总额，末期截断覆盖时间但不自动按天减价。估算、年化、月均与预计均不计入重要支出、账户余额或金融净资产。范围补记须用户明确确认确实已付，按填写的每期实付生成付款事实，既有记录保持原样；实付日期默认对应付款日，允许之后单独更正。

旧计划的付款日排期、旧独立虚拟资产的单次价格及已确认事实保持原义；未指定结束日的旧订阅只调整读取状态与提示，不写入续费或付款事实。

### 虚拟标签、计费方式与储值

| 概念 | 口径 |
|---|---|
| 虚拟标签 | 复用现有标签（稳定 ID）与管理；每条虚拟档案至多一个可空标签。标签有适用范围：实物、虚拟、通用；实物标签的既有引用与“标签投入分析”原义不变，通用标签不把订阅费用计入实物分析 |
| 计费方式 | 单次购买、订阅、储值，独立于旧业务类型字段；旧 `license/domain/subscription` 保留为业务类型，无计划的新档案采用中性类型。有计划的旧档案按订阅解释，无计划（含旧独立订阅）按单次投入解释，不推断月费 |
| 已有事实 | 已有付款或充值事实的档案不能更换计费方式；单次购买可明确标记“永久有效”，否则空有效期显示“未设置有效期”，两者用字段区分，不改写旧空值 |

单次购买的使用结束与权益到期分开：可明确选择“已结束使用”并填实际结束日期（允许过去，不早于购买日期、不晚于今天），复用既有 `stopped_on` 与保存回执，不新增计费方式或期限字段。结束后退出使用中，显示使用结束日期，原实付金额与购买日期仍参加历史支出；可撤回结束使用。购买日期过去不会自动结束，不把服务完成伪装成永久权益到期。一次性医疗等没有后续权益的消费可直接记重要支出，已经在虚拟档案记录的同一笔不再重复录入。贷款本金是偿债，由账户盘点同步减少资产与欠款；只将利息作为支出，不将整笔还款记成虚拟资产消费。

订阅默认新建为自然月、自动续费、无最终结束日、无试用、无提醒。自动续费与最后使用日期是两个独立设置：开启续费仍可指定最终使用日；关闭续费必须确认最后使用日，`today > 最后使用日` 才算结束，不加手动“已结束”状态。旧 `paused` 仍是暂停排期，与自动续费关闭是不同字段。周期支持自然月／季／半年／年（覆盖末日按原始锚点网格推算，1 月 31 日锚点的 2 月期为 2/28–3/30，不因短月漂移）与固定 1–3650 天（按自然日计数，年化按 365 天一次舍入折算）。周期长度、试用与覆盖锚点的修改按生效日期分段保存：历史期估算与补记沿用所属时段规则，新规则只影响之后的期；已确认付款、skipped、覆盖与价格历史不改写。免费试用从开始日计入第一天，计费起点默认为试用结束的次日且不得早于该日；试用期不计入付费期数、估算、固定负担或重要支出，也不是付款候选——试用内不能单期确认或范围补记出实付；试用内结束的服务保存为零费用已结束记录，不安排首笔付款。本期特殊到期按原始期始日保存，只影响未确认的目标期及后续推算；与下期相连时后续锚点顺延。后续续费价格保存为价格分段，取消只撤尚未生效的未来价格，已生效段保留；各期待付款金额、月／年折算与未来 12 个月预测都按所属服务期的生效价格计算，不把当前价格乘以期数，用户手填的补记实付保持独立。

储值档案按充值投入：每次充值独立稳定 ID，充值日、可空实付、赠送（默认无）、可修正的到账额度；实付是唯一支出来源并按充值日期计入重要支出，赠送与额度不进支出或金融净资产。实付未知不倒推；只有赠送且明确未支付时实付填零，与未知区分；未知充值日列入待补充。余额是带日期的手动盘点值，不用累计到账倒推，充值与到期不自动扣减或退款。档案删除带入最近删除，恢复原 ID 后同一事实继续生效。

备款提醒默认关闭；关联新版订阅可选择“每期提醒”（扣款前 0–30 天，默认 3 天）或“仅本次”的指定日期提醒，复用既有通知通道。每期提醒按当前及之后未记录的付款期推导，确认 paid 或 skipped 后撤销该期通知并转到下一期，付款事实与服务终止状态分开。备款／充值付款账户不等于订阅已扣款，不能直接记为订阅支出。每期提醒预安排未来 12 个月内的付款期，打开应用或修改资料时补充；自动续费关闭、排期暂停或没有可续费期时暂停。关闭、停用、到期、删除、模块关闭或切换资料库会撤销待通知，历史过期不补发。旧提醒迁移后仍是“仅本次”，不自动启用或改成每期。

虚拟订阅列表和详情可确认本期／下期真实付款，候选只取当前及之后未记录的服务期，不把历史漏记重新当成本期待办；付款后服务状态仍按实际终止日期判断。自动建议的最后使用日随开始日、周期和试用即时更新，手填或已保存的结束日保留；重新开启续费只清除本次表单未手改的自动建议。有限期订阅保留到期状态与日期，但不进入周期性待办。虚拟页筛选提供全部／标签（含未设置）／计费方式／状态，表头排序覆盖名称、开始、结束、状态与费用，未知置后；费用列按未年化原始金额排序。

总览分别展示金融净资产、持有物购入金额、重要支出和固定负担，不加成一个“总资产”。

购买趋势的柱状图与累计折线图支持悬浮查看准确起止日期、整数分金额、件数和未知金额提示，点击固定详情；左右方向键切换期间，Home／End 到首尾，Escape 关闭。切换粒度清除旧选中期间，表格保留精确明细。

## 表单、搜索与引用

- 普通表单关闭即丢弃未保存输入，不保存草稿，不新增退出确认；已经提交但结果未知的请求保留回执并核对，防止重复事实。
- 物品列表默认按购入日期降序，置顶优先；名称、日期、金额、日均、状态通过表头双向排序；「更多排序」仅补充没有对应列的添加时间和持有时长。持有时长从购入日算至今天或售出日，含退役后的持有期间，未知日期置后；状态按使用中、已退役、已售出分组，置顶组内未知值置后。排序在完整筛选结果中执行后再分页，同值按稳定 ID 排列，不改写物品记录。
- 心愿与财富记录列表共用表头排序操作，日期按早晚、金额用整数分比较，未知值不当作零。心愿列表为“心愿｜预计价格｜加入日期｜计划日期”，页头合计只统计考虑中的心愿（未知另列，历史待核实单列），历史待核实在“全部”和“考虑中”筛选中可见并带标记，不计入已购入数量或考虑中合计。
持续／永久权益按结束日期排序时置后，不拿已付覆盖期替代终止日；不完整盘点不提供已知净资产排序值。各列表的默认顺序见 USER_GUIDE，排序不改变金融汇总、付款事实或类型。
- 总览「只看物品」的分类分布默认按购入金额、从高到低列出分类；圆环与下方表格用同一个顺序，表格在当前口径的列标降序。切到「按数量」改按件数从高到低，金额只影响占比和圆环大小。金额未知的分类按已知金额 0 参与，排在金额口径末位，不当作没有该分类。分类颜色跟随分类本身，不随排序或口径改变。同值先比另一口径，再按稳定 ID（无 ID 时用名称）的字符顺序排列，不随系统语言改变。
- 搜索为去首尾空白、英文不区分大小写的字面子串匹配；先筛选／搜索后分页，只作用于本页列表，关键词不改变金融汇总。
- 「搜索全部资料」（⌘⇧F 或菜单「编辑 › 搜索全部资料」）独立于本页搜索：⌘F 仍聚焦本页搜索、⌘N 仍是本页新增。全局搜索只查当前资料库已开启模块的未删除记录，覆盖物品、心愿（含历史待核实）、账户、盘点、独立重要支出、周期计划、已付／已跳过的付款记录、虚拟资产与储值充值的首批字段；物品购入等聚合支出投影、时间轴与统计不作为第二条结果，附件内容、OCR、序列号、保障／维护与退款子记录、余额核对历史、未确认付款候选和金额文本都不搜索。单个整关键词、无分词拼音模糊或通配符（% 与 _ 保持字面）；名称／盘点日期命中的结果排在其他字段之前，组内按添加时间降序、固定类型顺序与稳定 ID 排列，先搜索排序后按 30 条分页，总数与各类型计数来自同一读取快照。关键词最多 200 个 Unicode 字符且不能含空字符；超长输入保留原文并提示，不静默截断。固定账户类型、支出分类、计划类别和虚拟资产类型按界面的中文名称匹配。关闭模块的记录与计数不返回，也不为打开结果自动启用模块；点击结果先按稳定 ID 校验来源，删除或失效时提示并从第一页刷新，不打开同名记录；重试会重新发起查询，同一资料库内写入后再次查询也从第一页开始；关闭面板后迟到的来源校验不再跳转；编辑或回执核对未结束时沿用现有阻塞流程。最近删除仍走既有入口；正式库与样例库绝不混合，无任何网络请求。
- 分类、渠道、标签按稳定 ID 引用；改名保持关系，删除有引用选项前处理引用，不产生悬空关系。
- 来源跳转校验对象 ID 和资料库身份；删除后刷新并说明原因，不打开同名对象，不让旧响应覆盖新资料。
- 样例库与自己的资料独立；样例的修改与删除不影响真实资料。备份、恢复与导出在自己的资料中执行；开发测试始终使用虚构资料。

## 删除、备份与恢复

删除先进入最近删除，可恢复原 ID 及这次删除带走的关系与图片；最近删除不自动清空。永久删除不可撤回，需明确确认；子记录恢复遵守父对象关系，不制造重复事实。

已关联订阅的档案与计划不能单边删除或恢复：删除从任一入口读取同一份整组影响（双方名称与修订、有效付款数、保护依赖），确认后在同一事务隐藏双方；付款通过所属计划隐藏，恢复集合就是这两个父对象，删除前已单独删除的付款保持删除、不随组复活。预览后新增付款、更正或引用变化会使旧确认失效，提交在写事务中按同一规则复核。恢复要求组内对象仍在删除后修订且计划未被其他有效档案占用；恢复后再次删除创建新组，旧组撤销与过期请求不能复活新组。永久删除与「清空最近删除」都先展示并复核全部付款（含此前单独删除的付款）、价格分段、生效规则、特殊到期及提醒的影响；预览后事实或引用变化必须重读。受引用保护的组及其子付款完整保留，清空结果列出保留原因，按组去重；可清除组的双方及这些事实一起移除。历史单边或双方删除且无组归属时，可从详情或最近删除核对，明确预览后恢复关联双方或归为删除组；计划被多个历史已删档案按 ID 引用时由用户点名候选，不按名称或删除先后自动选择。

完整 `.thingary` 备份包含资料、关系和图片，恢复是整体替换，不是合并。表格导入／导出集中在设置的数据管理，统一为 `.xlsx`，一个工作簿按类型分工作表；只导入现有支持的物品、账户、完整盘点和月度收入，分析表不写入资料。编号／日期／金额导出为文本，未知留空，明确零保留；拒绝公式及错误单元格。该格式调整不改变 schema 或现有资料库的升级路径。账户／完整盘点历史 Excel 导入纳入 0.0.3 Beta：外部键按来源与映射集合持久绑定，同名不自动合并，完整性按真实账户有效期核对，空余额不补零。同键异值或同日盘点冲突须明确整项处理，所选有效集合与映射／回执一次事务提交；显式历史覆盖只改变历史条目且类型方向必须一致。失败不留回执，同一请求可重试；未知结果保留仅含请求 ID／generation 的元数据并核对。完整备份恢复时携带映射和成功回执，永久清除后映射标墓碑，不重绑同名。

Excel 不能代替恢复备份；物品 Excel 导入只新增，先预览、默认跳过疑似重复，整批成功才写入。

恢复须先验证兼容性与内容，保留恢复前保护副本，并拒绝旧资料库请求继续写入。较新备份不保证兼容旧版。自动备份开关默认开启，完成备份安全方式选择后才生成备份，明文与密文合计保留最近 7 份，仍需异地备份。

**备份加密（标准 age）**：手动导出、本机自动备份与额外位置副本可用 age X25519 恢复密钥加密；应用只保存公钥与非机密策略，恢复密钥由用户保管、开启与轮换时必须重新输入并验证。密文用 `.thingary.age` 后缀，识别同时检查文件头；持有恢复密钥的人可用标准 `age` 命令行工具独立解密，应用也能恢复标准工具按受支持格式生成的密文；口令、SSH、插件与 armor 模式不支持。内层 ZIP 与资料格式不变，旧明文备份仍可恢复。首次运行（含升级）默认继续明文备份、自动备份照常运行，可随时开启加密；策略文件缺失读为未配置（备份目录里已有加密备份时，即使应用关闭期间丢失也不会被当作首次运行），与配置损坏或公钥非法一样，自动与额外备份暂停，应用内的常驻提示条和数据管理页都会提示并可一键进入处理，避免把丢失的加密策略静默当成明文；配置损坏或公钥非法进入异常态，配置缺失回到未配置状态；这些状态均停止自动与额外备份，绝不静默降级明文，退出异常态必须显式「修复为明文」。开启或轮换后即使资料无变化也会立即生成首份新密钥备份，其成败独立显示；自动备份文件名带创建时间与随机后缀，同日多份并存，旧新格式、明文与密文合计按时间排序保留最近 7 份。新文件名记录秒和更细时间，同刻创建按进程内顺序区分；兼容旧文件名，同分钟旧文件只在文件时间与名称一致时据此排序。清理始终保留刚发布的文件；保留边界的时间缺失或并列时停止清理、保留文件并提示错误，不按随机后缀猜测先后。额外副本沿用相同顺序并保留源文件时间。长时间的加密、解密与复制在存储 Worker 外执行；SQLite 冻结、最终发布和恢复切换经串行边界复核。运行中取消只影响本次任务，等待原操作清理并返回后才解锁；取消迟到时以原结果为准，恢复提交不提供运行中取消。加密备份的解密必须完整认证到文件结尾才进入内容检查，拒绝截断、篡改、尾部追加与错误密钥。明文 ZIP 只在本机私有暂存目录构建与校验；Windows 的 backup-staging 创建及复用时使用受保护 ACL，仅允许当前用户与 SYSTEM，权限设置或核验失败则阻止备份，不修改主资料目录权限；目标与云盘目录只出现密文；用户显式导出未加密副本是单次例外，不改变自动策略。恢复前保护副本仍是本机明文，也不复制到额外位置；主资料库、图片与恢复前副本未加密，界面如实披露；临时文件删除不承诺安全擦除。加密恢复到没有有效本机加密策略的环境时，先持久化待确认状态并暂停自动/额外备份，不会恢复后自动输出明文；本机已有其他有效公钥时保持本机密钥并披露。

涉及这些规则的改动，应同时修改相应代码、有效说明与有意义的测试；原始讨论记录不作为另一套现行规则。

### 规划风险工具

“假设分析”中的六种压力情景及影响结论的提示常显；市场路径、敏感性矩阵、收益顺序检查收在默认关闭的“深入分析”。展开状态仅在本次规划页会话内跨标签记忆，重新进入、切库、恢复或关闭规划后复位，不写偏好。折叠只收纳显示，仍自动计算 1,000 条市场路径供摘要使用，失败原因与查看重试入口在折叠外可见；离开假设分析或详情仍取消过期模拟。

市场模拟、确定性投影和风险比较共用 Rust 月账本，付款先后、首月比例、解锁与完整预算成功判据保持一致。原生与 WebAssembly 使用同一源码，TypeScript 不保留另一套计算公式。每次最多 20000 条路径、1440 个逐月区间；随机路径由种子和全局路径索引复现，分批不改变结果。余额可以为负，不能用截零隐藏缺口。取消会停止后续批次并丢弃已发出批次的迟到结果，不保证强制中断正在计算的一批。

随机收益分布以所设实际收益为中位值，以年度波动为标准差，不给现实概率承诺。压力等级按预算覆盖、目标可达及缺口发生时间的变化区分；状态未恶化但金额、时间或余额变差时为中。六类假设为持续投入、必要预算、收益、通胀、目标时间和市场波动；幅度由核心返回，界面显示并传入同一参数。矩阵保留基准金额，比较低、基准、高三档；生活预算轴不改变固定事件付款，目标时间轴按前后一年比较并按边界去重。分段投入以第一段严格正投入为参照，正投入阶段同比例变化，负投入和固定合同流保持原值；基准单元格保留全部原始分段。

收益顺序检查固定基准停止投入的时间，保持下跌持续时间及累计收益相同，比较发生时点。下跌幅度显示核心实际参数；首月和末尾不足一年按实际经过时间计算，并显示准确终点。期限终点可发生明确的一次性付款，但不新增一个生活月份或退休区间。

当前通用计算只把时间／预算／收入选择、资金起点用途未声明、非法输入或约束冲突，以及必需来源读取失败作为硬阻塞。不再要求职工养老金政策资料。

其余待核对项按只读覆盖计算：逾期且未核对事件暂停未来付款和持有流；信息完整的未来计划继续预计排期，「还没发生」不算缺项。已发生记录只计资料完整且未被起点吸收的付款、核对完整的余债及有实际持有依据的后续费用；未知金额/贷款保持 null，不补零、不重放原首付。已有负债本金保留在净资产口径，不再次从可用现金扣本金；还款与费用仍各计一次。

费用包含关系未知时「暂按额外费用计入，可能重复包含」，所需投入可能偏高。该假设不保存，用户核对后消失。未采用的受限账户不计入规划可用资金；一般资金释放只按用户明确安排进入一次。

只读 PlanningAnnotation 包含原因码、描述、影响方向、稳定来源、缺字段与精修入口。数字旁使用共享 CoverageNote/annotationSummary，偏低、偏高、方向尚不确定各至多一句，最多三条摘要；混合方向分开，来源去重计数。目标页同样常显这些方向摘要，具体未计入范围、缺字段与精修入口保留在可展开的清单中。其它共享结果的紧凑提示使用「有 N 项条件待确认，详见目标页」（N 为可核对标注数），仅有未计入说明时使用「有安排未计入，详见目标页」；提示后仍常显影响结论方向的摘要，不把遗漏或方向全部折叠。总览规划摘要将估算声明与依据合并到标题旁说明，保留紧凑提示与影响方向，数字旁不重复估算声明。标注使用「暂按／未计入／需确认」，不表示事实已确认。新增可选 retire.core.debt_repayments，仅存于计划 JSON，不建表、不迁移。缺省不插入空字段，旧请求序列化和指纹不变；新分区请求包含实际选择。含新字段的数据不能被旧版读取，回退前须保留可兼容旧版的备份。冻结基准与旧报告输出不重写。

## 已有贷款直接还款安排

已有贷款在目标页直接逐账户处理：固定每月实际本息总付款 × 剩余月数／最后一期、已含在每月开销里、或这次先不考虑。默认盘点次月开始，固定起止月份，不推算利率、不拆本金、不再次扣盘点本金；信用卡按固定情景。事件已引用同账户时只采用事件。可保存部分，关闭不存草稿；未处理／适用段未确认仍待核对。开销声明默认覆盖退休前后，更细可分别设置；忽略保留低估说明、不催办。余额差达到 max(原余额 10%, ¥100) 或归零提示复核，归零停独立流、期限不重置。

## 实际收入分类与投资区间核对

实际收入按到账日记录，分类为未分类、工作及其他非投资收入、利息、现金分红、其他投资现金收入；旧事实默认未分类。来源账户与投资收入去向均选填，不猜测归属。分类不改变账户余额，不自动生成未来收入。投资收入不默认带入公积金缴存，旧混合记录的缴存金额必须保留或经用户明确更正。

投资区间使用两次完整盘点的同一已计入投资账户集合。用户维护区间内外部投入、向外转出两项合计，空白是未知，零是明确无流动。确认完整且可比较时，由领域计算“期末 − 期初 − 外部投入 + 向外转出”，不再加利息和分红，也不输出伪精确收益率。现金、公积金、负债不自动归为投资。

核对保存不改变盘点余额。盘点金额、日期、范围、类型更正后撤销原确认有效性；只改备注不失效。新增中间盘点不自动摊分原核对，同范围重叠需明确删除旧汇总后重新维护；删除可恢复，恢复时重新检查重叠。失败保留草稿，提交结果未知保留原请求并核对。

本期事实优先展示；投资区间核对收进默认收起的「投资区间核对（高级）」，历史估计折叠。核对读取与结果更新持续运行，折叠不卸载核对内容。未确认回执、需重确认或失效的核对、读取及删除／恢复错误在折叠外保留提示并自动展开；编辑或提交期间保持展开。手动收起不隐藏待处理提示，也不解除原回执阻断；范围外投资费用未计入等影响损益解读的原因同样在折叠外保留。包含投资收入或发生分类更正的区间暂不提供旧口径储蓄／花销估计；净资产事实和收入金额仍显示。分类字段随收入导入导出，核对输入随分析表导出及完整备份恢复；区间表首版不支持 Excel 回导。未关联来源或去向的收入留在未归属明细，不要求补齐后才能记账。

## 规划假设核对

收益、通胀与模拟波动的独立核对状态由资料库存储。旧计划保持原值且显示「试算值，未确认」；只有明确确认并保存才建立已核对值。相关值变化后显示「条件已变，请确认」，无关预算、投入、费用分区保存保持原状态。目标页把编辑入口放在默认折叠的「条件与核对」；仅在假设未确认或条件已变时，在折叠外显示一行轻提示，不恢复下一步卡片、不增加阻断；假设读取失败仍明确说明原因并可重试。恢复默认值不隐式确认，假设未核对也不阻断需求估算。收益默认 0%／0%、通胀 2%、波动 5% 是试算条件；波动只作用于市场路径模拟。目标的假设入口统一为四字段编辑器，基础向导同样展示并保全四项数值；核对状态真实保存，原生验收范围见开发说明。

## 可选资金流动与来源核对

投资区间核对与资金流动属于高级功能，按需使用，不是完成账户盘点或查看净资产的前提。资金流动可在「设置 › 功能模块」关闭；此开关只控制明细能力，不是整个投资核对的开关。模块默认值、可信旧偏好只继承一次及起步卡片保留收入／资金流动原值的规则不变。

资金流动真实端口已接入财富下的收支记录，投资核对位于财务复盘。资金流动是一条具有两端的已结算正额事实，用于解释盘点变化，保存、更正、删除和恢复均不修改账户余额。新端点为可维护的现金／投资／混合投资／基金／债券资产账户，受限账户解锁和负债还款不作自动分类。范围外对象必须明确填写，不能保存未知或零额、两端同账户或外部到外部的流动。

投资区间使用 `(期初,期末]`，明细列表的日期筛选则包含两端。外到内计转入、内到外计转出、内到内抵消；直接生活支付计流出，提款不等于消费。投资费用留在余额净损益中，不作为转出加回；范围外另付投资费不自动扣入所选组合，并披露不含这类成本。分红留存和范围内再投资无需制造流动，现金分配只计一次流动，收入不再额外加入损益。

每个活动区间仅有手填合计或明细汇总一种权威来源，不能相加。未知手填金额保持未知，空明细不证明没有流动；只有明确确认完整才显示就绪损益。模式切换先预览原合计、新合计与差额，再原子保存，不生成补差流动。相关流动新增、更正、删除、恢复或关联来源变化会使确认待复核，只改备注不失效；旧预览依据在保存事务内重新验证。同范围重叠不自动拆分，插入中间盘点不摊分旧合计。

首版来源选择器提供月度收入及独立重要支出；派生购买、维护、周期付款、充值等暂不提供候选。整笔关联须同日同额且方向一致，来源最多由一条有效流动关联；来源更正或删除不级联删除流动。永久清除来源先显式解除关联并保留审计，仍被流动引用的账户（含已删除流动）拒绝永久清除。没有稳定来源的流动可以不关联，不能宣称全部消费齐全。

旧区间保持手填及原金额，旧回执继续可核对。新流动、来源模式、确认、旧合计与审计纳入完整备份恢复及 Excel 可读导出；明细与审计含已删除历史，Excel 不承担完整资料恢复，也不提供资金流动回导。当前财务工作区的核心保存、重启与系统备份／Excel 面板闭环已有隔离原生验证；每次行为变更仍按影响范围复验，历史结果不替代新改动的验证。完整键盘、输入法、VoiceOver 等未验边界见[开发说明](DEVELOPMENT.md#finance-workspace-validation)。

## 固定资产购入信息

房产和车辆可选填购入价与购入日期，两项可单独填写。购入价不参与任何金融净资产或规划计算，只和最近已知估值比较显示「估值较购入价」，不称作投资收益；未知保持未知，购入价为零时不显示涨跌百分比。日期在 1900-01-01 至今天之间。切换到其他类型前，须先清空并保存已有购入信息，避免静默丢失。车辆默认不计入金融净资产，可手动开启；房产固定不计入。应收款记录借出尚未收回的金额，还款后手动调小余额，全部收回后可停用，不代表已确认可用于规划。

## 外币账户与手填汇率

账户币种默认为 CNY；币种为三位大写字母，日元 JPY 无小数，其他常用币种及未列出代码按两位小数处理。任何盘点记录（包括未知金额和已删除盘点）建立后币种不能更改，须新建账户再停用旧账户。汇率是每单位原币兑换的人民币，最多6位小数且大于0；零原币金额同样须填写合法汇率。下游净资产、规划、比较与复盘只计算人民币分。

同一次完整盘点的同币种只提供一个本次汇率建议，注明记录日期；沿用记录日期不声称实际填写日期。修改本次原币金额才采用本次汇率，只改备注保留各行历史原币金额和汇率，包括同币种不同历史汇率。沿用保留其来源整组事实，更正已沿用行保留本行事实。未知金额不保存原币和汇率。外币清单主金额为“金额 CODE”，附人民币估值、汇率和记录日期；隐藏金额同时遮住这些只读金额。

快速更新增减按原币计算，并检查所见人民币金额和原币金额；原币变了而人民币因舍入不变时也须重读。外币转账只支持同币种、相同计入范围的账户，共用本次汇率；仍须两个账户人民币变化严格抵消。旧汇率不同或逐账户舍入使净变化不为零时拒绝并建议分别修改余额，不补差、不重算历史。资产结构的外币小计来自同一次最近完整盘点的计入资产，不能拼接各账户最近已知金额。

账户导入可选币种（缺省CNY），完整盘点可选币种、原币金额、汇率；外币原币与汇率须齐全，人民币金额可留空由导入计算，已填写则必须一致。映射账户币种必须相同；CSV与Excel导出保留这三列，人民币行原币和汇率留空。


## 按持仓记录投资

持仓仅是录入金额的一种方式，一个账户记录一个持仓；多只基金或股票可分别建账户，或继续按余额记录。仅投资账户、混合投资、基金、债券和黄金与贵金属可开启。份额最多8位小数，单价最多6位，单价按账户币种填写，非负数量与单价的乘积按币种小数位四舍五入后保存；0份额是明确零。外币再按本次手填汇率折算人民币，所有净资产、规划、复盘仍只使用人民币分。不记录逐笔交易、成本、收益或收益率，不联网取价。

录入方式可随时切换，只影响之后明确填写的事实。既有盘点的份额、单价、原币、汇率与人民币金额保留；只更正备注或快速更新其他账户不改变它们。更正时完整旧事实相同才可保留历史录入方式，新金额按当前方式校验。沿用金额同时沿用这些事实，旧来源没有份额时只沿用金额，不补造数量。

完整盘点的份额和单价不预填，可明确点击「沿用上次份额」，单价仍需手动确认填写，上次单价仅供参考；快速更新提供增减持仓、更新价格和同时填写份额单价的修改持仓，增减默认显示上次单价且可修改。没有已知份额时只能同时填写；结果数量不能小于零。持仓账户不能参加转账。整数部分可使用逗号或空格按三位分组，不混用两种分隔符；小数内部空格、数字中间换行与错误分组均拒绝，错误及超小数位输入保留原文并提示，不静默截断；隐藏金融金额同时隐藏只读份额和单价。

持仓单位是账户当前显示标签，1–8字，可空（当前持仓显示“份”），修改标签不换算旧数量。历史条目没有保存单位，关闭模式后自定义单位已清除，历史只中性显示“份额 × 单价”，不猜原单位。CSV与Excel保留每行数量和单价；账户表额外可选“按持仓记录”“持仓单位”，缺省为false/空。明确导入历史允许当前模式与各行实际录入事实不同，但整条份额→原币→人民币必须自洽；可只填份额、单价和外币所需汇率，由导入计算金额，有金额则必须一致。导出账户为当前模式，历史行保留各自事实。

## 同一订阅的多段使用期间

已结束的订阅可在原档案「重新订阅」，保留计划与服务档案稳定 ID。每段独立填写服务生效日期、每期价格与周期，生效日期须晚于上段最后使用日，可以在未来。默认首期计划付款日等于本段生效日，之后从本段的新日期按周期排期；开启「每期付款日与生效日不同」后，独立填写本段首期计划付款日，也须晚于上段最后使用日。新段默认续费，旧试用和旧未来调价不沿用；保存安排不自动生成实付。Plus与Pro等分别建档，不自动修改另一订阅。

实际扣款日期与计划付款日、服务覆盖期分别保存。一次性提前付款只记录实际日期和金额，不改变本段生效日或后续排期；固定提前付款则使用独立计划付款日。实际扣款日期不能晚于今天，服务覆盖期可以在未来。生效前显示「待生效」，不计入「使用中」数量，也不提前计入当前年化负担或累计服务期估算；真实已付仍按实际付款日计入支出。停订空档不参与服务期估算、付款候选、当前服务覆盖或历史补记；各段旧价格、已确认付款的金额、日期、覆盖期及来源保持不变。

最后一段尚未生效且没有本段付款记录时，可在详情「调整订阅安排」或确认「撤销待生效安排」；撤销恢复为前段已结束的安排，历史不变。已有本段付款（含本期不付和软删除记录）时，后端拒绝直接替换或撤销，要求核对付款与服务安排，不自动删除真实付款或办理退款；仍可仅取消后续续费并保留已付服务期。普通编辑不能绕过待生效安排的专用修改。保存结果未知时保留原回执核对，不重复创建使用期间。

详情直接列出同一订阅的付款记录，支持更正日期／金额／备注、改为本期不付和删除误记。充值备款不等于订阅扣款；取消续费与撤销错误付款分别操作，真实历史付款不随取消续费删除。退款不使用删除误记来表示。多段期间、价格与事实随完整备份恢复；原请求回执、资料库代际与关联双方修订检查沿用既有保存边界。
