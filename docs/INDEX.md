当前规划基础已在既有个人资料／月账本路径接入：复盘口径、明确净投入、资金与费用核对、实际发生接续。见[产品规则](PRODUCT_RULES.md)、[使用指南](USER_GUIDE.md#规划收入与复盘)、[架构](ARCHITECTURE.md)与[开发验收入口](DEVELOPMENT.md#规划核算与实际发生预览)。生命周期／数据场景／报告／组件契约文档仍是后续目标规格，不能以其存在视为全部实现。

规划三个入口按任务进入，目标提供四步可跳过引导，收入与养老金独立；真实资产与收入记录保留。操作见[使用指南](USER_GUIDE.md#规划收入与复盘)，草稿与保存约束见[架构](ARCHITECTURE.md#规划首次设置)。

规划统一为通用模型，退出旧职业/储蓄阶段路径，保留真实数据及历史回执；沿用必需/灵活支出与已有深入市场分析，不用三种条件比较替代模拟。通用基础模型、目标先看需求、未来投入选填及分批交付见[统一规划设计 §4.4](PLANNING_LIFECYCLE_DESIGN.md#44-积累能力资金承受能力与首次引导)，计算契约见[数据规格 §4.4](PLANNING_DATA_SCENARIOS_DESIGN.md#44-积累条件压力条件与时间线适配)，旧路径退出与事实保全见[§4.5](PLANNING_DATA_SCENARIOS_DESIGN.md#45-退出旧退休估算路径)。后续程序员、公务员等职业模块只提供待确认条件，基础模型独立可用。**第一批已集成，联合检查与隔离原生范围见开发文档**；正式安装状态单独维护。

最小实施定位见[统一设计 §4.4.7](PLANNING_LIFECYCLE_DESIGN.md#447-分批交付与必要改动)：先拆开需求与预测的门控，投入未知仍可反求；补一项收益压力需求，不新增职业概率问答。结果能力、完整预算与终点余额口径见数据规格 §4.4/§8.1，联合检查夹具 D29—D36；固定当前收支的临时承受能力工具已接入，无目标也可手填资金；完整事件／贷款联动仍待后续交付。更广的未来场景不因第一批集成而视为全部交付。

第一批的[界面细则](PLANNING_LIFECYCLE_DESIGN.md#449-第一批界面与操作细则)、[双分支接缝](PLANNING_LIFECYCLE_DESIGN.md#4410-实现接缝与双分支边界)与[联合验收B01—B15](PLANNING_LIFECYCLE_DESIGN.md#4411-第一批联合验收清单)已细化：Codex负责领域/计算/持久化，Claude Code负责UI/关联接入，先冻结共享契约再并行。基础与养老金资料的未知语义、唯一事实拥有方、分区保存、回执兼容及能力结果接口只维护在[数据规格 §4.4](PLANNING_DATA_SCENARIOS_DESIGN.md#44-积累条件压力条件与时间线适配)。**两个实现分支已完成并集成；当前验收范围见[开发文档](DEVELOPMENT.md#通用规划基础联合验收)。**
