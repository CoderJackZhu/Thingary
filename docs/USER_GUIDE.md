# 物志使用说明

物志把物品档案保存在这台 Mac 上。首次打开时看到「从第一件物品开始」，即可开始记录；使用过程不需要联网。

## 安装和打开

在「应用程序」中打开「物志」。这份自用版本尚未签名、公证；若 macOS 首次阻止打开，请在「系统设置 › 隐私与安全性」找到本次被阻止的「物志」，确认来源是你刚安装的应用后选择「仍要打开」。只对你信任的这份安装包这样操作。

正式版的资料保存在 `~/Library/Application Support/local.possio.app/`。请通过应用内的功能管理资料，**不要手动修改、移动或清理这个文件夹**。开发预览版和验收版使用各自独立的资料位置；它们的记录不会自动出现在正式版中。

## 记录与保护资料

从侧栏进入物品列表，选择「新增物品」，填写名称后即可保存；金额、日期和图片可按实际情况补充。在详情中可更正记录，也可删除并从「最近删除」找回。

**开始录入真实资料后，请立即在「设置 › 资料管理」做一次「完整备份」。** 以后定期重复，尤其是在大量录入、更换 Mac 或准备恢复资料之前。将生成的 `.possio` 备份文件另存一份到这台 Mac 以外的地方，例如你自己管理的外置硬盘。检查外置副本确实存在、可读取；不要只把备份留在原机。物志目前不会自动备份。

需要恢复时，在「设置 › 资料管理」选择「从完整备份恢复」，选中 `.possio` 文件，先阅读应用给出的检查摘要，再确认替换当前资料。恢复会替换本机当前档案；操作前先为当前资料另做完整备份。

## 三种资料操作的区别

| 操作 | 用途 |
|---|---|
| 完整备份 `.possio` | 保存可用于整体恢复的档案、关系和图片；异地保存它。 |
| 导出 CSV | 在表格软件中阅读资产清单；它不是完整备份，**不能用于恢复**。 |
| 最近删除 | 找回当前资料库中误删的记录；不能代替异地备份。 |

## 当前限制

本版本没有自动备份、同步或自动更新；安装包未经签名公证。已在当前 Apple Silicon Mac 验证，尚未实测 macOS 14 和 Intel Mac。VoiceOver、运行中跟随系统切换外观、显示缩放以及 Dock 固定后重启仍未实测。完整备份上限为 100 MiB、1023 个文件；大量图片录入时请留意备份结果。图片移除或放弃草稿后，未引用的托管原图不会自动清理。若遇到上述兼容或辅助功能问题，请先保留现有资料和异地备份。
