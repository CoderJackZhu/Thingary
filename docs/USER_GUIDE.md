# 物志使用说明

物志把物品档案保存在这台 Mac 上。首次添加自己的资产前，会看到八件可操作的虚构样例，方便体验总览、详情和统计。样例存放在独立资料库；点「新增资产」进入自己的资料库，首次成功保存后样例自动隐藏。使用过程不需要联网。

## 安装和打开

在「应用程序」中打开「物志」。这份自用版本使用本地临时签名，未经过 Developer ID 签名和公证；若 macOS 首次阻止打开，请在「系统设置 › 隐私与安全性」找到本次被阻止的「物志」，确认来源是你刚安装的应用后选择「仍要打开」。只对你信任的这份安装包这样操作。

正式版的资料保存在 `~/Library/Application Support/local.possio.main/`。请通过应用内的功能管理资料，**不要手动修改、移动或清理这个文件夹**。开发预览版和验收版使用各自独立的资料位置；它们的记录不会自动出现在正式版中。

## 记录与保护资料

从侧栏进入「全部资产」，点右上角「新增资产」（或按 ⌘N），填写名称后即可保存；金额和图片可按实际情况补充。购入日期预填今天，记录旧物时可通过「选日期」用鼠标选实际日期，也可用键盘输入；日期不确定可清空。其他日期字段也支持鼠标选择和键盘输入。在详情中可更正记录，也可删除并从「最近删除」找回。

名称左侧默认显示箱子。点击可选择图标、立体图标、最近使用的素材或自己的图片；支持分类和搜索，选好后点「使用此图标」。自己的图片可从 Mac 选择，也可拖入或粘贴到选择器。实物照片等通过备注区的虚线「添加图片」入口加入。替换已有图标会把原照片保留为附件；恢复默认箱子也不会删除旧照片。

侧栏底部的太阳／月亮／半明半暗圆形胶囊按钮可随时切换浅色、深色与跟随系统，高亮的一侧表示当前外观。设置页不再重复提供主题选项。单击列表中的物品后，右侧摘要底部始终可打开完整档案；摘要和完整档案的下方内容可各自滚动查看。

**开始录入真实资料后，请立即在「设置 › 资料管理」做一次「完整备份」。** 以后定期重复，尤其是在大量录入、更换 Mac 或准备恢复资料之前。将生成的 `.possio` 备份文件另存一份到这台 Mac 以外的地方，例如你自己管理的外置硬盘。检查外置副本确实存在、可读取；不要只把备份留在原机。物志目前不会自动备份。

需要恢复时，在「设置 › 资料管理」在「从备份恢复」下点「选择备份…」，选中 `.possio` 文件，先阅读应用给出的检查摘要，再确认替换当前资料。恢复会替换本机当前档案；操作前先为当前资料另做完整备份。

## 成本、状态与心愿

资产可选择按日或按次计算。按次请填写累计使用次数；零次时不会显示虚假的单次成本。目标可按单位成本或日期设定。自定义状态独立于保障、退役和售出记录，停用标签不会修改历史。状态、购买渠道及售出渠道可在选择面板中管理、拖动排序，也可按上移／下移调整。

“资产不计入统计”可分别排除总资产、日均成本、统计页和全局时间轴，物品仍可在列表和详情找到。

心愿支持倒计时和攒钱。攒钱详情可追加一笔或更正累计，达到目标价格会自动实现；自动实现后降到目标以下会回到未实现，手动实现不受此影响。实现后心愿仍留在清单，同时新增一件关联资产；预计心愿价格不会被当作实际购买价格，实际金额可在资产中补录。手动实现的资产备注为“手动实现心愿”。自动实现若因金额更正或目标价提高而回退，关联资产进入最近删除，编辑过的资料仍可找回。已关联的心愿不会重复生成资产。

保障与倒计时可设置本地通知，首次启用需允许 macOS 通知。通知时间是所选日期上午 9 点，已过去的时间不补发；系统未能安排时会提示。保存后由 macOS 安排提醒，关闭窗口或完全退出物志后仍可投递，无需常驻后台。Mac 关机、睡眠、专注模式及系统通知设置可能影响时间和横幅展示，不能保证准点弹出。更正日期、关闭提醒或删除相关记录并保存后，会同步更新或取消尚未发送的提醒。

统计页可在全部、本周、本月、本季、本年间切换，按购入日期筛选物品；购入日期未知只进入“全部”。可查看状态数量和占比、分类柱状图与圆环、持有周期和回收分析。回收率只比较已售出物品的已知购入价与售价，不含维护费用。

## 账户与盘点（1.2.0）

侧栏“财富 · 账户与盘点”用于定期核对各平台余额与欠款。先新增账户：只需名称、平台、资产或负债、类型与启用日期，不需要卡号或登录信息；房贷、车贷等可关闭“计入金融净资产”。

盘点时对照各平台逐行填写：回车到下一行，“未变”沿用上次金额，“未知”不当作 0。同一天再次盘点会更正原记录。有账户未填写的盘点单独标出，不画进净资产曲线，也不参与和上次的比较。净资产变化包含存取、消费和估值变动，不等于投资收益。实物购入金额不计入金融净资产。

误建的盘点和从未盘点过的账户可移入最近删除；有盘点记录的账户请填写停用日期（停用前最后一次盘点须为 0）。账户与盘点包含在完整备份中；1.2.0 的备份不能在 1.1.x 中恢复，1.3.0 的备份也不能在 1.2.0 及更早版本中恢复。

## 重要支出

侧栏“财富 · 重要支出”按年回顾大额消费。物品的购入价和维护费用会自动计入，改了物品价格这里也会跟着变；设了“不计入统计页”的物品不计入。旅行、培训等没有对应物品的花费，用“记一笔支出”单独记录，可选旅行、教育培训、医疗健康、家居服务、数字服务、礼物人情、其他。

每笔支出可记一次退款：原来的月份仍按全额计，退款计入退款日期所在的月份。先记了支出、后来又把它建成物品时，在支出里“关联到物品”，这笔就不再单独计入，避免重复。售出回收单独列出，不从支出里扣除。日期未知的购入或维护单独小计，不归入任何月份。支出与退款也会出现在时间轴的“支出”筛选里，误删的支出可在最近删除恢复。

## 三种资料操作的区别

| 操作 | 用途 |
|---|---|
| 完整备份 `.possio` | 保存可用于整体恢复的档案、关系和图片；异地保存它。 |
| 导出 CSV | 在表格软件中阅读资产清单；它不是完整备份，**不能用于恢复**。 |
| 最近删除 | 找回当前资料库中误删的记录；不能代替异地备份。 |

## 当前限制

本版本没有自动备份、同步或自动更新；安装包仅有本地临时签名，未经过 Developer ID 签名和公证。已在当前 Apple Silicon Mac 验证，尚未实测 macOS 14 和 Intel Mac。VoiceOver、运行中跟随系统切换外观、显示缩放以及 Dock 固定后重启仍未实测。完整备份上限为 32 GiB、10 万个文件，备份过程中需要约为资料两倍大小的可用磁盘空间（备份文件本身加一次完整校验）。图片移除或关闭未保存表单后，未引用的托管原图不会自动清理；每次恢复前生成的保护副本和恢复前的旧资料也保留在资料目录中，不会自动删除。若遇到上述兼容或辅助功能问题，请先保留现有资料和异地备份。

### 桌面录入与心愿操作

新建和编辑表单顶部保存，点叉直接退出并丢弃未保存的输入，不再保留普通草稿。已点击保存但结果待确认时，按顶部提示核对原请求，避免重复记录。

心愿列表整行点击进入详情；进度、快捷金额和攒一笔位于首屏。只提供未实现和已实现，优先级和放弃入口已移除。

分类和渠道左侧手柄可拖动排序，拖动时整行跟随指针；右侧排序按钮或聚焦手柄后的上下方向键也可排序；改名和移除放在每行更多菜单。名称和新建按钮相邻，输入后点击创建即可。

## 心愿完成与系统通知

心愿清单默认显示全部记录，可切换“进行中”和“已实现”。攒钱达到目标时详情自动关闭，心愿保留并显示 100%；超额输入只补足目标。如需纠正金额，可在已实现心愿的编辑页更正累计金额。

启用到期提醒后可继续填写，不必等待系统许可对话框。macOS 首次请求时请允许“物志”发送通知；若曾拒绝，可用表单中的“打开系统通知设置”前往系统设置 › 通知 › 物志。开关与日期保存并不代表系统通知已经获准；界面会提示尚未安排成功的提醒。
