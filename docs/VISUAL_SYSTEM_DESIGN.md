# 界面质感与共用操作组件设计

状态：设计已批准，A 阶段共用操作层已实现并完成自动与浏览器验证；原生视觉验收待完成。本文定义共用界面的目标行为；实施及验证状态以末尾交付表为准。产品字段、计算、保存与恢复规则仍以 [PRODUCT_RULES](PRODUCT_RULES.md) 为准。规划目标的数据契约见 [生命周期设计](PLANNING_LIFECYCLE_DESIGN.md)。

## 1. 方向与范围

物谱的视觉方向是「安静、精确、有生活材质的资产档案」。提高质感依靠一致的尺度、克制的层次、真实的内容与可靠的交互。保留现有导航、三套主题、默认柔和卡片主题及用户外观偏好。

本轮首先解决新增记录、菜单、表单、图片操作、图标选择、日期与月份选择。总览布局和规划业务由现行专项设计负责，跨分支接入通过共用组件完成。不能在视觉改动中删除业务字段、弱化未知提示、改变金额口径或把规划当作已发生。

参考 Wealthfolio 的共用组件体系、清晰操作层次、紧凑日期面板和目标图片的内容表达。研究基线为 [51cdbf9](https://github.com/afadil/wealthfolio/tree/51cdbf92e2738c6e8c58fa9f04ae630125549043)。采用独立实现，继续使用物谱的 React、CSS 与现有 SVG；不复制其源代码、照片、品牌资产或特色页面组合。具体截图与研究记录在独立内部资料中维护。

## 2. 设计令牌

颜色只在 `src/theme.css` 定义。保留 native／olive／bento 的色彩差异；共用组件使用语义令牌，避免另建一套深浅色。原生、暖米橄榄、柔和卡片都必须覆盖浅色和深色。

| 类别 | 规格 | 用途 |
|---|---|---|
| 间距 | 4、8、12、16、24 px | 图标与文字、控件、分组、弹层内边距 |
| 正文 | 13–14 px，行高 1.5–1.65 | 菜单、输入、说明 |
| 次级文字 | 12–13 px | 提示和快捷键，保持既有对比度要求 |
| 表单标题 | 20 px，600 | 标题不使用全大写装饰或金融术语堆叠 |
| 工具栏控件 | 36 px | 新增记录、菜单触发器 |
| 表单控件 | 38 px，紧凑操作 32 px | 输入与选择；避免每行高度随控件变化 |
| 控件圆角 | 共用 8 px；主题可适度调整 | 不用全圆胶囊表达所有动作 |
| 弹层圆角 | 14 px | 菜单、日历与月份面板 |
| 表单圆角 | 18 px | 标准表单；批量表格沿用专用宽布局 |
| 图标 | 工具 16 px；媒体操作 20 px | currentColor，1.5 px 线宽，统一端点 |
| 动效 | 悬停 120 ms；进入 160 ms | 只表达出现与状态变化；减少动态时关闭 |
| 浮层阴影 | 轻近影 + 低透明度远影 | 深色靠边框与表面区分，避免黑影糊边 |

金额沿用等宽数字；未知金额显示「待补录」，不能显示 ¥0。状态颜色来自既有 positive／warn／error；文本与按钮不能只用颜色区分状态。焦点使用 accent 外描边，与选中背景分别表达。

## 3. 新增记录与菜单

新增记录保留一个紧凑主按钮：左侧加号、正文、弱化快捷键、右侧小箭头。高度 36 px；图标与文字间距 8 px。快捷键放在同一平面，不再加嵌套边框。菜单宽度至少 208 px，内边距 6 px，单行至少 36 px。项目使用文字行与悬停表面，不保留一行一个带边框的按钮盒。

沿用当前六个入口和各自保存行为，不改入口次序或导航。开启后焦点进入首项；上下键移动，Home／End 到首末项，Escape 关闭并回到触发器，Tab 关闭后继续正常顺序。点击外部关闭。窄窗口菜单仍应完整可见；禁用项不能获得操作焦点。

## 4. 表单与图片操作

标准物品／心愿表单宽 640 px；账户、支出、计划等简洁表单按内容沿用现有宽度，最大不超过窗口减去 32 px；复杂核对表单可扩展至 720 px；批量编辑不强行缩窄。最大高度为窗口减去 32 px。标题、关闭与保存保持可见，正文独立滚动。关闭沿用「不存普通草稿」规则；结果未知的已提交请求必须继续保留并核对。

标题区内边距 20–24 px，关闭控件 32 px；长说明放在标题下方，不挤压保存按钮。表单正文以 16 px 分组间距建立层次。分组使用 card 表面和细分隔，不用深灰底加粗框叠加。字段行标签在左、输入在右；长标签允许换行；提示独占下一行，行高 1.6，不能锁在 170 px 标签窄栏里。

输入框必须有可识别的边界与焦点，文本输入靠左，金额按现有组件口径显示。空值使用现有占位词；placeholder 不能替代标签。多控件行保持间距；复选框与开关不继承全宽文本框样式。窄窗口先压缩留白，必要时上下排列，不让控件溢出。

`FormRow` 为提示生成稳定 ID，适用输入共享 `aria-describedby`，已有说明 ID 必须合并。错误／提示／结果未知继续显示在相关表单内，不能以短暂 toast 替代需要核对的文字。

添加图片改为单色「图片框 + 加号」，与文字同一水平线；按钮 40–44 px，适当留白。图片自身才是视觉主体，操作图标不再使用多层彩色相册插画。沿用现有图片上限、排序、保存和去重，不生成或替换用户图片。空白、上传中、失败与可重试状态保留明确文字。

图标选择保留现有图标、立体素材、最近使用与自定义内容，保持稳定图标 ID。工具图标和物品内容图标分工明确。选择器使用规则网格、统一单元格、轻悬停、清晰选择标记；类别和搜索保持可见。素材不用饱和色块围成另一层按钮。无结果明确提示并允许重置搜索。

## 5. 日期与月份

统一 `DateInput`（YYYY-MM-DD）及 `MonthInput`（YYYY-MM），仍可直接键入。键入中间态交由原表单验证；打开选择器不擅自把空值填成今天。清空产生空字符串，未知仍是未知。日期按本地日历处理，不经 UTC 转换；月份不能伪造成某月第一天。

触发器使用日历线图标，可访问名称为「选择 + 字段名」，提供 expanded／controls／haspopup。日历为 7 列、周一起始；明确今天、选中、禁用和键盘焦点。选中使用 button-bg／button-text，不能拿 accent 配 bg 导致深色低对比。年份及月份可直接跳转，导航遵守字段原有 min／max；今天在界外时禁用。

月份选择为 3 列 × 4 行，只回传 YYYY-MM；当前月与选择月分别标记，支持年份跳转。现有未来计划和过去记录的边界分别保留，不统一设置「不能选未来」。

浮层宽 304 px，内边距 12 px；从触发器右侧对齐，空间不足向上打开，左右靠近窗口时夹到 12 px 安全边距。浮层渲染在所属原生 dialog 内（无 dialog 时在 body），采用固定定位，避免被正文滚动容器裁切；窗口变化与滚动时重算位置。小高度窗口允许面板内部滚动。

开启把焦点放在已选或有效日期；方向键移动一天／一周，Home／End 到当前周首末，PageUp／PageDown 切月；月份用左右移动一月、上下移动三月。Enter／Space 选择，Escape 只关闭选择器并回到触发器，第二次 Escape 才由表单处理。输入法组合期间不处理 Escape。外部点击／Tab 离开关闭，不提交表单；选择器内所有按钮 type=button。

## 6. 目标图片与图表的后续接入

目标图片在统一目标数据和页面入口稳定后实施，不为了图片新增业务类型或虚构进度。本轮先确立图片与卡片规格，避免与规划分支同时改结构。

图片表达目标的生活内容：自然光、真实材质、低饱和、适当空白；自行制作或使用可核验许可的独立素材。以局部物件、空间细节、旅途环境等表达主题，避免复刻 Wealthfolio 的主体、构图与目标卡片组合。卡片图片比例 16:9，裁切焦点可控，标题与状态在图片下方；内容不依赖照片上的叠字。没有图片时使用安静的现有物品图标，占位高度稳定。深色不反转照片，可轻压亮度；装饰图 alt 为空，承载内容的用户照片沿用真实描述。

未来图表沿用既有数据语义与 chart 令牌：稀疏历史不补点、不平滑捏造趋势；缺失是断点，未知单独说明。统一 tooltip 表面、数字对齐、轴文字与点选状态；关键数值先于图形。页面与图表仅淡入，不闪白或跳动；减少动态时直接呈现。具体图表交互由现有总览、统计、规划专项设计接续。

## 7. 文件职责与分支接入

| 文件／层 | 职责 |
|---|---|
| `theme.css` | 色彩、尺寸、层次与动效令牌 |
| `controls.css` | 共用操作组件外观；从旧样式迁移所属规则，避免覆盖堆叠 |
| `FormControls.tsx` | 字段、提示、开关、分段、图片操作语义 |
| `DateInput.tsx`、`date-picker.ts` | 日／月输入、键盘选择、定位与本地日期计算 |
| `date-input.css` | 日期／月份浮层与网格 |
| `topbar.tsx` | 新增菜单行为与可访问性 |
| 业务表单 | 仅传值、边界和保存状态；不重复实现日期弹层 |

本轮不改规划计算、导入、报告、目标模型与首页信息结构。其他分支在后续整合时复用共用组件，并解决真实改动冲突；不能以静态设计完成代替实际联调。旧样式中属共用控件的规则迁移到唯一归属文件，页面布局规则继续留在页面样式。
