# 物谱 0.0.5 Beta · 公开测试版

GitHub 标记为 Pre-release；[0.0.4](https://github.com/CoderJackZhu/Thingary/releases/tag/v0.0.4) 保留为历史版本。

## 下载与支持范围

在 [v0.0.5 Release](https://github.com/CoderJackZhu/Thingary/releases/tag/v0.0.5) 的 Assets 下载 `Thingary-0.0.5-universal.dmg`。从本版起提供 **Apple Silicon 与 Intel 通用安装包**，两种 Mac 下载同一个文件。包内有「物谱.app」、Applications 快捷方式、图文离线指南和完整许可材料；`SHA256SUMS.txt` 用于完整性校验，Source code 是源码。

只在 Apple Silicon、macOS 27 实测；Intel 部分只经过构建与架构检查，尚未在 Intel Mac 上运行验证。最低打包目标为 macOS 14，其他系统未验。采用本地临时签名，**未经过 Developer ID 签名和 Apple 公证**；首次打开如被拦截，请按[安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.5/docs/USER_GUIDE.md#download)在「系统设置 › 隐私与安全性」允许打开。

## 本次更新

- **页面标签更醒目**：规划、账户与盘点、收支记录、财务复盘切换整页视图的标签移到页面标题正下方，字号和点击区域加大；筛选类控件保持小号。
- **目标结果卡片**：恢复「查看测算详情与图表」主按钮；结果有缺口时提供「试算：歇一阵或换工作会怎样」入口；去掉重复的金额与结论行。
- **导航更直接**：从总览、起步选择或侧栏进入顶层页面不再显示「← 返回」链接；打开具体记录或从复盘下钻到明细时仍保留返回。
- **文案**：总览与账户页资产结构旁的口径改为「计入净资产的账户」。
- **通用安装包**：同一安装包支持 Apple Silicon 与 Intel Mac。
- **许可证**：改为 AGPL-3.0-or-later，与规划模块早期参考的上游许可一致。物谱是本地应用，对使用者没有新增义务；名称与图标仍不在开源许可范围内。

## 更新与资料兼容

本版**没有数据库或备份格式变化**，仍为 schema 39；从 0.0.4 更新只需退出旧应用并替换。从 0.0.3 或更早版本更新会把资料升级到 schema 39，升级后旧版不能直接打开，请先做[完整备份并异地保存](https://github.com/CoderJackZhu/Thingary/blob/v0.0.5/docs/USER_GUIDE.md#backup)，详见 [0.0.4 发布说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.5/docs/releases/v0.0.4.md)。

## 验证与限制

本轮运行前端构建、**1,059 项 UI 测试**、Rust 格式／Clippy 和 **578 项 Rust 测试**；3 项既有容量测试按原规则忽略。页面标签、结果卡片入口与返回链接在浏览器内存虚构预览中检查了浅色、深色和 820 像素宽窗口；**本版改动未做原生走查**。

正式包的版本、正式身份、x86_64 与 arm64 双架构和严格签名通过静态核验；只读挂载包与原始构建包、临时复制包一致，包内没有数据库、备份、测试资料或凭据。核验未启动正式身份包。

使用指南中目标、测算详情、试算、账户与盘点、收支记录和财务复盘的截图沿用 0.0.4 拍摄，页面标签仍显示在旧位置（页头右上角），内容与操作不受影响，下个版本重拍。

VoiceOver、完整键盘／输入法组合、系统通知送达、Intel Mac、其他系统和真实下载首开未验。资料及备份未加密，无跨设备同步、自动更新、交易或自动付款。规划与模拟是假设测算，路径占比不代表现实成功概率；详见[当前限制](https://github.com/CoderJackZhu/Thingary/blob/v0.0.5/docs/USER_GUIDE.md#limits)。

代码按 AGPL-3.0-or-later 授权，名称与图标使用权保留。对应源码、锁文件及构建脚本由同标签 Source code 提供，第三方告知与许可全文随 DMG 提供。问题请用虚构资料提交 [Issue](https://github.com/CoderJackZhu/Thingary/issues)；安全问题按[安全政策](https://github.com/CoderJackZhu/Thingary/blob/v0.0.5/SECURITY.md)私下报告。
