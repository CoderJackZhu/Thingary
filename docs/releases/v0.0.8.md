# 物谱 0.0.8 Beta · 公开测试版

GitHub 标记为 Pre-release，Gitee 同步提供相同安装包。这一版同时提供 Mac 与 Windows。

## 下载与支持范围

在 [GitHub v0.0.8](https://github.com/CoderJackZhu/Thingary/releases/tag/v0.0.8) 或 [Gitee v0.0.8](https://gitee.com/CoderJackZhu/thingary/releases/tag/v0.0.8) 下载：

- **Mac**：`Thingary-0.0.8-universal.dmg`，Apple Silicon 与 Intel 同一个文件；只在 Apple Silicon、macOS 27 实测，Intel 仅经过构建和架构检查，打包最低目标 macOS 14，其他系统未实测。本地临时签名，未经 Apple 公证，首次打开如被拦截，按[安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.8/docs/USER_GUIDE.md#download)在「隐私与安全性」里允许。
- **Windows**：`Thingary_0.0.8_x64-setup.exe`，目标 Windows 10 1809+／11 x64；简体中文安装器，只安装给当前用户，缺少 WebView2 时在线安装运行时。**未签名**，可能出现 SmartScreen 提示（「更多信息 › 仍要运行」）；Windows 11 开启「智能应用控制」时，未签名安装包可能被直接拦截。详见[Windows 安装](https://github.com/CoderJackZhu/Thingary/blob/v0.0.8/docs/USER_GUIDE.md#windows-install)。

每个安装包旁的 `SHA256SUMS.txt` 用于校验文件完整性，不是来源认证签名。下载页里的 Source code 是源码，不是安装包。

## 本次更新

**盘点与账户**
- 投资类账户可按**份额和手填单价**盘点，支持增减持仓与更新价格；不联网取价，不做交易账本或收益率。
- 新增**外币账户**：手填汇率、按原币盘点，净资产和规划仍统一按人民币计算。
- 新增**账户分组**：就地创建、按组小计与资产结构，删除分组保留账户。
- 新增**单账户快速更新**：修改余额、增减与同范围转账，保留完整盘点。
- 新增**应收款**与**车辆**账户类型；房产和车辆可选填购入价和日期，在账户清单查看相对最近估值的涨跌。
- 净资产图可同轴显示资产与负债，支持近 30 天、近 6 个月、近 1 年、今年以来、全部与自定义范围。
- 主入口改名「盘点全部账户」，未填齐时可「定位下一处未填」；盘点记录页每条完整盘点可「查看比较」，也可「比较任意两次盘点」。

**目标与复盘**
- 目标页宽屏改为**左侧条件、右侧结论与资产轨迹**，随页面滚动保持可见；窄窗口上下排列。原顶部三个问题入口已移除：每月要存多少、何时能不靠工资直接看右侧结论，「歇一阵能撑多久」只在试算页。
- 区间回顾改用与首页一致的期间选择（默认近 1 年，自然年在自定义面板里），不再默认展开大曲线，改为起止日期、金额、变化额与一张小折线，并可一键查看这段走势。
- 财务复盘默认只有「本期复盘」与「区间回顾」两个页签，盘点比较从盘点记录页或本期复盘进入。
- 物品统计的购买趋势图与财务图表外观一致。

**订阅**
- 持续订阅可在停订后重新开通，新一段服务与付款分别核对；待生效的新一段不计入当前负担。

**隐私与更新**
- 屏幕隐私：「启用身份验证」是总开关，开启后才出现「闲置后重新验证」；「窗口不在前台时遮住内容」独立设置。仅 Mac 支持身份验证；只保护屏幕显示，不加密资料库。
- 新增可选的「启动时检查更新」，默认关闭；开启后每次启动至多一轮、距上次尝试至少 24 小时的公开版本查询，不上传你的资料，下载和安装仍由你决定。

## 更新与资料兼容

更新前先做[完整备份并异地保存](https://github.com/CoderJackZhu/Thingary/blob/v0.0.8/docs/USER_GUIDE.md#backup)，退出旧应用后替换。本版数据库由 schema 42 升至 **44**：新增账户类型、外币、持仓、分组与固定资产购入价所需字段，账户、盘点和引用逐行迁移保留；中断时保持原资料不变。**升级后的库和 0.0.8 生成的完整备份不能直接用旧版（0.0.7 及更早）打开**；需要回退时请使用升级前的备份，并确认本机未再写入新资料。

## 验证与限制

**Mac**（Apple Silicon、macOS 27，隔离身份、虚构资料）：前端构建、1,402 项 UI 测试、Rust 格式／Clippy 与 968 项 Rust 测试通过，3 项既有容量测试按规则忽略。0.0.7（schema 42）生成的虚构资料升级到 0.0.8 后，账户、盘点与物品逐列一致，重启后仍为 schema 44，未知金额保持未知；0.0.7 生成的完整备份可在 0.0.8 恢复（42→44），0.0.8 生成的备份在全新安装恢复后内容一致。

**Windows**（Windows 11 x64，原生运行、150% 显示缩放，隔离身份、虚构资料）：1,402 项 UI 测试、格式／Clippy 与 976 项 Rust 测试通过；安装包静态核验（版本、身份、许可、`longPathAware`、`asInvoker`、未签名）通过；完整原生自动流程（安装、虚构备份恢复、单实例、保存／取消／重启、默认卸载保留资料与重装、系统通知排期）通过。0.0.7 虚构资料升级到 0.0.8 后逐列一致，迁移前副本已生成；Mac 生成的 0.0.7 与 0.0.8 备份在 Windows 恢复一致，Windows 生成的备份在 Mac 恢复一致；各做一次加密备份往返通过。新界面（目标页布局与大额计划、复盘页签与比较入口、区间回顾、统计图表、屏幕隐私遮挡、订阅重新开通、快速更新／外币／持仓／分组／应收款／车辆）在 1600×1000 与 800×600 逻辑尺寸下走查通过。GitHub CI 的 Mac／Windows 检查在主线上通过。

**未完整验证**（不要因本说明视为通过）：
- Mac：开启身份验证后的原生界面（验证机无 Touch ID 或系统登录密码可用）、通知送达、VoiceOver 与完整键盘路径、系统显示缩放、Intel 与 macOS 14。
- Windows：交互安装与 SmartScreen、缺少 WebView2 的机器与 Windows 10、可见通知与点击、实体键盘与微软拼音组合输入、讲述人、多屏与 100%／125% 缩放、OneDrive 云同步、含图片的跨机恢复、三种外观与 Mac 同内容同尺寸对照、完整断网下的更新检查分支。

- Windows 安装包不含离线使用说明（Mac 磁盘映像里有），应用「关于」页已按此说明；请用网页版使用指南。
