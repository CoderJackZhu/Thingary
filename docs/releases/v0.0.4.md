## 本次更新

- **物品与起步**：物品侧栏收为全部物品、心愿清单和物品统计，状态在列表切换。新增首屏只保留名称、价格、日期、备注和图片，补充资料按需展开；购买日期默认未知。首次使用可独立选择整理物品或盘点账户，明确选择后才隐藏辅助模块；无账户时可直接进入已有表格导入。修复样例说明图标被横幅拉宽的问题。
- **财富记录与复盘**：账户与盘点、收支记录、财务复盘各有入口；实际收入和资金流动独立于目标开关。收入可分类，投资区间核对区分转入／转出与损益金额，未知不当作零，分红不重复计入。不提供证券账本、行情或收益率。
- **通用规划**：退出地区社保、医保及养老金待遇测算，改用目标月份、生活预算、资金起点和未来收入。官方复杂测算保留工具入口，外部测算结果可手填为未来收入；公积金、个人养老金账户和实际收入保留。市场模拟、压力测试和深入分析继续提供。
- **目标、详情与试算**：页内分为目标、测算详情和试算。目标保留已保存条件与结论；详情集中轨迹和快照；试算提供心愿影响、职业变化及资金续航。试算不改保存条件，心愿不自动计入目标。新增假设核对与可选流动明细来源，沿用确认失效及回执约束。
- **只读报告与交互**：当前报告默认隐私，可切换完整数值和复制摘要，在结论旁显示影响事项数量；关闭不保存报告。改进条件提示、职业复选框间距、来源返回及财富未知保存结果的重启核对入口。周期付款和复盘来源分页不改变全量汇总；关闭辅助模块后不再把未读取来源误报为读取失败。

## 更新与资料兼容

更新前先做完整备份并异地保存，退出旧包，再手动替换应用。正式资料身份保持 `local.thingary.main`；本轮验收始终使用全新隔离身份，未启动正式身份包或访问正式资料库。

数据库从 0.0.3 的 **schema 35** 升至 **39**：36 退出旧政策输入，37 增加收入分类与投资区间核对，38 增加假设确认，39 增加资金流动及复盘来源。物品、心愿、账户、盘点、实际收入、金额、未知值、稳定 ID、关联、图片和保障保留。旧政策规划的月份与未来收入需重新确认，不把旧年龄／待遇选择自动当成通用规划确认；有语义变化的规划修订递增，原更新时间及历史回执保留。

**旧版不能直接打开已升级资料或新版备份。** 降低应用版本号不会降低数据格式；回退必须使用升级前、与旧版兼容的完整备份。恢复是整体替换，不是合并；Excel 不包含全部图片与关系，不能替代完整备份。

本轮从 `v0.0.3` 标签源码构建隔离旧包，由原生应用生成内置虚构样例，再复制到同身份的空个人库作为兼容夹具。旧包原生保存完整备份后，依次验证新包直接升级、重启、原生选择并恢复旧完整备份及恢复后重启。50 张旧事实表的 236 行全部原字段保持；8 个原图及 16 个缓存图片散列一致，旧备份字节未变。直接升级保持资料集 ID 与 generation，恢复按现行设计更换二者；外键和数据库完整性检查通过。新确认、资金流动与投资来源表为空，没有自动生成确认或交易。

## 验证与限制

本轮运行前端构建、**1,059 项 UI 测试**、Rust 格式／Clippy 和 **578 项 Rust 测试**；3 项既有容量测试按原规则忽略。增加 36→37、37→38 提交前故障回滚与重试测试，结合既有 35→36、38→39、旧 schema35 备份恢复及新备份往返测试覆盖迁移边界。自动检查不替代原生交互。

截图使用全新隔离身份的真实 WebView 与内置虚构样例，来源和捕获尺寸见[截图清单](https://github.com/CoderJackZhu/Thingary/blob/v0.0.4/docs/images/README.md)。本轮原生走查通过首次样例、切换空个人库、表单取消、仅名称物品保存（价格／日期未知）、新建现金账户、10,000 元完整盘点、手动完整备份及恢复、重启保留。隐藏辅助模块后的总览提示和样例说明图标已在最终包原生复验。

正式包的 0.0.4 版本、正式身份、纯 arm64 与严格签名通过静态核验；只读挂载包、原始构建包与临时复制包的全部文件及符号链接一致。离线指南 17 个图片元素与 13 个内部链接检查通过，许可全文覆盖 297 项清单记录，来源散列核验通过；包内没有数据库、备份、测试资料或凭据。核验未启动正式身份包。

VoiceOver、完整键盘／输入法组合、系统通知送达、其他 Mac／系统和真实下载首开未验；全部新增功能的原生完整交互尚未闭环。资料及备份未加密，无跨设备同步、自动更新、交易或自动付款。规划与模拟是假设测算，路径占比不代表现实成功概率；详见[当前限制](https://github.com/CoderJackZhu/Thingary/blob/v0.0.4/docs/USER_GUIDE.md#limits)。
