# 物谱 0.1.1

> **公开测试版（Pre-release）。** 本版以手机界面重整为主，同时包含 macOS 通知授权与图标修正。升级前请先做一次完整备份；未验证的内容不应视为已通过。

## 本版重点

- **手机界面重整**：五个标签共用一套与桌面一致的图标色板，底栏当前页用底色和文字共同强调；总览默认先显示金融净资产，再显示规划、物品日均成本、待处理摘要和近期记录；「我的」把常用设置与提醒／隐私分组，减少同权色块。
- **物品页更易读**：列表顶部突出「持有总价」和日均成本；有未知价格时改称「已知持有总价」，缺项单独说明，不把未知当作 0。搜索生效时收起摘要和状态分段，空结果直接提供「清除搜索」。
- **物品编辑更直接**：图标与名称并排，图标右下角的小铅笔提示可更换；默认图标与当前分类图形一致，棕色纸箱素材改名为「纸箱」，选择结果与预览一致。保障、状态、成本与目标、置顶和统计排除默认可见，仅购买渠道、品牌、型号、序列号收在「更多信息」。
- **统计排除**：主开关一次切换总金额、日均成本、统计页面和时间轴四项，展开「分别设置」后可逐项调整。
- **macOS 通知授权**：区分「尚未申请」与「已拒绝」；「重试提醒」会主动请求权限，等待期间禁用重复点击；请求结束后读取系统实际授权状态，已有提醒会重新安排。
- **macOS 应用图标**：全部尺寸统一使用五线版主图，不再在小尺寸混用历史三线图稿。

桌面与手机共用 `src/icon-palette.css` 的图标色值。这是把原先写死的桌面颜色提取为共享令牌，桌面两套主题的色值保持不变；本版没有重做桌面布局。

## Android

- 提供 **arm64-v8a** 签名 APK，支持 Android 10（minSdk 29）及以上；不包含 32 位 ARM 和 x86 模拟器架构。
- 正式包名 `local.thingary.main`，应用名「物谱」，可与开发预览 `local.thingary.preview` 同时安装。
- 本版手机界面已在小米 Android 16 真机上用隔离预览身份和虚构资料验收；正式签名包在发布前另行安装核对启动、通知权限与升级路径。
- 国产安卓系统可能对未备案或未知来源应用弹提示或拦截，这是系统策略，不是应用故障。

## WebDAV

本版未改动同步代码。发布前已用真实 WsgiDAV 服务完成桌面与安卓真机往返：手机推送、桌面拉取、桌面推送新版本、手机拉取并恢复附件与删除状态，断网时明确报错，服务恢复后回到 `up_to_date`。

尚未验证：无 ETag 服务器的并发写入（可能退化为后写覆盖）、真实 Nextcloud／坚果云当前版本、公网 TLS／代理环境和大资料库性能。同步仍属实验性功能，使用前请先做完整备份。

## 已知限制

- iPhone 版尚未上架，也没有公开安装包；iOS 当前暂停公开分发。
- macOS 安装包未经过 Apple 公证，Windows 安装包未签名；首次打开可能需要在系统中手动允许。
- Windows 10、Intel Mac、辅助功能、多屏和系统缩放仍未完整覆盖；Windows 最小化到通知区域后的实际送达、macOS 新电脑首次通知授权等原生流程，以对应验收记录为准。
- 主资料库和图片未加密；自动备份与主资料位于同一台电脑，仍需另存异地备份。
