# 物谱 0.0.1 Beta · 公开测试版

这是当前唯一公开下载的测试版，GitHub 标记为 Pre-release。本包在 2026-10-05 以当前代码重新构建，包含此前全部修复与改进；较早的同版本 Release 和安装包已撤下，替换为本次 0.0.1 Beta；旧 0.1.0-beta.1 Release 已撤下。物谱 Thingary 用来记录值得留档的物品、低频盘点账户和金融净资产。资料保存在自己的 Mac 上，无需注册账号或编程。

## 下载和安装

下载本页 Assets 中的 **Thingary-0.0.1-arm64.dmg**，打开后把「物谱」拖到「Applications／应用程序」，复制完成后从「应用程序」打开。Source code.zip／tar.gz 是源码，不是安装包。SHA256SUMS.txt 提供安装包完整性校验值。

仅提供 **Apple Silicon Mac**（M 系列芯片）安装包；只在 macOS 27 实测，macOS 14 和 Intel 尚未实测，无 Windows／Linux 包。安装包使用本地临时签名，**没有 Developer ID 签名或 Apple 公证**。首次可能被系统阻止，请按 [下载安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/docs/USER_GUIDE.md#download) 在「系统设置 › 隐私与安全性」允许本应用；无需编译或运行终端，也不要关闭全局安全保护。

安装包附有可离线打开的「开始使用.html」和许可材料。首次打开可先浏览独立的虚构样例，然后点「开始记录我的资料」。图文指南：[第一件物品](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/docs/USER_GUIDE.md#first-record) · [第一次盘点](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/docs/USER_GUIDE.md#first-snapshot) · [完整备份](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/docs/USER_GUIDE.md#backup)。

## 可以做什么

- 建立物品档案，记录价格、日期、照片、维护与保障，回顾持有成本、退役和售出。
- 记录心愿与攒钱进度，实现后形成关联物品档案。
- 建立资产和负债账户，每隔一段时间记录余额，比较金融净资产和各账户变化。
- 按需开启重要支出、周期费用与虚拟资产，通过总览、统计和时间轴回顾。
- 完整备份与恢复、自动备份、CSV 导入导出、最近删除；浅色／深色／跟随系统及三种界面风格。

## 本次更新

- 周期费用的状态、费用与服务覆盖期自动换行，长说明不再撑宽页面；已结束订阅保留历史档案与付款记录，不再出现在主页「待关注」。
- 虚拟资产支持单次购买、订阅与储值三种计费方式，并可使用虚拟或通用标签；储值按充值实付计入投入，赠送与额度不算支出，余额可手动盘点并记录日期。
- 订阅支持固定天数周期、免费试用、本期特殊到期与后续价格调整；关闭自动续费时确认最后使用日期，可按需开启续期提醒（默认关闭）。
- 维护记录新增配件，配件费用计入主物品总投入与日均成本。

- 购买趋势两张图支持悬浮查看准确日期、金额与件数，点击固定详情并用方向键切换。
- 订阅按实际结束日期自动判断状态，历史费用显式显示累计估算，可直接补记已确认的历史付款；已结束不再安排续费。
- 首页新增物品日均成本合计，包含当前持有物品和维护费；资料不全明确提示，售出、按次与主动排除的物品不参与。
- 物品、心愿与财富记录统一点击列标题排序，再次点击反向；物品补充添加时间与持有时长排序。
- 订阅价格明确为每期费用，默认持续按月续费；无结束日期时不频繁提醒到期。房租支持独立租期、预付覆盖期与年度季付，估算与实付分开。
- 新物品保障默认从购买日期起一年；日期未知时从今天起，保留手动修改与已有保障。
- 修复心愿详情更多菜单裁切，新增摄影素材分类及 12 个配件图标，保留已有素材 ID。

保持应用资料身份，数据库通过增量迁移升级至 schema 25（包含 21 → 25 的兼容迁移），保留已有记录、图片与历史付款。新版资料及备份不应直接降级到旧包。版本记录见 [CHANGELOG](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/CHANGELOG.md)。

## 使用前了解

公开测试版用于收集使用与兼容性反馈；录入重要资料前请阅读下面的保护与恢复说明。此前短暂发布的 2.6.1 和 0.1.0-beta.1 安装包已撤下，当前统一为 0.0.1 Beta。旧版使用者先做完整备份再手动替换应用；版本编号相同或变小不代表资料格式可以降级，已有资料由增量迁移保留。

录入第一批资料后立即做完整备份，另存到原机以外。资料和备份未加密；选择云盘作为额外备份位置时，副本由云盘软件同步。应用没有跨设备同步和自动更新，界面目前只有中文。金额未知不会当作 0；实物购入价不计入金融净资产。

恢复备份会整体替换当前资料，不能用 CSV 代替完整备份。新用户无需迁移；曾使用 2.5.0 及以前自用版的用户须阅读 [更新与迁移](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/docs/USER_GUIDE.md#update)，旧身份与旧备份后缀不自动兼容。

虚拟标签、储值、续期提醒及本次布局修复的原生完整交互验收尚未闭环；自动检查和浏览器验证不能代替原生验收。真实下载后的 Gatekeeper 首开、macOS 14／Intel、VoiceOver 和部分系统集成项目仍未实测，详见 [当前限制](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/docs/USER_GUIDE.md#limits)。问题请提交 [Issue](https://github.com/CoderJackZhu/Thingary/issues)，只用虚构数据复现，勿上传真实数据库、发票或备份；安全问题按 [安全策略](https://github.com/CoderJackZhu/Thingary/blob/v0.0.1/SECURITY.md) 私下报告。
