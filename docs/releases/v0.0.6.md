# 物谱 0.0.6 Beta · 公开测试版

GitHub 标记为 Pre-release，Gitee 同步提供相同安装包。

## 下载与支持范围

在 [GitHub v0.0.6](https://github.com/CoderJackZhu/Thingary/releases/tag/v0.0.6) 或 [Gitee v0.0.6](https://gitee.com/CoderJackZhu/thingary/releases/tag/v0.0.6) 下载 `Thingary-0.0.6-universal.dmg`；Apple Silicon 与 Intel 使用同一个文件。包内包含「物谱.app」、Applications 快捷方式、离线图文指南与完整许可材料。`SHA256SUMS.txt` 用于校验文件完整性。

只在 Apple Silicon、macOS 27 实测，Intel 仅经过构建和架构检查；打包最低目标 macOS 14，其他系统未实测。本地临时签名，未经过 Developer ID 签名和 Apple 公证；首次打开如被拦截，请按[安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.6/docs/USER_GUIDE.md#download)操作。

## 本次更新

- **可选盘点提醒**：设置中选择每 1、2 或 3 个月提醒，新的完整盘点自动重新计时，默认关闭。关闭账户模块时暂停提醒；偏好仅存本机。
- **每月存钱的差距提醒**：目标页比较你填写的每月能存金额与已记录收入、盘点区间提供的参考，差距较大时链接到财务复盘。不自动修改你的数字，暂时关闭提醒后下一次完整盘点可再次出现。
- **盘点以来的目标变化**：每次完整盘点后首次打开目标页，保存当时的可用资金、所需月存金额、自己的投入估计与结论；至少两个有效记录后显示。以后调整目标不改写历史；盘点更正后旧结论失效，不为旧盘点编造记录。
- **主动检查更新**：在「设置 › 数据管理」点击后向 Gitee 和 GitHub 各查询一次公开版本列表，取最新版本；任一来源不可达不影响另一处。可打开相应下载页，提醒先做完整备份；不会自动下载或安装，平时不联网，不发送档案资料。
- **指南与演示更新**：随包提供当前操作说明；主要页面截图为 0.0.5 的隔离虚构样例，新增功能以文字说明为准。

## 更新与资料兼容

更新前做[完整备份并异地保存](https://github.com/CoderJackZhu/Thingary/blob/v0.0.6/docs/USER_GUIDE.md#backup)，退出旧应用后替换。本版数据库由 schema 39 升至 **40**，只新建空的目标进度表，不改写旧盘点事实。升级后的库和完整备份不能直接用旧版打开；需要回退时使用与旧版兼容的升级前备份，不直接降级打开新库。

本轮前端构建、1,085 项 UI 测试、Rust 格式／Clippy 和 596 项 Rust 测试通过，3 项既有容量测试按规则忽略。schema 39→40 的提交前回滚、重试与备份恢复由临时虚构资料测试覆盖。正式包版本、正式身份、x86_64 与 arm64 双架构、严格签名、只读挂载及复制完整性通过；离线指南的 17 张图片和内部跳转完整。构建有既有前端包体积提示。
