# 物谱 0.0.2 Beta · 公开测试版

本版集中加入退休与财务独立规划，改进低频盘点、心愿决策和订阅管理。GitHub 标记为 Pre-release；0.0.1 保留为历史版本。

## 下载与安装

下载 Assets 中的 **Thingary-0.0.2-arm64.dmg**，打开后将「物谱」拖入「Applications／应用程序」。Source code 是源码；SHA256SUMS.txt 提供安装包完整性校验值。包内附有「开始使用.html」和完整许可材料。

仅提供 **Apple Silicon Mac** 安装包，实测系统为 macOS 27；最低配置目标 macOS 14 尚未实测，无 Intel、Windows 或 Linux 包。使用本地临时签名，**未经过 Developer ID 签名和 Apple 公证**。首次打开如被系统拦截，请按[安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.2/docs/USER_GUIDE.md#download)在「系统设置 › 隐私与安全性」允许本应用。

## 本次更新

- **规划与测算**：四步首次设置，明确预算、预计投入、可用资金及费用关系；退休与 FIRE 详情提供资金轨迹、所需月投入、现值／名义值、压力测试与市场路径模拟。历史净资产增长不再推定真实储蓄，资料缺项时说明需要核对的内容。
- **大额计划与现实核对**：比较买房、买车等设想的资金影响；实际发生后核对付款、起点盘点和剩余贷款，避免重复扣减。
- **职业变化试算**：目标页可展开临时试算，回答休息能撑多久、高收入还需维持多久、换工作后每月需要攒多少。答案在前，假设可修改；默认不计养老金、公积金与个人养老金，关闭即丢弃，不改变已保存计划。另有独立资金续航试算。
- **心愿与盘点**：心愿围绕购买理由、顾虑、计划日期和明确购入确认；旧攒钱记录只读保留。账户逐项填余额、盘点备注与详情、停用账户筛选、全局搜索，以及总览规划摘要和金融金额隐藏。
- **订阅与导出**：订阅共用详情，同名旧记录可逐对确认关联；直接确认本期／下期付款，每期自动备款提醒，单次虚拟购买记录结束日期。一次导出全部五份业务表格至新文件夹。
- 改进窄窗口、弹窗焦点、图表文字避让和费用核对；养老金参数附来源与核对日期，修正弹性延迟退休最低缴费年限判断。

## 更新与资料兼容

更新前先做[完整备份并异地保存](https://github.com/CoderJackZhu/Thingary/blob/v0.0.2/docs/USER_GUIDE.md#backup)，退出旧应用，再手动替换应用包。资料身份保持不变，数据库增量迁移至 **schema 33**。新版资料及备份不能直接交给旧版打开；需要回退时使用升级前且与旧版兼容的备份。

旧阶段、35 岁职业路线等退休估算已退出；没有通用输入的旧计划需重新确认目标、完整预算、预计投入及未来收入。账户、盘点、已记录收入、养老金事实、已发生付款和余债保留。旧心愿的自动实现记录可能提示核实，不会自动删除对应物品。

## 验证与限制

前端构建、679 项前端逻辑测试、Rust 格式／静态检查及 469 项领域／存储测试通过。隔离原生身份下走通首次样例、新建物品与账户、盘点、完整备份恢复和重启保留；旧版虚构资料的直接升级与备份恢复通过 Store/API 核对。安装包另核对身份、版本、架构、严格签名、离线指南和许可材料。隔离数据验证与未覆盖的原生交互范围见[当前限制](https://github.com/CoderJackZhu/Thingary/blob/v0.0.2/docs/USER_GUIDE.md#limits)。

职业变化与养老金均为假设测算；北京断缴指数和起领时间等仍属待校准的简化估算，市场模拟路径占比不代表现实成功概率。全部新增功能的原生交互验收尚未闭环。真实下载后的 Gatekeeper 首开、macOS 14／Intel、VoiceOver、系统通知实际送达等仍未实测。

资料和备份未加密；没有跨设备同步、自动更新、交易或自动付款。问题请提交 [Issue](https://github.com/CoderJackZhu/Thingary/issues)，只用虚构资料复现；安全问题按[安全政策](https://github.com/CoderJackZhu/Thingary/blob/v0.0.2/SECURITY.md)私下报告。
