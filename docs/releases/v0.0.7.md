# 物谱 0.0.7 Beta · 公开测试版

GitHub 标记为 Pre-release，Gitee 同步提供相同安装包。这一版同时提供 Mac 与 Windows。

## 下载与支持范围

在 [GitHub v0.0.7](https://github.com/CoderJackZhu/Thingary/releases/tag/v0.0.7) 或 [Gitee v0.0.7](https://gitee.com/CoderJackZhu/thingary/releases/tag/v0.0.7) 下载：

- **Mac**：`Thingary-0.0.7-universal.dmg`，Apple Silicon 与 Intel 同一个文件；只在 Apple Silicon、macOS 27 实测，Intel 仅经过构建和架构检查，打包最低目标 macOS 14，其他系统未实测。本地临时签名，未经 Apple 公证，首次打开如被拦截，按[安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.7/docs/USER_GUIDE.md#download)在「隐私与安全性」里选「仍要打开」。
- **Windows**：`x64-setup.exe`，目标 Windows 10 1809+／11 x64；简体中文安装器，只安装给当前用户，缺少 WebView2 时在线安装运行时。**未签名**，可能出现 SmartScreen 提示（「更多信息 › 仍要运行」）；Windows 11 开启「智能应用控制」时，未签名安装包可能被直接拦截。详见[Windows 安装](https://github.com/CoderJackZhu/Thingary/blob/v0.0.7/docs/USER_GUIDE.md#windows-install)。

每个安装包旁的 `SHA256SUMS.txt` 用于校验文件完整性，不是来源认证签名。下载页里的 Source code 是源码，不是安装包。

## 本次更新

**盘点与目标**
- 账户新增**房产、个人养老金、保险现金价值、黄金与贵金属**。房产固定不计入金融净资产，保险默认不计入，不合成总资产；已有账户、盘点和引用迁移后保留。
- 新增**存钱目标**：为一笔钱设目标，选关联账户，按最近完整盘点显示进度与可选日期的每月需存；未知不当零，不冻结或预留资金。支持最近删除恢复、备份与导出。
- 新增**区间回顾**（财务复盘）：默认近 12 个月，可选自然年或自选日期；净资产按实际盘点日期展示，收入与重要支出按区间汇总，缺项与范围变化如实说明；复制摘要默认不含金额与名称。
- 首次使用从一次账户盘点开始，也可先整理物品；完成第一次完整盘点后只询问一次是否开启提醒，默认关闭。目标页先回答「每月要存多少、什么时候能不靠工资、歇一阵能撑多久」，深入分析折叠。

**备份与安全**
- 完整备份支持标准 **age 外层加密**，恢复密钥由你保管，应用只存公钥，丢失无法找回；持有密钥可用标准 `age` 命令行独立解密。默认不加密、自动备份照常运行；加密配置丢失或损坏时自动与额外备份暂停并常驻提示，不会静默回到明文。
- 修复同一分钟自动备份可能清除最新一份的问题，始终保留刚发布的文件。
- 主资料库、图片和恢复前保护副本未加密，加密只保护导出的备份文件。

**Windows 与其他**
- Windows 接入系统文件选择、JPEG／PNG／WebP 预览、定时系统通知、关窗保护与受保护的备份暂存目录；卸载默认保留资料。
- Excel 导入识别文件内与库内疑似重复，结果未知时保留请求并可核对。
- 修复最近删除按 UTC 取日、可能显示前一天的问题。

## 更新与资料兼容

更新前先做[完整备份并异地保存](https://github.com/CoderJackZhu/Thingary/blob/v0.0.7/docs/USER_GUIDE.md#backup)，退出旧应用后替换。本版数据库由 schema 40 升至 **42**：新建存钱目标相关空表，账户类型迁移保留已有账户与盘点；应用在升级前会在资料目录保存一份迁移前副本。升级后的库和完整备份不能直接用旧版打开；需要回退时使用与旧版兼容的升级前备份。

## 验证与限制

本机前端构建、1,248 项 UI 测试、Rust 格式／Clippy 与 864 项 Rust 测试通过，3 项既有容量测试按规则忽略；GitHub CI 的 Mac／Windows 检查、两个方向的跨平台恢复和 Windows 安装包构建与验收均通过。0.0.6（schema 40）的虚构资料与完整备份在新版中升级／恢复后，原有各表内容逐列一致；Mac 与 Windows 的明文和加密备份已互相恢复核对。

未完整验证：Mac 的通知送达、VoiceOver 与完整键盘路径、系统显示缩放、Intel 与 macOS 14；Windows 的无 WebView2 机器、Windows 10、多屏与 100%／125% 缩放、讲述人与输入法、OneDrive 云同步及部分文件对话框；升级、备份与恢复中强退的少数时点。恢复页是「选择备份文件＋粘贴恢复密钥」，没有直接选密钥文件的入口。没有跨设备同步、自动安装更新、交易或自动付款；规划与模拟均按假设估算，路径占比不代表现实成功概率。
