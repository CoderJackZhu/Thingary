# 物谱 0.0.3 Beta · 公开测试版

本版统一 Excel 导入导出，加入金融历史导入与盘点后轻量复盘，改进四问规划、已有贷款安排及养老金资料补齐。GitHub 标记为 Pre-release；0.0.2 保留为历史版本。

## 下载与安装

发布后从 [v0.0.3 Release](https://github.com/CoderJackZhu/Thingary/releases/tag/v0.0.3) 的 Assets 下载 **Thingary-0.0.3-arm64.dmg**，打开后将「物谱」拖入「Applications／应用程序」。Source code 是源码；SHA256SUMS.txt 提供安装包完整性校验值。包内提供「开始使用.html」、图文说明与完整许可材料。

仅提供 **Apple Silicon Mac** 安装包，实测系统范围仍为 macOS 27；最低配置目标 macOS 14 尚未实测，无 Intel、Windows 或 Linux 包。沿用 0.0.2 的本地临时签名，**未经过 Developer ID 签名和 Apple 公证**。首次打开如被系统拦截，请按[安装说明](https://github.com/CoderJackZhu/Thingary/blob/v0.0.3/docs/USER_GUIDE.md#download)在「系统设置 › 隐私与安全性」允许本应用。

操作见[图文使用指南](https://github.com/CoderJackZhu/Thingary/blob/v0.0.3/docs/USER_GUIDE.md)及[规划与职业试算](https://github.com/CoderJackZhu/Thingary/blob/v0.0.3/docs/USER_GUIDE.md#planning)。在线主分支说明会继续更新；本版标签、安装包和包内离线说明在发布后保持发布时的快照。

## 本次更新

- **Excel 与金融历史**：导入导出统一为 `.xlsx` 工作簿，物品、账户、完整盘点、月度收入及分析记录分表展示。账户、完整盘点与月度收入支持预览、冲突核对和同批提交，任一失败整批不写入；未知与零分别保留，同名账户不自动合并。旧 CSV 需整理到新模板；图片及全部关系仍用完整备份迁移。
- **四问规划与结果**：每屏回答一个问题，确认出生年月与退休年龄、生活费、资金和退休收入；可点击步骤切换，编辑时每屏保存。目标页并排显示每月需要与预计能存多少，未知不当零；详情入口、缺项确认和默认收起的工具更清楚。
- **盘点与复盘**：完整盘点后可进入对应区间的轻量复盘，查看待核对清单和事实观察。复盘、向导及详情统一估计存下与推算花销，投资账户变化单列；推算花销为负时撤下金额，提示收入可能没记全。估计不代表真实消费，净资产变化不代表投资收益。
- **已有贷款与待核对条件**：在目标页逐账户填每月还款及固定期限，或声明已含在开销／本次先不考虑；支持部分保存，同一贷款只计一次。待核对的事件、付款、剩余贷款与费用可保留带说明的结果；基础缺项、填写不合规、读取资料失败和职工养老金必要资料不足仍阻止完整计算。没有实际事实的误标发生可撤回。
- **更通用的家庭规划**：可按全家生活费规划，配偶养老金或收入作为其他收入计入，年龄以本人为准；三档收益假设可修改，买房、买车和其他大额预设不分城市。退休后可加子女教育、赡养父母、医疗与护理等阶段性支出。逐年快照按实际起止月份标注目标与退休，默认收起。
- **养老金资料原地补齐**：职工养老金支持北京内置参数与其他城市自填参数；可手填社保工具测算结果，把退休那年的金额折算为今天的钱。目标页、第四问和养老金页共用补齐入口，保留已有事实与选择，保存后按同一组条件比较。自填参数与折算均是假设，不提供官方核定背书。
- **医保年限与提示**：按已确认的缴费安排提醒到法定退休年龄时医保缴费年限是否足够，未知只提示、不阻断目标；不足时可自填补缴估算，作为到达法定退休年龄当月的一次性支出。其他城市要求由用户填写。规划与复盘提示减少工程术语，更直接说明需要填写或核对什么。

## 更新与资料兼容

更新前先做[完整备份并异地保存](https://github.com/CoderJackZhu/Thingary/blob/v0.0.3/docs/USER_GUIDE.md#backup)，退出旧应用，再手动替换应用包。正式资料身份保持 `local.thingary.main`，数据库从 0.0.2 的 **schema 33** 增量迁移至 **schema 35**；旧 schema 33／34 资料与完整备份沿已有兼容路径升级，导入记录随完整备份保留。Excel 格式改动不另加数据库迁移，也无需通过 Excel 搬运原库。

**新版资料和完整备份不能被旧版打开。** 新贷款安排、养老金及医保字段也有旧版读取边界；降低应用版本号不会降低数据格式。需要回退时，须使用升级前且与旧版兼容的完整备份，不能让旧应用直接打开已经升级的资料。Excel 不包含图片及全部配置和关系，不能替代 `.thingary` 完整备份；恢复是整体替换，不是合并。

本次以全新隔离身份运行 0.0.2 源码生成的虚构资料，验证直接升级、重启保留，以及旧自动完整备份恢复后升级至 schema 35；物品、心愿、账户、金额与未知值、关联、保障及图片逐项比对一致。夹具同时包含完整盘点和带未知金额的历史盘点，未知未当作零。

## 验证与限制

本次工程回归基线（版本与交付材料修改前）：前端构建、**875 项前端逻辑测试**、Rust 格式／Clippy 检查及 **513 项数据与存储测试**通过；另有 3 项既有容量测试忽略。前端逻辑和数据与存储测试不代表原生交互已验。

**本次原生验收**：隔离身份下的首次样例、切换自己的空资料、新建物品与账户、完整盘点、自动完整备份恢复及重启保留通过。已抽查四问保存、医保核对卡入口、其他城市参数填写与保存，以及盘点后复盘页；其他城市完整养老金测算尚未逐项验收。手动备份保存与恢复的系统文件选择框**维护者已手动确认（在 227714a 隔离验收构建上，之后备份恢复代码未变）**：保存显示“已保存并校验”，从该文件恢复后目标与医保数据均保留。正式包的 0.0.3 版本、正式身份、arm64 架构与严格签名已核验；只读挂载及复制后的全部文件和符号链接一致，离线指南图片／锚点和许可全文核验通过，包内无数据库、备份或凭据。核验未启动正式身份包。

VoiceOver、其他 Mac／系统版本、真实下载后的 Gatekeeper 首开及系统通知实际送达**未验证**。全部新增功能的原生交互验收尚未闭环；具体限制见[当前限制](https://github.com/CoderJackZhu/Thingary/blob/v0.0.3/docs/USER_GUIDE.md#limits)。

职业变化、养老金、收益及补缴均为假设测算。职工养老金仍有缴费指数、计发基数与起领时间等简化和待校准范围，不代表待遇核定；医保年限不代替经办认定，补缴金额需自行核实。市场模拟的路径占比不代表现实成功概率。

资料和备份未加密；没有跨设备同步、自动更新、交易或自动付款。问题请提交 [Issue](https://github.com/CoderJackZhu/Thingary/issues)，只用虚构资料复现；安全问题按[安全政策](https://github.com/CoderJackZhu/Thingary/blob/v0.0.3/SECURITY.md)私下报告。
