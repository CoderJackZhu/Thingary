# 物谱 0.1.0

> **候选草稿，尚未打标签或公开。** 功能范围、验证结果、附件和已知限制在冻结后按[发布流程](../RELEASING.md)核对；本页不是已发布说明，也不能作为下载入口。

## 本版重点

以下为 0.1.0 候选的用户可感知变化，最终以冻结点和 Release 正文为准：

- 首次打开直接进入完整的虚构样例，顶部说明样例、本机存储与未加密；用途精简只留在设置，不再用引导页阻塞首次使用。
- 账户与盘点主流程改为「更新今天的余额」：保存后先看这次变化；账户行区分本次填写、沿用旧金额和待填写，未变化可逐行确认「与上次相同」。
- 目标页改为左侧条件、右侧结论与资产轨迹；「每月要存多少」「什么时候能不靠工资」直接在结果栏显示，「歇一阵能撑多久」留在试算。报告入口回到结论卡。
- 区间回顾使用与首页一致的期间选择，默认近 1 年；财务复盘保留本期复盘、盘点比较和区间回顾。
- 恢复备份后保留本机身份验证、失焦遮挡与显示偏好；加密恢复支持直接选择密钥文本文件。
- 编辑普通表单时侧栏不再整体变灰；点其他入口先询问是否放弃未保存输入，确认后才离开。

## Windows

- 提供未签名 NSIS x64 安装包，当前用户安装，通常不需要管理员权限；缺少 WebView2 时安装器联网补装。
- **Windows 11 x64 是支持范围；Windows 10 1809+ 是目标范围，但尚未实机验证。** 0.0.8 已有真实 x64 验收；0.1.0 候选本次 CI 在 Windows 11 ARM64 的 x64 模拟环境通过，新增界面仍需真实 x64 复验。仅提供 x64 安装包；ARM64 设备通过系统模拟运行，不等同于原生 ARM 版。
- 0.1.0 候选构建的 [Windows candidate workflow](https://github.com/CoderJackZhu/Thingary/actions/runs/40014617577) 两项任务成功（源码 `87c11ebc31cae2b266f63a7cd7c0057687f5a110`）：release 任务完成构建、静态核验和签名状态检查；隔离验收包完成安装、通知、卸载重装等原生自动流程。验收运行在 Windows 11 ARM64 的 x64 模拟环境，不等于真实 x64 硬件或所有 Windows 版本已验。
- 安装包未签名；SmartScreen 可能提示，智能应用控制可能直接拦截且没有放行按钮。不要为此关闭整机安全保护。

## 已知限制

- Windows 安装包未签名，可能导致 SmartScreen 或设备策略拦截；本项目暂不购买 Windows 代码签名证书，SignPath 申请尚未有结果。
- Windows 10、缺少 WebView2 的联网／断网机器、多屏、完整键盘／输入法／讲述人矩阵仍未闭环。
- 尚未提交 Microsoft Store 或 winget；winget 清单在 0.1.0 公开发布后生成并提交。
- iOS 暂停公开分发；Android 仍在开发；本页不承诺这两个平台的 0.1.0 安装包。
- 主资料库和图片未加密；备份可选加密，自动备份与主资料同盘，仍需异地备份。
