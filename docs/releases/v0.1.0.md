# 物谱 0.1.0

> **公开测试版（Pre-release）。** 本版先作为 Pre-release 发布以收集反馈；各平台验证范围见下文「已知限制」，未验证的内容不应视为已通过。升级前请先做一次完整备份。

## 本版重点

以下为 0.1.0 候选的用户可感知变化，最终以冻结点和 Release 正文为准：

- 首次打开直接进入完整的虚构样例，顶部说明样例、本机存储与未加密；用途精简只留在设置，不再用引导页阻塞首次使用。
- 账户与盘点主流程改为「更新今天的余额」：保存后先看这次变化；新盘点默认把上次有完整金额的账户按「沿用」预填，没变的不用动、变了直接改；账户行区分本次填写、沿用旧金额和待填写。
- 目标页改为左侧条件、右侧结论与资产轨迹；「每月要存多少」「什么时候能不靠工资」直接在结果栏显示，「歇一阵能撑多久」留在试算。报告入口回到结论卡。
- 区间回顾使用与首页一致的期间选择，默认近 1 年；财务复盘保留本期复盘、盘点比较和区间回顾。
- 恢复备份后保留本机身份验证、失焦遮挡与显示偏好；加密恢复支持直接选择密钥文本文件。
- 编辑普通表单时侧栏不再整体变灰；点其他入口先询问是否放弃未保存输入，确认后才离开。
- **界面支持 English**（设置 › 通用，自动时按系统语言）。
- **可选 WebDAV 同步（实验性）**：默认关闭，在「同步方式」选 WebDAV 后展开；服务商预设（坚果云、Nextcloud、群晖）、同步口令默认记在本机、打开与前后台切换时自动核对云端并在本机领先时自动上传，不会自动替换本机资料；冲突时可「对比两边内容」再选。只在本机 WebDAV 服务和 Android 模拟器上验证过。
- **手机界面**：日历用月份格选择，不再弹系统长列表；物品筛选与排序改为点选标签并有「查看 N 件」确认；搜索栏失焦自动收起；批量选择有固定的选择栏。
- **规划样例**：样例展示一个达成目标、没有待确认项的完整示例。
- **Excel 资料表格**：「导出资料表格」补齐心愿与决策、维护与保障、物品状态历史、虚拟资产与储值、订阅付款与规则、已保存规划、业务提醒和自定义选项；物品 Excel 现在可以修改名称、分类、品牌、型号、序列号、购入价、购入日期、渠道和备注并新增行，导入前先预览新增、修改、未变化和冲突，整批确认后才写入，过期表格不会覆盖较新的档案。**这是会修改已有资料的功能，使用前请先做一次完整备份**；表格不是备份，不能用于整体恢复。
- 综合总览恢复先看家底的顺序：金融净资产与规划摘要之后是资产结构、持有物品、四项指标、待关注和近期记录。

## Windows

- 提供未签名 NSIS x64 安装包，当前用户安装，通常不需要管理员权限；缺少 WebView2 时安装器联网补装。
- **Windows 11 x64 是支持范围；Windows 10 1809+ 是目标范围，但尚未实机验证。** 0.0.8 已有真实 x64 验收；0.1.0 候选本次 CI 在 Windows 11 ARM64 的 x64 模拟环境通过，新增界面仍需真实 x64 复验。仅提供 x64 安装包；ARM64 设备通过系统模拟运行，不等同于原生 ARM 版。
- 0.1.0 候选构建的 [Windows candidate workflow](https://github.com/CoderJackZhu/Thingary/actions/runs/40014617577) 两项任务成功（源码 `87c11ebc31cae2b266f63a7cd7c0057687f5a110`）：release 任务完成构建、静态核验和签名状态检查；隔离验收包完成安装、通知、卸载重装等原生自动流程。验收运行在 Windows 11 ARM64 的 x64 模拟环境，不等于真实 x64 硬件或所有 Windows 版本已验。
- 安装包未签名；SmartScreen 可能提示，智能应用控制可能直接拦截且没有放行按钮。不要为此关闭整机安全保护。

## 已知限制

- Windows 安装包未签名，可能导致 SmartScreen 或设备策略拦截；本项目暂不购买 Windows 代码签名证书，SignPath 申请已提交（2026-10-25），对方要求补充公开声誉材料，暂未通过。
- Windows 10、缺少 WebView2 的联网／断网机器、多屏、完整键盘／输入法／讲述人矩阵仍未闭环。
- 尚未提交 Microsoft Store 或 winget；winget 清单在 0.1.0 公开发布后生成并提交。
- iOS 暂停公开分发；Android 为预览阶段，发布草稿流水线会生成签名 APK，是否随本版发布以 Release 为准；本页不承诺这两个平台的 0.1.0 安装包。
- Excel 修改已有物品的导入为本版新增，已有自动测试，原生真机往返验证以验收记录为准；出现异常时请用导入前的完整备份恢复。
- WebDAV 同步为实验性功能：坚果云已在桌面完成真机检查（上传、下载恢复、冲突识别、错误口令、重启）；Nextcloud 和手机真机往返尚未验证。使用前请先做完整备份。
- 部分国产安卓系统对未备案应用可能弹出拦截提示，与应用本身无关；见 README 的 Android 说明。
- 主资料库和图片未加密；备份可选加密，自动备份与主资料同盘，仍需异地备份。
