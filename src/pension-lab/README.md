# 养老金政策核对实验

这里保存可复现的条件计算与校准用例，不是普通规划的备用引擎。暂停新增模型、参数与面板；维护仅限已知错误、既有用例和边界检查。

| 路径 | 用途与边界 |
|---|---|
| `../plan-pension.ts` | 普通入口的简化估算；保留其明确披露的假设和限制 |
| 手填退休收入 | 用户明确填写外部测算金额；不是本目录结果自动写回 |
| `benefit.ts`、`contribution-index.ts`、`account.ts` | 独立金额、历史指数、账户条件核对 |
| `candidate.ts`、`ledger.ts` | 把同一候选条件接到既有账本，供测试和审计使用 |
| `input.ts` | 实验内部输入校验，不供普通业务反向依赖 |

实验可以复用普通模型的日期、资格和账本类型；普通应用入口不得反向依赖实验模块，包括仅类型引用。独立 `career-preview/preview.tsx` 的金额核对、测试及审计脚本可以引用。本边界由 `tests/pension-boundary.test.mjs` 检查静态及动态相对导入。

不新增统一调度器或自动回退。只有取得部分年份同口径的外部核定算例、确认用户可取得输入资料，并验证现金流与原生完整任务后，才讨论替换普通实现；接入时须同时退出被替代路径，不能再保留两套长期运行的选择。

当前算法及限制的权威说明见 [职业情景设计](../../docs/CAREER_SCENARIO_DESIGN.md#北京养老金政策核验与接入门槛)。测试通过不代表政策核定通过。
